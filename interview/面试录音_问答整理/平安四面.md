## Q1. 自我介绍

**问题：** 先简单做个自我介绍，讲一下最近几年的工作。

**回答：** 最近几年主要是在虾皮阶段。我在虾皮负责广告架构开发以及 AI 开发两个方向。

项目经验主要有两段。第一段是作为核心开发者，全程参与广告系统从 0 到 1 的全链路搭建以及持续演进。这块主要让我对在线广告架构、在线架构以及广告预算算法机制有比较深入的实践和了解。

第二个是主导商家运营智能助手 Agent 落地，解决广告运营在知识获取、数据查询、复杂归因诊断三个环节的效率低下问题。通过混合多级 Agent 架构交付三个场景对应能力，同时通过记忆机制设计解决长程任务上下文膨胀，以及上下文膨胀后导致的注意力丢失。

整体来说，我的技术领域聚焦在线 AI 架构，具备算法和工程两个视角，对在线侧和模型侧都有比较深入的实践和了解。

## Q2. Agent 助手整体架构和记忆机制

**问题：** 详细介绍第二个 Agent 助手项目，尤其注意力机制、上下文压缩怎么做，压缩后信息丢失怎么平衡。

**回答：** 项目整体技术架构是通过意图理解模块接入三个场景对应的 Agent，包括知识查询 Agent、text-to-SQL 数据查询 Agent、复杂归因诊断任务的多 Agent 能力。

复杂归因诊断场景里，运营跟踪广告投放表现时，会分析投放数据，发现效果问题，然后需要找到归因并进行优化。这个流程涉及多步骤排查和多数据源拉取。

最开始我们用单 ReAct Agent 做，发现多步推理执行过程中，数据越拉越多，执行结果在上下文里持续膨胀，会出现注意力失焦。比如最开始目标是诊断 CPC 下降原因，后面随着工具持续调用，可能偏移到分析用户画像。

针对这个问题，我们设计了分级记忆机制。大模型上下文窗口有限，所以通过分级存储和上下文窗口构建机制，更有效利用上下文窗口注意力。

## Q3. 四级记忆架构具体是什么

**问题：** 四级记忆机制分别是什么？

**回答：** 四级记忆包括短期记忆、长期记忆、工作区记忆、文件系统记忆。

短期记忆是持续暴露给大模型的 session 记忆。

工作区记忆是为了解决长程任务目标漂移。我们把每一次规划结果和当前 todo list 维护在工作区记忆里，专注当前工作目标。通过定期注入 prompt，提醒它当前应该完成的目标和事项，避免受到工具调用结果干扰。

文件系统记忆主要解决工具调用导致的上下文膨胀。工具调用结果外置到文件系统中，短期上下文只保留摘要和引用文件信息。除了工具调用结果，也会无损保存触发上下文阈值压缩时的上下文记忆。我们保留前 10% 和后 10%，把中间 80% 外置，同时做压缩再回写，实现相对无损的压缩。

长期记忆不是为了解决上下文膨胀，而是让 Agent 在多次执行中沉淀已有经验，形成优化闭环。任务规划时可以检索相似任务的规划路径，优化规划准确度。

## Q4. 上线效果和持续优化

**问题：** 项目上线后的运营效果怎么样？迭代过程中怎么持续优化智能体应用效果，做了哪些具体动作？

**回答：** 效果上，我们有用户采纳率指标。归因诊断这一块达成了 70% 的用户采纳率。

后续迭代中，第一是针对用户未采纳结果做样本 dump，分析观测结果和执行路径。比如有一个 bad case 里发现执行路径出现死循环，导致任务无法推进。基于这个 case，我们做了死循环检测：当前执行节点无法推进时，触发失败传播机制，返回主 Agent 做局部重规划，让局部死循环通过重规划继续推进。

第二是做离线评估。通过离线评估看优化带来什么收益。

## Q5. 业务如何参与 Agent 建设

**问题：** 业务和你们之间是什么协作关系？业务怎么参与具体工作，把原有业务要求或知识转成智能体能力？

**回答：** 业务参与有几种路径。

第一，建设过程中有评价指标维度，我们会建设评估知识库版，很多评估布置依赖业务来编写。

第二，最开始黄金测试集需要业务帮忙构建，相当于给我们迭代的黄金标准。

第三，在使用环节，业务会提出具体使用中的问题和痛点，我们再做系统优化。

第四，业务专家经验会帮我们沉淀标准排查案例 SOP 库。这些 SOP 案例库会作为第一版规划的 few-shot prompt，优化规划。

## Q6. 怎么驱动业务参与

**问题：** 业务有时候不一定乐于参与。你们组织内怎么驱动业务？

**回答：** 我们目标是达成一致的，前期做了一些协调和规划，所以阻力不是特别大。整体来说，他们给我们的支持工作量也不是那么多。

如果有阻力，主要是在构建黄金测试集时，需要他们做手动填写和记录，会有摩擦。可以考虑建设自动录入系统，把他们跟进效果诊断的排查过程转移到平台上做。他们只需要在平台上做信息录入和读取，通过平台化操作记录完整记录步骤，这样可以减少帮我们做信息记录的摩擦成本。

## Q7. 找工作的原因

**问题：** 你现在找工作的原因是什么？详细讲一下。

**回答：** 主要是为了更加深耕 Agent 领域。当前团队主线更偏广告效果优化，我判断未来 Agent 领域会持续增长，所以想进入主线在 Agent 构建的团队，follow 最新发展，让 Agent 能力在不同场景落地。

当前团队毕竟有自己的主线，偏算法工程，更多做广告效果优化。这个领域的发展有窗口期，我希望更快参与到 Agent 领域建设里，找到更聚焦 Agent 构建的团队，更深入参与这个领域。
