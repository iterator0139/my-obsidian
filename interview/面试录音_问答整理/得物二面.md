## Q17. 对 Agent 本质的理解

**问题：** 你觉得 Agent 的本质是什么？从更底层、人类发展史的视角，我们建设这些 Agent 核心是在做什么？

**回答：** 好的，我先聊一下就是我认为的agent是什么。然后首先我们现在是已经有了智能，在我这里看我觉得模型就是模型就是智能，因为它没办法去和现实世界做连接去，它只有它所有的数据分布，你给它一个input它可以给你一个output，但它没办法做任何的事情。

所以我们需要去围绕这个智能去给它构造所有它能够使用的工具，给它围绕这个智能去构造一个一整个生态。它可以基于它的一个智能，它想就像人的大脑一样，你大脑想控制哪你就可以去进行一个物理的一个活动。

所以就是所有的一切，我们包括所有的一切我们都需要去围绕智能，然后来去构造它的整个工具链路。包括第一个我觉得是手，就是它的一个手，手的话就是它的一个工具，它所有能调用的工具，它在它在哪调用工具，然后它包括内置的工具还是你三方的工具，这些都是需要去给它做一个集成的。

第二个的话就是它需要常常提到的所有的上下文。你因为它现在的模型的智能，它是它还没有能够做到动态记忆更新的这样一个能力，所以我们需要才需要去做这种给它做上下文的一些管理以及记忆的机制。

从人类的历史发展史说，这个肯定是就是做我们生产力的一个提升。因为像人类的话他从很早以前的话他的信息的传播速率很慢，然后信息的处理速度也很慢。然后你经过科技的发达，然后科技的发展，然后你的信息互联网的一个发展，然后我们信息的整个流通的效率变得成千上万的这样一个速率在提高。

然后现在的话我们有了大模型，大模型它其实没有把你的信息交换的效率提高，它是把你信息处理的吸收的能力给提高了。所以相当于这一块它是相当于是把你提高了人类在对信息做处理的速率，对，是吸收和处理的一个速率。
