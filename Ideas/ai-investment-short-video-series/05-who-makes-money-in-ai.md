# AI 时代到底谁赚钱：GPU、模型厂商，还是 Agent 应用？

## 开场钩子

AI 肯定会创造巨大价值，但最关键的问题是：  
这笔钱到底谁赚？

是卖 GPU 的公司赚？  
是大模型公司赚？  
还是未来的 Agent 应用赚？

这个问题比“AI 有没有前途”重要得多。

## 核心观点

AI 价值链里，技术重要性不等于利润归属。  
短期最确定的是基础设施，中期最关键的是平台控制权，长期最有想象力的是 Agent 应用，但不确定性也最高。

## 口播正文

我们可以把 AI 价值链拆成三层。

第一层，是基础设施。比如 GPU、HBM、先进封装、数据中心、网络设备、电力设备。

这一层短期最确定赚钱。因为 AI 资本开支已经真实发生了。模型公司和应用公司还在烧钱抢用户，但 GPU、HBM、服务器、电力这些公司已经开始确认收入。

这就是所谓“卖铲子”的优势：不需要判断谁最终淘到金，只要淘金热还在，铲子就有人买。

但卖铲子也不是绝对安全。

关键在于两个问题：铲子是不是稀缺？卖铲子的人是不是不可替代？

NVIDIA 强，不只是因为 GPU 强，而是因为 CUDA、软件生态、开发者习惯、客户迁移成本和平台标准。如果只是某个硬件环节短期产能紧缺，那它更像周期制造业；如果是整个平台被深度绑定，那它才更接近长期垄断。

第二层，是模型厂商。

模型当然重要，但模型公司未必天然赚钱。因为训练成本巨大，推理成本持续消耗毛利，开源模型不断追赶，企业客户也不愿被单一模型锁死。

如果模型能力逐渐同质化，那么 API 价格战就会出现。

所以模型公司的关键不是 benchmark 有多高，而是能不能变成平台。它要控制开发者生态、企业工作流、数据闭环、分发渠道和支付关系。

单纯卖 API 的模型公司，可能创造了巨大技术价值，但商业利润被云厂商、芯片厂、应用层和开源生态分走。

第三层，是 Agent 应用。

这一层想象空间最大。因为如果 Agent 真能接管任务执行，那么软件就不再只是人用的工具，而会变成 AI 调度和执行的系统。

但这一层也最不确定。

一个通用 Agent 帮你处理所有事情，这个愿景很诱人。但现实中有很多难题：权限怎么给，出错谁负责，企业系统怎么集成，支付和身份怎么处理，用户为什么信任它。

所以未来可能不是一个超级 Agent 吃掉所有应用，而是很多垂直软件内部长出 Agent 能力。比如办公软件有办公 Agent，CRM 有销售 Agent，客服系统有客服 Agent，代码编辑器有编程 Agent。

所以谁赚钱？我的判断是：

短期，基础设施最确定。  
中期，模型平台和云平台最关键。  
长期，Agent 应用可能赔率最高，但赢家最难判断。

## 结尾金句

AI 创造价值是一回事，谁能把价值留下来，是另一回事。

## 适合延展的问题

- 模型 API 会不会变成低毛利基础设施？
- NVIDIA 的护城河到底是芯片，还是生态？
- Agent 应用会成为独立公司，还是巨头软件的功能？
