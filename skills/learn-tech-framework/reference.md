## 2. 分析优势的维度

| 维度 | 问什么 |
|------|--------|
| 效果 | 结果质量怎么样 |
| 效率 | 速度、资源利用怎么样 |
| 成本 | 建设、使用、维护成本怎么样 |
| 可靠性 | 是否稳定、容错、鲁棒 |
| 灵活性 | 是否适应多场景、多变化 |
| 扩展性 | 规模变大还能不能扛住 |
| 易用性 | 学习、使用、接入门槛高不高 |
| 可控性 | 是否容易理解、调试、治理 |

---

## 3. 成本分析维度

| 阶段 | 包含 |
|------|------|
| 引入成本 | 学习、选型、采购、接入、迁移 |
| 落地成本 | 开发、人力、时间、协作推进 |
| 运行成本 | 资源、使用、运维、监控 |
| 演进成本 | 扩容、维护、升级、改造、偿还技术债 |
| 机会成本 | 选它而不选别的方案失去什么 |

---

## 4. 风险分析维度（精简版）

| 风险 | 问什么 |
|------|--------|
| 正确性 | 会不会做错 |
| 稳定性 | 会不会不稳 |
| 扩展性 | 规模大了会不会失效 |
| 可控性 | 会不会越来越难管 |
| 依赖 | 会不会被外部条件卡住 |
| 安全/合规 | 会不会出安全或合规问题 |
| 组织/业务 | 会不会落不了地或造成业务损失 |

---

## 5. 机制分析微模板

```markdown
#### [机制名]

#### 是什么
[一段话]

#### 解决的问题
- ...

#### 解决方式
[数据流 / API / 组件]

#### 引入成本
- ...
```

## 6. 调研证据清单

| 问题 | 证据来源 |
|------|----------|
| 官方定位一句话 | README / website |
| 开源 vs 商业边界 | LICENSE, blog, legacy/ |
| 核心 API 入口 | examples, SDK docs |
| 底层引擎 | 依赖、子项目、论文 |
| 推荐第一个 example | examples/ |
| 如何评测 | benchmarks, eval harness |
| 框架集成 | integrations/ |

## 7. Agent 架构映射（可选）

```text
感知层 → 上下文/记忆层 → 意图/规划层 → 执行层 → 反思层 → 学习层
         ↑ 横切：权限 / 成本 / 安全 / 评测
```

标注：**解决哪层 / 不解决哪层**。
