给你一个整数数组 `nums`，请你将该数组升序排列。

你必须在 **不使用任何内置函数** 的情况下解决问题，时间复杂度为 `O(nlog(n))`，并且空间复杂度尽可能小。

**示例 1：**

**输入：**nums = [5,2,3,1]
**输出：**[1,2,3,5]
**解释：**数组排序后，某些数字的位置没有改变（例如，2 和 3），而其他数字的位置发生了改变（例如，1 和 5）。

**示例 2：**

**输入：**nums = [5,1,1,2,0,0]
**输出：**[0,0,1,1,2,5]
**解释：**请注意，nums 的值不一定唯一。

**提示：**

- `1 <= nums.length <= 5 * 104`
- `-5 * 104 <= nums[i] <= 5 * 104`

手撕快排


```

from random import randint
from typing import List

def sort(nums: List[int], left, right) -> None:

	# 缺少递归终止
	if left >= right:
		return
	
	# partition
	mid = partition(nums, left, right)
	
	# sort left part and right part
	sort(nums, left, mid-1)
	sort(nums, mid+1, right)
	
	return
	

def partition(nums: List[int], left: int, right: int) -> int:
	# find the pivot
	# 这里只有random.randint
	pivot_index = rand.int(left, right)
	pivot = nums[pivot_index]
	
	# place pivot to the most left place
	nums[left], nums[pivot_index] = nums[pivot_index], nums[left]
	
	i = left
	j = right
	
	while i < j:
		# 找右边比pivot小的数
		while i < j and nums[j] >= pivot:
			j -= 1
		
		# 找左边比pivot大的数
		while i < j and nums[i] <= pivot:
			i += 1
		
		# 两个数交换
		nums[i], nums[j] = nums[j], nums[i]
	
	# 最后交换left和i就可以了，i左边都是小于等于pivot值的
	nums[left], nums[i] = nums[i], nums[left]
	return i
	
```


你的快速排序在**所有元素相同**的情况下退化为 O(n²) 了。这是快排的经典陷阱。

**问题分析：**

- 当所有元素都是 2 时，虽然你用了随机 pivot，但 partition 后仍然只能排除一个元素
- 每次递归只减少一个元素，导致递归深度为 n，总操作次数为 n + (n-1) + ... + 1 = O(n²)

**思考方向：**

1. 为什么当前的 partition 在全相同元素时效率这么低？
2. 如何修改 partition 逻辑，让**所有等于 pivot 的元素一次性归位**，不再参与后续递归？

**提示：** 考虑使用**三路快排（3-way partition）**，将数组分成：

- `< pivot` 的部分
- `== pivot` 的部分（这部分已经有序！）
- `> pivot` 的部分

你现在的代码中，`== pivot` 的元素分散在左右两部分，导致重复递归。试着修改 partition 函数，让所有等于 pivot 的元素集中在中间，然后只递归处理左右两部分。

```
import random

class Solution:
    def sortArray(self, nums: list[int]) -> list[int]:
        
        def quick_sort(left: int, right: int):
            # 1. 致命遗漏修复：递归终止条件
            if left >= right:
                return
            
            # 2. 随机选取 pivot
            pivot_index = random.randint(left, right)
            pivot = nums[pivot_index]
            
            # 3. 三路划分核心逻辑
            lt = left      # lt 维护“小于区”的右边界
            gt = right     # gt 维护“大于区”的左边界
            i = left       # i 是当前的探测指针
            
            # 当探测指针和大于区相撞时，扫描结束
            while i <= gt:
                if nums[i] < pivot:
                    # 发现小数，扔到前面的小于区
                    nums[lt], nums[i] = nums[i], nums[lt]
                    lt += 1
                    i += 1
                elif nums[i] > pivot:
                    # 发现大数，扔到后面的大于区
                    nums[gt], nums[i] = nums[i], nums[gt]
                    gt -= 1
                    # 注意：这里 i 不能加 1！因为从后面换过来的新数字还没被检查过！
                else:
                    # 相等，直接跳过，它自然就留在了中间的“等于区”
                    i += 1
            
            # 4. 完美避开重复元素，只对纯粹的“小于区”和“大于区”进行递归
            # 中间的 [lt, gt] 全是等于 pivot 的数，已经彻底排好了！
            quick_sort(left, lt - 1)
            quick_sort(gt + 1, right)

        quick_sort(0, len(nums) - 1)
        return nums
```
