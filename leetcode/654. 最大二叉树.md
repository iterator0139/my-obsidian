给定一个不含重复元素的整数数组 `nums` 。一个 **最大二叉树** 定义如下：

- 二叉树的根是数组 `nums` 中的最大元素
- 左子树是通过数组中 **最大值左边部分** 递归构造出的最大二叉树
- 右子树是通过数组中 **最大值右边部分** 递归构造出的最大二叉树

返回有数组 `nums` 构造的 **最大二叉树** 。

**示例 1：**

**输入：** nums = [3,2,1,6,0,5]
**输出：** [6,3,5,null,2,0,null,null,1]
**解释：**
```
      6
    /   \
   3     5
  / \   /
 2   1 0
```

**示例 2：**

**输入：** nums = [3,2,1]
**输出：** [3,null,2,null,1]

**提示：**

- `1 <= nums.length <= 1000`
- `0 <= nums[i] <= 1000`
- `nums` 中的所有整数 **互不相同**

## 五分钟读题法分析

### 第一步：分析性质

#### 识别信号

> **根由「全局最大」决定，左右子树独立递归 → 分治；数组互异、父节点总是子数组最大 → 单调栈 O(n) 在线建树。**

#### 题目性质

- **数据规模**：n ≤ 1000，O(n²) 递归也能过，O(n) 单调栈更优
- **数据结构**：数组 → 二叉树
- **目标类型**：构造树
- **约束特征**：元素**互不相同**；根 = 子数组最大值，左右递归
- **分治信号**：max 把数组切成左、右两段，各自独立构造

#### 性质 → 方法

| 性质 | 本题体现 | 若不满足则… |
|------|---------|------------|
| 根 = 区间最大值 | 全局 max 做根 | 有重复 → index 选择规则要约定 |
| 左右子树独立 | 左段 / 右段递归 | 父子依赖更复杂 → 其他模型 |
| 分治切割 | max 位置切开 | — |
| 互异 + 最大堆性质 | 父 > 子 | 单调栈可 O(n) 建树 |

**判断流程**：

```
构造树，根由区间最大值决定？
  ├── 是 → 分治递归：找 max → 左递归 + 右递归
  │     └── 要 O(n)？
  │           └── ✅ 单调递减栈：维护「还没找到父亲的节点」
  └── 否 → 其他建树规则
```

#### 方法约束

- **约束**：递归每次需 O(n) 找 max 则最坏 O(n²)；单调栈利用「更大元素吃掉左边更小元素」建立父子关系
- **本题**：满足
- **易混淆**：不是 BST（不比较整棵左/右子树大小关系，只保证父 > 直接子）；不是堆数组下标那套（这里是按数组顺序建树）

### 第二步：读题与盲猜

**题目核心**：按「子数组最大为根、左边建左子树、右边建右子树」递归构造二叉树。

**第一直觉**：每次 `index(max)` 切开，左右递归——完全贴合题意，写法最直接。

**盲猜优化方向**：

- **数据结构**：递归分治；或单调栈 O(n)
- **时间复杂度**：递归 O(n²) 最坏（有序数组每层扫全长）；单调栈 O(n)
- **关键洞察**：更大元素会成为更小元素的祖先；栈维护当前「待挂接」的递减链

### 第三步：最优解法

#### 核心转换（分治定义即算法）

```
construct(nums[l..r]):
    if l > r: return null
    p = l..r 中最大值下标
    root = TreeNode(nums[p])
    root.left  = construct(nums[l..p-1])
    root.right = construct(nums[p+1..r])
    return root
```

题面定义本身就是递归结构。

#### 单调栈版（O(n) 破局眼）

扫描 `nums`，栈中保存**递减**节点（栈底到栈顶值递减）：

```
对每个新节点 node：
  while 栈顶值 < node.val:
      node.left = 弹出栈顶    # 更小的成为 node 的左子树
  if 栈非空:
      栈顶.right = node       # node 是栈顶的右孩子
  入栈 node
最后栈底就是根
```

**直觉**：右边出现的更大元素，会把左边比它小的节点「收编」为左子树；还没被更大元素收编的，挂在栈顶右边。

#### 状态定义

**递归版**

- `nums[l:r+1]`：当前待构造的子数组
- 返回值：该子数组对应的最大二叉树根

**单调栈版**

- `stack`：当前递减节点链，等待被右侧更大元素确定父子关系

### 核心代码（Python）

**写法 A：分治递归（最直观）**

```python
def constructMaximumBinaryTree(nums: list[int]) -> Optional[TreeNode]:
    if not nums:
        return None
    i = nums.index(max(nums))
    root = TreeNode(nums[i])
    root.left = constructMaximumBinaryTree(nums[:i])
    root.right = constructMaximumBinaryTree(nums[i + 1:])
    return root
```

**写法 B：单调栈 O(n)**

```python
def constructMaximumBinaryTree_stack(nums: list[int]) -> Optional[TreeNode]:
    stack = []
    for val in nums:
        node = TreeNode(val)
        while stack and stack[-1].val < val:
            node.left = stack.pop()
        if stack:
            stack[-1].right = node
        stack.append(node)
    return stack[0]
```

### 第四步：拆解记忆点

#### 一句话破局眼

> **LeetCode 654 最大二叉树：子数组最大做根，左右分治递归；单调栈 O(n)——更大元素收编左边更小节点为左子树。**

#### 复杂度对比

| 方法 | 时间复杂度 | 空间复杂度 | 适用性 |
|------|-----------|-----------|--------|
| **分治递归** | **O(n²) 最坏，均摊 O(n log n)** | **O(n) 递归栈** | **最贴合题意，n≤1000 足够** |
| **单调栈** | **O(n)** | **O(n)** | **最优，面试加分** |

#### 关键理解点

1. **为什么直接递归就对？** 题面定义 = 算法：max 切开 → 左段左子树、右段右子树
2. **单调栈在干什么？** 维护「还没被更大元素认领」的节点；新来的更大节点把栈顶小节点弹走做左子树
3. **为什么 `stack[-1].right = node`？** 比栈顶大、但比栈顶右边下一个更大的小 → 是栈顶的右孩子
4. **和 105 构造二叉树对比**：105 用前序+中序确定结构；654 只靠最大值分治，规则更简单
