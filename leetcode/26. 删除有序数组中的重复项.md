给你一个 **非严格递增排列** 的数组 `nums`，请你 **原地** 删除重复出现的元素，使每个元素 **只出现一次**，返回删除后数组的新长度。元素的 **相对顺序** 应该保持 **一致**。然后返回 `nums` 中唯一元素的个数。

考虑 `nums` 的唯一元素的个数为 `k`，你需要做以下事情确保题面得到尊重：

- 如果数组中有任何元素不是唯一的，那么你修复前 `k` 个元素应该包含最终被放在数组中的唯一元素。下标 `≥ k` 的其余下标（`nums` 的容量）可以保持任何内容。
- 不用理会数组后面那些可能存在的元素。
- 你不需要考虑数组超出新长度后面的元素。

**示例 1：**

```
输入：nums = [1,1,2]
输出：2, nums = [1,2,_]
解释：函数应该返回新的长度 2 ，并且原数组 nums 的前两个元素被修改为 1, 2 。不需要考虑数组中超出新长度后面的元素。
```

**示例 2：**

```
输入：nums = [0,0,1,1,1,2,2,3,3,4]
输出：5, nums = [0,1,2,3,4]
解释：函数应该返回新的长度 5 ，并且原数组 nums 的前五个元素被修改为 0, 1, 2, 3, 4 。不需要考虑数组中超出新长度后面的元素。
```

**提示：**

- `1 <= nums.length <= 3 * 10^4`
- `-100 <= nums[i] <= 100`
- `nums` 已按 **非严格递增** 排列

## 五分钟读题法分析

### 第一步：分析性质

#### 识别信号

> **有序数组原地去重 → 重复元素相邻，快指针扫描、慢指针维护「已去重区间」的写入位置。**

#### 题目性质

- **数据规模**：n ≤ 3×10⁴，O(n) 一趟足够
- **数据结构**：有序数组
- **目标类型**：原地修改 + 返回新长度
- **范围约束**：保持相对顺序；只要求前 k 位正确
- **单调性**：有序 → 相同值必相邻，见一个「新值」才写入

#### 性质 → 方法

| 性质           | 本题体现    | 若不满足则…                              |
| ------------ | ------- | ----------------------------------- |
| 数组有序         | 重复值相邻   | 无序 → 哈希 set 去重，或排序后本题解法             |
| 原地修改         | 不能开新数组  | 可用新数组则直接 set                        |
| 保序           | 慢指针顺序写入 | 不要求顺序 → set 更简单                     |
| 每个元素最多保留 1 次 | 见新值才写   | 保留 2 次 → LC 80，慢指针判断 `nums[slow-1]` |

**判断流程**：

```
有序数组 + 原地删除重复？
  ├── 每个值保留 1 次 → ✅ 同向双指针（快慢 / 读写）
  ├── 每个值最多 2 次 → LC 80，慢指针多看 slow-1
  └── 无序 → 哈希 / 排序
```

#### 方法约束

- **约束**：读写双指针有效，需要「慢指针维护的区域始终是合法答案前缀」
- **本题**：满足。`nums[0..slow]` 始终是无重复递增前缀
- **易混淆**：
  - LC 27 移除元素：条件不同，但手势相同（快扫慢写）
  - LC 80 允许最多 2 个重复：写法几乎一样，多一个比较

### 第二步：读题与盲猜

**题目核心**：有序数组原地去重，返回唯一元素个数 k，前 k 位为去重结果。

**第一直觉**：用 set 收集，再写回数组。O(n) 但 O(n) 空间，且 set 不保证顺序（Python 3.7+ 虽有序但面试常要求 O(1) 空间）。

**盲猜优化方向**：

- **数据结构**：同向双指针（慢 = 写，快 = 读）
- **时间复杂度**：O(n) 一趟
- **关键洞察**：有序 → 重复必相邻；`nums[fast]` 与 `nums[slow]` 不同才是「新唯一值」

### 第三步：最优解法

#### 核心转换

```
原地去重
  ⇔ 把每个「首次出现」的值依次写到 nums[0], nums[1], ...
  ⇔ slow 指向已去重区间的最后一个位置
```

#### 状态定义

- `slow`：已去重区间 `[0, slow]` 的最后一个下标（下一个唯一值写到哪里）
- `fast`：扫描指针，从 1 到 n-1

#### 核心状态转移（破局眼）

```python
if nums[fast] != nums[slow]:
    slow += 1
    nums[slow] = nums[fast]
# fast 每轮 +1（for 循环）
return slow + 1
```

#### 关键实现细节

- **初始化**：`slow = 0`（第一个元素一定保留），`fast` 从 1 开始
- **为什么和 `nums[slow]` 比？** `slow` 是已写入区间的末尾，有序数组下新唯一值一定与末尾不同
- **返回值**：`slow + 1`（长度），不是 `slow`
- **空数组**：题目保证 `n >= 1`，无需特判
- **全相同**：`slow` 始终为 0，返回 1

### 核心代码（Python）

```python
def removeDuplicates(nums: list[int]) -> int:
    if not nums:
        return 0
    slow = 0
    for fast in range(1, len(nums)):
        if nums[fast] != nums[slow]:
            slow += 1
            nums[slow] = nums[fast]
    return slow + 1
```

#### 等价写法（slow 表示「下一个写入位置」）

```python
def removeDuplicates(nums: list[int]) -> int:
    slow = 0
    for fast in range(len(nums)):
        if slow == 0 or nums[fast] != nums[slow - 1]:
            nums[slow] = nums[fast]
            slow += 1
    return slow
```

推荐第一种：`slow` = 已去重区间末尾，更直观。

### 第四步：拆解记忆点

#### 一句话破局眼

> **LeetCode 26 删除有序数组中的重复项：有序则重复相邻，快扫慢写，见新值才 `slow++` 写入。**

#### 复杂度对比

| 方法 | 时间 | 空间 | 适用性 |
|------|------|------|--------|
| set 去重再写回 | O(n) | O(n) | 不要求 O(1) 空间 |
| 同向双指针 | O(n) | O(1) | ✅ 最优 |

#### 关键理解点

1. **为什么必须有序？** 无序时重复不相邻，不能只看 `nums[slow]`，需要哈希记录见过谁。
2. **slow 的含义？** 已确认唯一区间的 **最后一个下标**；新值写到 `slow+1`。
3. **和 LC 27 的区别？** 27 按条件删（等于 val）；26 按「与上一唯一值不同」写。手势都是快读慢写。
4. **LC 80 怎么改？** 允许 2 个重复时，判断 `nums[fast] != nums[slow - 1]`（或 `slow < 2`）再写入。
