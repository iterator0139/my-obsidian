给定一个二叉树的根节点 `root`，请找出该树 **最底层最左边** 节点的值。

**示例 1：**

**输入：** root = [2,1,3]
**输出：** 1

**示例 2：**

**输入：** root = [1,2,3,4,null,5,6,null,null,7]
**输出：** 7

**提示：**

- 树中节点的数目范围是 `[1, 10^4]`
- `-2^31 <= Node.val <= 2^31 - 1`

---

## 五分钟读题法分析

### 第一步：分析性质

#### 识别信号

> **按层处理 + 取最深层信息 → BFS 层序遍历，每层记录第一个节点，最后一层第一个即答案；或 DFS 先左后深，更深时更新答案。**

#### 题目性质

- **数据规模**：n ≤ 10⁴，BFS/DFS O(n) 足够
- **数据结构**：二叉树
- **目标类型**：找特定节点值（最深层的**最左**）
- **约束特征**：「最底层」= 最大深度；同层多个时取**最左**
- **层与层关系**：层序遍历天然区分深度

#### 性质 → 方法

| 性质     | 本题体现     | 若不满足则…            |
| ------ | -------- | ----------------- |
| 要最深层   | 最大 depth | 只要最左节点 → 一直走 left |
| 同层取最左  | 每层第一个    | 要最右 → 每层最后一个      |
| 按层统计   | BFS 批处理  | 不需层信息 → 纯 DFS 也行  |
| 单一路径答案 | 一个值      | 要所有最底层节点 → 收集整层   |
|        |          |                   |

**判断流程**：

```
找最底层最左节点？
  ├── BFS 层序 → 每层记第一个，遍历结束后即答案 ✅
  └── DFS 先左后右 → 更深时更新 (depth, val) ✅
```

#### 方法约束

- **约束**：BFS 必须按层批处理（`size = len(q)`），不能边 pop 边入队混层；DFS 必须**先左后右、先深后浅**才能保证同层更左不被覆盖
- **本题**：满足
- **易混淆**：不是「左下角」= 一直走 left（那是左链末端，可能不在最深层）

---

### 第二步：读题与盲猜

**题目核心**：返回深度最大那一层里，最靠左节点的值。

**第一直觉**：DFS 一路向左到底——错。如 `[1,2,3,4,null,5,6,null,null,7]`，最底层最左是 7，不是左链上的 4。

**盲猜优化方向**：

- **数据结构**：BFS 队列，或 DFS 递归
- **时间复杂度**：O(n)
- **关键洞察**：「最底层 + 最左」= 层序遍历中**最后一层的第一个节点**

---

### 第三步：最优解法

#### 核心转换

```
最底层最左 = 深度最大的那一层中，下标最小的节点
         = BFS 按层遍历时，最后一层的队首元素
```

#### 写法 A：BFS 层序（最直观）

**状态定义**

- `queue`：当前层节点
- `ans`：当前层第一个节点的值（每处理新一层就更新）

**破局眼**

```
while q:
    size = len(q)
    ans = q[0].val          # 本层第一个 = 本层最左
    处理 size 个节点，子节点入队
return ans                  # 循环结束时 ans 即最后一层最左
```

#### 写法 B：DFS 先左后深

**破局眼**

```
dfs(node, depth):
    if not node: return
    if depth > max_depth:
        max_depth = depth
        ans = node.val
    dfs(node.left, depth+1)   # 先左
    dfs(node.right, depth+1)  # 后右
```

同深度时先访问左子树，所以更左的节点先被记录，不会被右边覆盖。

#### 关键实现细节

- **BFS 必须按层批处理**：不能 `while q: pop; push children` 混在一层里，否则无法区分「最后一层第一个」
- **左链 ≠ 答案**：最底层最左可能在右子树的更深处
- **DFS 更新条件**：`depth > max_depth` 用严格大于，同深度不更新（先左后右已保证最左）

### 核心代码（Python）

**写法 A：BFS**

```python
from collections import deque

def findBottomLeftValue(root: Optional[TreeNode]) -> int:
    q = deque([root])
    ans = root.val
    while q:
        size = len(q)
        ans = q[0].val
        for _ in range(size):
            node = q.popleft()
            if node.left:
                q.append(node.left)
            if node.right:
                q.append(node.right)
    return ans
```

**写法 B：DFS**

```python
def findBottomLeftValue_dfs(root: Optional[TreeNode]) -> int:
    ans = 0
    max_depth = -1

    def dfs(node, depth):
        nonlocal ans, max_depth
        if not node:
            return
        if depth > max_depth:
            max_depth = depth
            ans = node.val
        dfs(node.left, depth + 1)
        dfs(node.right, depth + 1)

    dfs(root, 0)
    return ans
```

### 第四步：拆解记忆点

#### 一句话破局眼

> **LeetCode 513 找树左下角的值：BFS 层序，每层记第一个，最后一层第一个即答案；DFS 先左后深、更深时更新。**

#### 复杂度对比

| 方法 | 时间复杂度 | 空间复杂度 | 适用性 |
|------|-----------|-----------|--------|
| 一路向左 | O(h) | O(1) | **错**：左链末端不一定在最深层 |
| **BFS 层序** | **O(n)** | **O(n)** | **最直观，推荐** |
| **DFS 先左后深** | **O(n)** | **O(h)** | **代码短，空间更省** |

#### 关键理解点

1. **「左下角」≠ 左链末端**：要的是**最深层**里的**最左**，可能在右子树深处
2. **BFS 为何记每层第一个？** 层序从左到右入队，队首就是该层最左
3. **DFS 为何先左后右？** 同深度时左子树先访问，配合 `depth > max_depth` 保证取最左
4. **和 662 对比**：662 也算层信息，但要编号算宽度；513 只要层首值
