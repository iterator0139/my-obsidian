给你一个数组 `prices` ，其中 `prices[i]` 是商店里第 `i` 件商品的价格。

商店里正在进行促销活动，如果你要买第 `i` 件商品，那么你可以得到与 `prices[j]` 相等的折扣，其中 `j` 是满足 `j > i` 且 `prices[j] <= prices[i]` 的 **最小下标** ，如果没有满足条件的 `j` ，你将没有任何折扣。

请你返回一个数组，数组中第 `i` 个元素是折扣后你购买商品 `i` 最终需要支付的价格。

**示例 1：**

**输入：**prices = [8,4,6,2,3]
**输出：**[4,2,4,2,3]
**解释：**
商品 0 的价格为 price[0]=8 ，你将得到 prices[1]=4 的折扣，所以最终价格为 8 - 4 = 4 。
商品 1 的价格为 price[1]=4 ，你将得到 prices[3]=2 的折扣，所以最终价格为 4 - 2 = 2 。
商品 2 的价格为 price[2]=6 ，你将得到 prices[3]=2 的折扣，所以最终价格为 6 - 2 = 4 。
商品 3 和 4 都没有折扣。

**示例 2：**

**输入：**prices = [1,2,3,4,5]
**输出：**[1,2,3,4,5]
**解释：**在这个例子中，所有商品都没有折扣。

**示例 3：**

**输入：**prices = [10,1,1,6]
**输出：**[9,0,1,6]

**提示：**

- `1 <= prices.length <= 500`
- `1 <= prices[i] <= 10^3`

---

## 破局眼 🎯

> **"下一个更小或相等元素" → 单调递增栈。遇到右侧第一个 ≤ 当前值的元素，结算折扣。**

栈里存下标，维护**单调递增**（栈底到栈顶 prices 递增）。遍历到 `j` 时，如果 `prices[j] <= prices[栈顶]`，说明栈顶找到了它的折扣，弹出结算。

## 代码

```python
def finalPrices(self, prices: List[int]) -> List[int]:
    n = len(prices)
    ans = prices[:]           # 先复制，没有折扣就是原价
    stack = []                # 单调递增栈，存下标

    for j in range(n):
        while stack and prices[stack[-1]] >= prices[j]:
            i = stack.pop()
            ans[i] = prices[i] - prices[j]
        stack.append(j)

    return ans
```

## 单调栈模板对比

| 问题 | 栈的单调性 | 触发结算条件 |
|------|-----------|-------------|
| 下一个更大元素 | 递减 | `cur > 栈顶` |
| 下一个更小元素 | **递增** | `cur <= 栈顶` |
| 本题 | **递增** | `cur <= 栈顶` |

> 单调栈的核心就两件事：**栈里存什么（下标）、什么条件触发结算。**

## 什么性质的题可以用这个解法？

本题本质是 **"下一个更小/更大元素" → 单调栈** 模式。

### 必要条件

| 性质 | 本题体现 | 反例（不能用） |
|------|---------|-------------|
| **找下一个满足条件的元素** | 找右侧第一个 `≤` 当前值的元素 | 不关心顺序 → 排序后双指针 |
| **方向性**（向左/向右找） | 向右找（`j > i`） | 无方向约束 |
| **条件是比较运算** | `prices[j] <= prices[i]` | 条件无法用比较表达 → 用其他结构 |
| **结算依赖于找到的元素** | 找到后计算 `price[i] - price[j]` | 只需知道有没有 → 布尔数组 |

### 单调栈的两种模板

| 场景 | 栈的单调性 | 触发结算 | 代表题 |
|------|-----------|---------|-------|
| **下一个更大元素** | **递减**栈 | 遇到 `cur > 栈顶` 时弹出结算 | LC 496, LC 739 |
| **下一个更小元素** | **递增**栈 | 遇到 `cur < 栈顶` 时弹出结算 | LC 1475（严格小） |
| **下一个更小或相等** | **递增**栈 | 遇到 `cur <= 栈顶` 时弹出结算 | LC 1475（本题） |

### 判断流程

```
题目要求找每个元素右侧/左侧第一个比它大/小的元素？
  ├── 是 → ✅ 单调栈
  │     ├── 找更大 → 递减栈
  │     └── 找更小 → 递增栈
  └── 否 → 是否找连续的区间极值？
        ├── 是 → 单调队列（滑动窗口）
        └── 否 → 不是单调栈问题
```

### 单调栈核心要点

> **栈里存什么？** 通常存下标（方便回源数组取值）。
> **什么时候结算？** 新元素破坏了栈的单调性时。
> **结算做什么？** 弹出栈顶，用新元素和栈顶计算答案。
