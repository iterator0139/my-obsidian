给定 `n` 个非负整数表示每个宽度为 `1` 的柱子的高度图，计算按此排列的柱子，下雨之后能接多少雨水。

**示例 1：**

![](https://assets.leetcode.cn/aliyun-lc-upload/uploads/2018/10/22/rainwatertrap.png)

**输入：**height = [0,1,0,2,1,0,1,3,2,1,2,1]
**输出：**6
**解释：**上面是由数组 [0,1,0,2,1,0,1,3,2,1,2,1] 表示的高度图，在这种情况下，可以接 6 个单位的雨水（蓝色部分表示雨水）。 

**示例 2：**

**输入：**height = [4,2,0,3,2,5]
**输出：**9

**提示：**

- `n == height.length`
- `1 <= n <= 2 * 104`
- `0 <= height[i] <= 105`

题目的分析

每一个位置能承载的雨水由她左边最高的柱子和右边最高的柱子决定。
$cap[i] = min(leftMax, rightMax) - height[i]$

所以暴力法可以为每个位置，求它左边的最高和右边的最高，然后累加每个位置的雨水
这样时间复杂度是$O(n^2)$，空间复杂度为$O(1)$

```
def trap(nums: List[int]) -> int:
	n = len(nums)
	res = 0
	for i in range(n):
		maxLeft, maxRight =  0, 0
		for j in range(0, i):
			maxLeft = max(nums[j], maxLeft)
		for j in range(n-1, i, -1):
			maxRight = max(nums[j], maxRight)
		if min(maxLeft, maxRight) - nums[i] > 0:
			res += min(maxLeft, maxRight) - nums[i]
	return res
		
```


为了优化时间复杂度，我们采用预计算的方式，为每个位置预计算它的左前缀最大数组和右前缀最大数组，这样可以直接查表的方式得到$leftMax$和$rightMax$

```
def trap(nums: List[int]) -> int:
	n = len(nums)
	prefixMax = [0] * n
	suffixMax = [0] * n
	res = 0
	
	# 建议在定义前缀/后缀最大值时，包含当前柱子自身，
	# 这样既能避免越界，又能自动处理当前柱子是最高点时雨水为 0 的情况。
	prefixMax[0] = nums[0]
	for i in range(1, n):
		prefixMax[i] = max(prefixMax[i-1], nums[i])
	
	suffixMax[n-1] = nums[n-1]
	for i in range(n-1, -1, -1):
		suffixMax[i] = max(suffixMax[i+1], nums[i])
		
	for i in range(n):
		max = min(prefixMax[i], suffixMax[i])
		if max > nums[i]: #构建前缀最大值的时候已经比较过？
			res += max - nums[i]
```

更进一步的优化，我们发现当左边的最大值小于右边最大值的时候，这个时候left位置的雨水量已经和右边无关了，我们可以直接结算，然后更新左边的最大值。同理，当rightMax小于leftMax的时候，right位置的雨水量也只取决rightMax了，也可以直接结算

```
def trap(nums: List[int]) -> int:
	n = len(nums)
	left = 0
	right = n-1
	leftMax, rightMax = 0, 0
	res = 0
	
	while left < right:
		if leftMax <= rightMax:
			# 先更新max来统一当前位置比左右高的情况？
			leftMax = max(leftMax, nums[left])
			res += leftMax - nums[left]
			left += 1
		else:
			rightMax = max(rightMax, nums[right])
			res += rightMax - nums[right]
			right -= 1
	return res
```


最后如果用栈的方法
维护一个单调递减栈，如果遇到比栈顶更高的元素，那么可以pop出栈顶，然后用新栈顶作为left，当前位置作为right，构成一个集水区，area = (right - left - 1) * min(right_height, left_height)

```
def trap(nums: List[int]) -> int:
	stack = []
	res = 0
	for i, num in enumerate(nums):
		while stack and nums[i] > nums[stack[-1]]:
			mid = stack.pop()
			if not stack:  
				break
			left = stack[-1]
			right = i
			
			width = right - left - 1
			height = min(nums[left], nums[right]) - nums[mid]
			if height > 0:  
				res += width * height
		stack.append(i)
	return res
			
```
