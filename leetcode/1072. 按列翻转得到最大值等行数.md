给定 `m x n` 矩阵 `matrix` 。

你可以从中选出任意数量的列并翻转其上的 **每个** 单元格。（即翻转后，单元格的值从 `0` 变成 `1`，或者从 `1` 变为 `0` 。）

返回 _经过一些翻转后，行内所有值都相等的最大行数_ 。

**示例 1：**

**输入：**matrix = [[0,1],[1,1]]
**输出：**1
**解释：**不进行翻转，有 1 行所有值都相等。

**示例 2：**

**输入：**matrix = [[0,1],[1,0]]
**输出：**2
**解释：**翻转第一列的值之后，这两行都由相等的值组成。

**示例 3：**

**输入：**matrix = [[0,0,0],[0,0,1],[1,1,0]]
**输出：**2
**解释：**翻转前两列的值之后，后两行由相等的值组成。

**提示：**

- `m == matrix.length`
- `n == matrix[i].length`
- `1 <= m, n <= 300`
- `matrix[i][j] == 0` 或 `1`



1072. 按列翻转得到最大值等行数 这道题我的思路是求出每一行要变成一样的要反转哪些列，不能反转哪些列。任意两行能够同时通过反转变成一样的数字的条件是，不能反转的列和要反转的列是互斥的。求满足条件最多的行数

你的直觉非常敏锐，已经精准地逼近了解题的本质！

你说的“要反转的列和不能反转的列互斥”，用更直白的矩阵语言翻译过来就是：**如果两行能够同时通过某种列翻转方案达到“全行相等”，那么这两行在初始状态下，要么完全相同，要么完全相反（互补）。**

比如 `[0, 1, 0]` 和 `[1, 0, 1]`。如果我们翻转中间那一列，第一行变成 `[0, 0, 0]`，第二行变成 `[1, 1, 1]`，它们都达到了全行相等。

为了不去处理复杂的“互斥集合”，我们可以用一个极妙的技巧——**特征标准化（Canonicalization）**：让每一行都强行以 `0` 开头。如果某一行以 `1` 开头，就把整行取反。这样，所有“本质相同”的行都会变成一模一样的字符串，我们只需要用哈希表数一数谁出现的次数最多即可。

### 破局眼 🎯

两行能同时变相等的充要条件是：它们**完全相同**或**完全相反**。 通过**将所有行“标准化”为以 0 开头**，将复杂的“方案匹配”退化为简单的“字符串计数（哈希表）”。

### 解法：特征标准化 + 哈希表计数

Python

```
def maxEqualRowsAfterFlips(matrix: list[list[int]]) -> int:
    from collections import Counter
    
    count = Counter()
    
    for row in matrix:
        # 如果整行以 1 开头，我们就把整行取反（0变1，1变0），强行让它以 0 开头
        if row[0] == 1:
            # 利用元组作为哈希表的 key
            normalized = tuple(1 - x for x in row)
        else:
            normalized = tuple(row)
            
        count[normalized] += 1
        
    # 返回出现次数最多的标准化特征的数量
    return max(count.values())
```

### 过程图解（matrix = [[0,1],[1,0],[1,1]]）

- **第 0 行：`[0, 1]`**
    
    - 以 `0` 开头 → 保持不变 → 特征为 `(0, 1)`
        
    - 哈希表：`{(0, 1): 1}`
        
- **第 1 行：`[1, 0]`**
    
    - 以 `1` 开头 → 全行取反 → 特征变为 `(0, 1)`
        
    - 哈希表：`{(0, 1): 2}`（发现同路人了！）
        
- **第 2 行：`[1, 1]`**
    
    - 以 `1` 开头 → 全行取反 → 特征变为 `(0, 0)`
        
    - 哈希表：`{(0, 1): 2, (0, 0): 1}`
        

**最终答案：** `max(2, 1) = 2`。

- **时间复杂度：** O(M×N)，其中 M 是行数，N 是列数。只需遍历一次矩阵。
    
- **空间复杂度：** O(M×N)，用于存储哈希表中的行特征。
    

### 什么性质的题可以用这个解法？

本题本质是 **“等价类划分 / 特征归一化（Normalization）”** 的模式。

#### 必要条件

| 性质             | 本题体现                                          | 反例（不能用归一化计数）                               |
| -------------- | --------------------------------------------- | ------------------------------------------ |
| **状态独立性**      | 列的翻转对所有行是全局同步生效的，两行之间的相对关系（相同或相反）是死理，不随翻转而改变。 | 翻转某一列会给不同行带来不同的、非线性的收益。                    |
| **存在某种对偶/对称性** | 目标是全 `0` 或全 `1`，这两种状态在逻辑上是对等的。                | 目标具有特异性（比如要求第 1 行全 0，第 2 行必须全 1 且指定位置为 0）。 |
| **容易提取“代表元”**  | 通过“首位对齐为 0”可以极低成本地找到这组状态的“代表元”。               | 状态极其复杂，无法用简单的规则将其化简为统一形态。                  |
