当给定整数 `n` 时，返回满足以下条件的**最大整数**：

- 该整数的每一位数字都满足单调递增（即每一位数字都大于等于左边一位数字）
- 该整数小于等于 `n`

**示例 1：**

**输入：** n = 10
**输出：** 9

**示例 2：**

**输入：** n = 1234
**输出：** 1234

**示例 3：**

**输入：** n = 332
**输出：** 299

**提示：**

- `0 <= n <= 10^9`

---

## 五分钟读题法分析

### 第一步：分析性质

#### 识别信号

> **在 ≤ n 的约束下求「数位单调递增」的最大数 → 从高位贪心；一旦出现 `digits[i] > digits[i+1]`，必须让左边那位减 1、右边全变 9。**

#### 题目性质

- **数据规模**：n ≤ 10⁹，最多 10 位，按位处理 O(位数) 即可
- **数据结构**：整数，按十进制位处理
- **目标类型**：构造满足约束的**最大**整数（≤ n）
- **约束特征**：数位从左到右非递减（每位 ≥ 左边）
- **贪心信号**：要最大 → 尽量不动高位；只有「破坏递增」时才动，且动完右边填 9 能最大化低位

#### 性质 → 方法

| 性质 | 本题体现 | 若不满足则… |
|------|---------|------------|
| 数位约束 | 每位 ≥ 左边 | 无数位约束 → 其他模型 |
| 求 ≤ n 的最大合法数 | 高位尽量大 | 求 ≥ n 的最小 → 对称贪心 |
| 破坏递增处必须调整 | `s[i] > s[i+1]` | 已递增 → 直接返回 n |
| 减 1 可能连锁左移 | `332` 减十位后百位仍破坏 | 只减「第一个」可能不够 |

**判断流程**：

```
数位是否已单调递增？
  ├── 是 → 直接返回 n
  └── 否 → 找到破坏递增的位置
        ├── 从左找第一个 s[i] > s[i+1]，s[i]--，后面全 9
        │     └── 若 s[i-1] > s[i]（减后仍破坏）→ 继续左移减 1
        └── 或：从右往左扫，凡 s[i-1] > s[i] 就让 s[i-1]--，记录 mark，最后 mark 之后全 9
```

#### 方法约束

- **约束**：贪心正确性来自——减高位 1 损失最小；减完之后右边全填 9 是在该高位固定下的最大低位
- **本题**：满足
- **易混淆**：「第一个破坏递增的数字」要减的是**左边那位较大的**（`s[i]` 当 `s[i] > s[i+1]`），且减 1 后可能要**连锁往左**再减

### 第二步：读题与盲猜

**题目核心**：找 ≤ n 且数位单调递增的最大整数。

**第一直觉**：从左往右维护递增，遇到第一个 `s[i] > s[i+1]`，把 `s[i]` 减 1，后面全变 9——大方向对，但 `332` 会翻车：只减十位得 `329`，百位 3 仍 > 十位 2。

**盲猜优化方向**：

- **数据结构**：数字转字符数组，按位修改
- **时间复杂度**：O(位数)
- **关键洞察**：破坏递增后，减 1 可能引发左边新的破坏，要从右往左扫完整个「递减链」，或减完后继续左移

---

### 第三步：最优解法

#### 核心转换

把整数看成字符串/数组，问题变成：**最少改动哪些位，使结果 ≤ 原数且数位单调递增，并尽量大**。

策略：一旦出现 `s[i-1] > s[i]`，必须让 `s[i-1]` 减 1（否则无法单调），并把 `i` 及之后全设为 `9`（在该前缀下最大化后面）。

#### 用户思路 vs 完整贪心

| 步骤 | 用户思路 | 需补充 |
|------|---------|--------|
| 发现破坏递增 | ✅ `s[i] > s[i+1]` | 减的是**左边**那位 `s[i]`，不是 `s[i+1]` |
| 减 1 + 后面全 9 | ✅ | 减 1 后若 `s[i-1] > s[i]`，要**继续往左**减 |
| 扫描方向 | 从左往右发现 | 实现上**从右往左**更自然，自动处理连锁 |

**反例 `332`**：

```
只减第一个破坏位（十位 3→2）：329，百位 3 > 十位 2，仍不合法
连锁：百位也减 1 → 299 ✅
```

#### 状态定义

- `s`：n 的字符数组
- `mark`：从哪一位开始后面全部填 `9`（初始 `len(s)`，表示暂不填）

#### 核心状态转移（破局眼）

**从右往左**（推荐，自动处理连锁）：

```
for i from n-1 down to 1:
    if s[i] < s[i-1]:
        s[i-1]--           # 左边太大，必须减
        mark = i           # i 及之后全变 9
for j from mark to n-1:
    s[j] = '9'
```

**从左往右**（等价，需 while 回退）：

```
找到第一个 i 使 s[i] > s[i+1]
s[i]--
while i > 0 and s[i-1] > s[i]:   # 连锁左移
    i--
    s[i]--
把 i+1 之后全设为 '9'
```

#### 关键实现细节

- **减的是左边那位**：`s[i] > s[i+1]` 时动 `s[i]`，不是 `s[i+1]`
- **连锁左移**：`1332` → 个位 2 破坏 → 减十位 3→2 → 百位 3 > 十位 2 → 继续减百位 → `1299`
- **边界**：`n=10` → `09` → 整数 9；前导 0 不影响结果
- **已递增**：循环不触发，`mark` 保持末尾，不会误填 9

### 核心代码（Python）

**写法 A：从右往左（推荐）**

```python
def monotoneIncreasingDigits(n: int) -> int:
    s = list(str(n))
    mark = len(s)
    for i in range(len(s) - 1, 0, -1):
        if s[i] < s[i - 1]:
            s[i - 1] = str(int(s[i - 1]) - 1)
            mark = i
    for i in range(mark, len(s)):
        s[i] = '9'
    return int(''.join(s))
```

**写法 B：从左往右 + 连锁回退**

```python
def monotoneIncreasingDigits_left(n: int) -> int:
    s = list(str(n))
    i = 0
    while i < len(s) - 1 and s[i] <= s[i + 1]:
        i += 1
    if i == len(s) - 1:
        return n
    while i > 0 and s[i - 1] > s[i]:
        i -= 1
    s[i] = str(int(s[i]) - 1)
    for j in range(i + 1, len(s)):
        s[j] = '9'
    return int(''.join(s))
```

### 第四步：拆解记忆点

#### 一句话破局眼

> **LeetCode 738 单调递增的数字：发现 `s[i] > s[i+1]` 就让 `s[i]` 减 1、后面全 9；减完可能要连锁往左再减。**

#### 复杂度对比

| 方法 | 时间复杂度 | 空间复杂度 | 适用性 |
|------|-----------|-----------|--------|
| 暴力枚举 ≤ n | O(n) 不可行 | O(1) | n 大时 TLE |
| **贪心按位调整** | **O(位数)** | **O(位数)** | **本题最优** |

#### 关键理解点

1. **减哪一位？** `s[i] > s[i+1]` 时减 **左边的 `s[i]`**，右边填 9 是在该前缀下的最大低位
2. **为什么要连锁？** `332` 只减十位得 `329`，百位仍破坏；必须从右往左扫完或 while 回退
3. **为什么从右往左好写？** 每次 `s[i] < s[i-1]` 就减 `s[i-1]` 并更新 mark，自然覆盖整条递减链
4. **为什么后面全 9？** 高位减 1 后，要 ≤ 原数且尽量大，低位能填多大填多大 → 全 9
