给你一个单链表的引用结点 `head`。链表中每个结点的值不是 0 就是 1。已知此链表是一个整数数字的二进制表示形式。

请你返回该链表所表示数字的 **十进制值** 。

**最高位** 在链表的头部。

**示例 1：**

![](https://assets.leetcode.cn/aliyun-lc-upload/uploads/2019/12/15/graph-1.png)

**输入：**head = [1,0,1]
**输出：**5
**解释：**二进制数 (101) 转化为十进制数 (5)

**示例 2：**

**输入：**head = [0]
**输出：**0

**提示：**

- 链表不为空。
- 链表的结点总数不超过 `30`。
- 每个结点的值不是 `0` 就是 `1`。

---

## 破局眼 🎯

> **边遍历边转换：`res = res * 2 + val`。最高位在头部，正好从高位开始构建，无需反转也无需知道长度。**

你的两个方案都能 work，但其实有一个更简单的——**一边走一边算**，类似二进制字符串转整数的 `int(s, 2)`。

### 解法一：直接遍历（最优）

```python
def getDecimalValue(self, head: ListNode) -> int:
    res = 0
    while head:
        res = res * 2 + head.val   # 等价于 res = (res << 1) | head.val
        head = head.next
    return res
```

**原理：** 遍历 `[1,0,1]` 的过程：
```
res = 0
→ 0*2 + 1 = 1
→ 1*2 + 0 = 2
→ 2*2 + 1 = 5 ✅
```

就是 Horner 求值法，也是 `int("101", 2)` 的手算过程。

### 解法二：先算长度（你的思路）

```python
def getDecimalValue(self, head: ListNode) -> int:
    n, cur = 0, head
    while cur:
        n += 1
        cur = cur.next
    
    res = 0
    cur = head
    while cur:
        n -= 1
        if cur.val == 1:
            res += 1 << n   # 2^n
        cur = cur.next
    return res
```

### 解法三：反转链表（你的思路）

```python
def getDecimalValue(self, head: ListNode) -> int:
    # 反转链表
    prev, cur = None, head
    while cur:
        nxt = cur.next
        cur.next = prev
        prev = cur
        cur = nxt
    
    res, power = 0, 1
    while prev:
        if prev.val == 1:
            res += power
        power <<= 1
        prev = prev.next
    return res
```

### 三种对比

| 方法         | 思路                  | 代码量 | 额外空间 |
| ---------- | ------------------- | --- | ---- |
| ✅ **直接遍历** | `res = res*2 + val` | 3 行 | O(1) |
| 先算长度       | 扫两次，按位加 2ⁿ          | 略多  | O(1) |
| 反转链表       | 反转 + 从低位构建          | 最多  | O(1) |

> **直接遍历是最简洁的，数据范围 n ≤ 30 所以位运算不容易溢出。**

## 什么性质的题可以用这个解法？

本题本质是 **"线性结构上的进制转换"** 模式。

| 性质                  | 本题体现    | 反例             |
| ------------------- | ------- | -------------- |
| **二进制表示，高位优先**      | 头节点是最高位 | 低位优先 → 直接遍历即可  |
| **线性结构（链表/数组/字符串）** | 单链表     | 树结构 → DFS      |
| **n 足够小（≤ 30）**     | 不会溢出    | n > 60 → 需大数处理 |

**判断流程：**

```
二进制表示转十进制？
  ├── 数据结构是？
  │     ├── 数组/字符串 → 直接 int(s, 2) 或遍历
  │     ├── 链表（高位在头） → ✅ 遍历 + res = res*2 + val
  │     └── 链表（低位在头） → 遍历 + 累加 2^i
  └── n 的范围？
        ├── 小 → 整数运算足够
        └── 大 → 考虑大数或取模
```
