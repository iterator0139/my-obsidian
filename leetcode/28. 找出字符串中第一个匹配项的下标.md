给你两个字符串 `haystack` 和 `needle`，请你在 `haystack` 字符串中找出 `needle` 字符串的第一个匹配项的下标（下标从 0 开始）。如果 `needle` 不是 `haystack` 的一部分，则返回 `-1`。

**示例 1：**

```
输入：haystack = "sadbutsad", needle = "sad"
输出：0
解释："sad" 在下标 0 和 6 处匹配。第一个匹配项的下标是 0 ，因此返回 0 。
```

**示例 2：**

```
输入：haystack = "leetcode", needle = "leeto"
输出：-1
解释："leeto" 没有在 "leetcode" 中出现，所以返回 -1 。
```

**提示：**

- `1 <= haystack.length, needle.length <= 10^4`
- `haystack` 和 `needle` 仅由小写英文字符组成

---

## 五分钟读题法分析

### 第一步：分析性质

#### 识别信号

> **在文本串里找模式串第一次出现的位置 → 子串匹配；暴力枚举起点 + 逐字符比对，或 KMP 利用已匹配信息跳过无效回退。**

#### 题目性质

- **数据规模**：长度 ≤ 10⁴，暴力 O(nm) 最坏 10⁸，边界可过；KMP O(n+m) 更稳
- **数据结构**：两个字符串
- **目标类型**：找第一个匹配下标（存在性 + 位置）
- **范围约束**：连续子串匹配，不是子序列
- **操作特征**：匹配失败时能否少回退 → KMP 的核心

#### 性质 → 方法

| 性质 | 本题体现 | 若不满足则… |
|------|---------|------------|
| 连续子串匹配 | needle 必须连续出现在 haystack | 子序列 → DP / 双指针 |
| 求第一次出现 | 找到即返回 | 求所有出现 → 继续扫 |
| n,m ≤ 10⁴ | 暴力可过 | 更大数据 → 必须 KMP |
| 匹配有前缀重复 | `aabaaab` 类模式 | 无重复 → 暴力也够 |

**判断流程**：

```
在 s 中找 p 第一次出现？
  ├── 面试要最优 / 数据更大 → ✅ KMP O(n+m)
  ├── 实现简单、能通过 → 暴力枚举起点 + 比对
  └── 不要求连续 → 子序列 DP，不是本题
```

#### 方法约束

- **约束**：KMP 有效，需要「当前缀后缀有重叠时，匹配失败不必从头比」
- **本题**：满足。经典子串匹配模板题
- **易混淆**：
  - **不是**滑动窗口：窗口内容是动态的，本题是固定模式串对齐
  - **不是**对撞双指针：不从两端夹逼
  - LC 459 重复子串、LC 1071 公因子串：用 KMP 的 next 数组性质，不是找位置

### 第二步：读题与盲猜

**题目核心**：返回 `needle` 在 `haystack` 中第一次出现的起始下标，不存在返回 -1。

**第一直觉**：枚举 `haystack` 每个起点 `i`，检查 `haystack[i:i+len(needle)]` 是否等于 `needle`。O(n×m)。

**盲猜优化方向**：

- **数据结构**：KMP 的 `next`（或 `lps`）数组
- **时间复杂度**：O(n + m)
- **关键洞察**：匹配到某处失败时，利用「已匹配前缀 = 模式串某后缀」跳回 `next[j-1]`，文本指针 `i` 不回退

---

### 第三步：最优解法

#### 核心转换

```
子串匹配
  ⇔ 用指针 i 扫文本、j 扫模式
  ⇔ j 回退由 next[j-1] 决定，而不是 i 回退
```

#### 状态定义

- `next[k]`：模式串 `needle[0..k]` 的 **最长相等真前后缀** 长度
- 匹配时：`i` 指 haystack，`j` 指 needle；`needle[j] == haystack[i]` 则双进，否则 `j = next[j-1]`

#### 核心状态转移（破局眼）

**构建 next（模式串自匹配）**：

```python
j = 0
for i in range(1, m):
    while j > 0 and needle[i] != needle[j]:
        j = next[j - 1]
    if needle[i] == needle[j]:
        j += 1
    next[i] = j
```

**主匹配**：

```python
j = 0
for i in range(n):
    while j > 0 and haystack[i] != needle[j]:
        j = next[j - 1]
    if haystack[i] == needle[j]:
        j += 1
    if j == m:
        return i - m + 1
return -1
```

#### 关键实现细节

- **next 数组长度**：`m`，`next[i]` 对应前缀 `needle[0..i]`
- **为什么 i 不回退？** 已匹配段等价于把模式串「滑动」到 next 位置，文本侧不丢信息
- **找到时**：`j == m` 表示完整匹配，`起始下标 = i - m + 1`
- **暴力写法**：面试可先写，再提 KMP；Python 里 `haystack.find(needle)` 不能当面试答案

### 核心代码（Python）

#### 解法一：暴力（能通过）

```python
def strStr(haystack: str, needle: str) -> int:
    n, m = len(haystack), len(needle)
    if m == 0:
        return 0
    for i in range(n - m + 1):
        if haystack[i : i + m] == needle:
            return i
    return -1
```

#### 解法二：KMP（推荐记忆）

```python
def strStr(haystack: str, needle: str) -> int:
    if not needle:
        return 0
    m = len(needle)
    next_arr = [0] * m

    j = 0
    for i in range(1, m):
        while j > 0 and needle[i] != needle[j]:
            j = next_arr[j - 1]
        if needle[i] == needle[j]:
            j += 1
        next_arr[i] = j

    j = 0
    for i in range(len(haystack)):
        while j > 0 and haystack[i] != needle[j]:
            j = next_arr[j - 1]
        if haystack[i] == needle[j]:
            j += 1
        if j == m:
            return i - m + 1
    return -1
```

### 第四步：拆解记忆点

#### 一句话破局眼

> **LeetCode 28 找出第一个匹配项下标：暴力枚举起点；KMP 用 next 数组让 j 回退、i 永不回退。**

#### 复杂度对比

| 方法 | 时间 | 空间 | 适用性 |
|------|------|------|--------|
| 暴力枚举 + 切片比对 | O(n×m) | O(1) | n,m≤10⁴ 可过 |
| KMP | O(n+m) | O(m) | ✅ 标准最优 |
| `haystack.find` | 内置 | — | 非面试写法 |

#### 关键理解点

1. **next[i] 是什么？** `needle[0..i]` 的最长相等真前后缀长度；匹配失败时 j 跳到 `next[j-1]`。
2. **为什么不是双指针夹逼？** 本题是模式对齐，不是有序数组求和；「双指针」仅体现在 i、j 同向扫描。
3. **构建 next 和主匹配代码几乎一样**：把 `haystack` 换成 `needle[i]` vs `needle[j]` 就是在算 next。
4. **和 LC 26/27 的区别**：26/27 是读写分区；28 是字符串匹配，优化靠前缀函数不是慢指针写回。
