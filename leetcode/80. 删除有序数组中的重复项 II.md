给你一个有序数组 `nums`，请你 **原地** 删除重复出现的元素，使得出现次数 **超过两次** 的元素只出现 **两次**，返回删除后数组的新长度。

元素的 **相对顺序** 应该保持一致。

考虑 `nums` 的长度为 `n`，你需要做以下事情：

- 如果数组中有任何元素出现 **超过两次**，那么你修复前 `n` 个元素应该包含最终被放在数组中的元素。下标 `≥ n` 的其余下标（`nums` 的容量）可以保持任何内容。
- 不用理会数组后面那些可能存在的元素。
- 你不需要考虑数组超出新长度后面的元素。

**示例 1：**

```
输入：nums = [1,1,1,2,2,3]
输出：5, nums = [1,1,2,2,3]
解释：函数应返回新长度 5 ，并且原数组的前五个元素被修改为 1, 1, 2, 2, 3 。不需要考虑数组中超出新长度后面的元素。
```

**示例 2：**

```
输入：nums = [0,0,1,1,1,1,2,3,3]
输出：7, nums = [0,0,1,1,2,3,3]
```

**提示：**

- `1 <= nums.length <= 3 * 10^4`
- `-10^4 <= nums[i] <= 10^4`
- `nums` 已按 **升序** 排列

## 五分钟读题法分析

### 第一步：分析性质

#### 识别信号

> **有序数组原地删重，每个值最多留 2 个 → LC 26 的升级版，快扫慢写，写入前和 `nums[slow-2]` 比。**

#### 题目性质

- **数据规模**：n ≤ 3×10⁴，O(n) 一趟足够
- **数据结构**：有序数组
- **目标类型**：原地修改 + 返回新长度
- **范围约束**：保序；前 k 位正确即可
- **单调性**：有序 → 重复相邻；同一值第 3 次出现时，`nums[fast] == nums[slow-1] == nums[slow-2]`

#### 性质 → 方法

| 性质 | 本题体现 | 若不满足则… |
|------|---------|------------|
| 数组有序 | 重复值相邻 | 无序 → 哈希 / 排序 |
| 原地修改 | 快扫慢写 | 可开新数组 → 直接计数写入 |
| 每值最多 k 次 | k=2 | k=1 → LC 26；通用 k → 和 `nums[slow-k]` 比 |
| 保序 | 慢指针顺序写 | 不要求顺序 → 可 swap |

**判断流程**：

```
有序数组 + 原地删重，每值最多出现 m 次？
  ├── m=1 → LC 26：nums[fast] != nums[slow]
  ├── m=2 → ✅ LC 80：nums[fast] != nums[slow-2]（slow≥2）
  └── 通用 m → slow < m 或 nums[fast] != nums[slow-m]
```

#### 方法约束

- **约束**：读写双指针 + 有序相邻重复，慢指针区始终是合法前缀
- **本题**：满足。判断是否可写入时，看「已写入区倒数第 2 个」是否与当前值相同
- **易混淆**：
  - LC 26：和 `nums[slow]` 比（末尾唯一代表）
  - **本题**：和 `nums[slow-2]` 比（末尾两个代表，第三个相同则拒绝）

### 第二步：读题与盲猜

**题目核心**：有序数组原地处理，每个数最多出现 2 次，返回新长度。

**第一直觉**：用哈希表计数，再扫一遍按计数写入。O(n) 但 O(n) 空间。

**盲猜优化方向**：

- **数据结构**：同向双指针（快扫慢写）
- **时间复杂度**：O(n)
- **关键洞察**：有序 → 同一值的重复连在一起；慢指针区末尾最多 2 个相同，若 `nums[fast] == nums[slow-2]` 说明要写第 3 个，跳过

### 第三步：最优解法

#### 核心转换

```
每值最多 2 次
  ⇔ 写入 nums[fast] 时，不能与「已写入区最后两个」都相同
  ⇔ slow < 2 直接写；否则要求 nums[fast] != nums[slow-2]
```

#### 状态定义

- `slow`：下一个写入位置（也是当前保留区长度）
- `fast`：扫描指针

#### 核心状态转移（破局眼）

```python
if slow < 2 or nums[fast] != nums[slow - 2]:
    nums[slow] = nums[fast]
    slow += 1
```

#### 关键实现细节

- **前两位直接保留**：`slow < 2` 时无需比较（不可能出现 3 个相同）
- **为什么和 slow-2 比？** 写入后 `nums[slow-2], nums[slow-1]` 是末尾两个；若 `nums[fast]` 与 `nums[slow-2]` 相同，且有序，则三者相同 → 第 3 个重复
- **和 LC 26 对照**：

| | LC 26（留 1 个） | LC 80（留 2 个） |
|--|----------------|----------------|
| 写入条件 | `nums[fast] != nums[slow]` | `nums[fast] != nums[slow-2]` |
| slow 含义 | 已写入区 **末尾** | 下一 **写入位** |

两种 slow 语义不同，但 80 的写法更统一（slow 始终=写入位）。

- **示例走一遍**：`[1,1,1,2,2,3]`
  - fast=0,1：slow<2，写入 → `[1,1,...]`
  - fast=2：`nums[2]=1 == nums[slow-2]=nums[0]=1`，跳过
  - fast=3,4,5：依次写入 2,2,3 → 长度 5

### 核心代码（Python）

```python
def removeDuplicates(nums: list[int]) -> int:
    slow = 0
    for fast in range(len(nums)):
        if slow < 2 or nums[fast] != nums[slow - 2]:
            nums[slow] = nums[fast]
            slow += 1
    return slow
```

#### 通用模板（每值最多 k 次）

```python
def removeDuplicatesK(nums: list[int], k: int) -> int:
    slow = 0
    for fast in range(len(nums)):
        if slow < k or nums[fast] != nums[slow - k]:
            nums[slow] = nums[fast]
            slow += 1
    return slow
```

LC 80 即 `k=2`。

### 第四步：拆解记忆点

#### 一句话破局眼

> **LeetCode 80 删除有序数组重复项 II：快扫慢写，和 nums[slow-2] 不同才写入（前两位直接写）。**

#### 复杂度对比

| 方法 | 时间 | 空间 | 适用性 |
|------|------|------|--------|
| 哈希计数再写回 | O(n) | O(n) | 不要求 O(1) |
| 快扫慢写 | O(n) | O(1) | ✅ 最优 |

#### 关键理解点

1. **为什么是 slow-2 不是 slow-1？** slow-1 是上一个写入，相同值第 2 次应保留；和 slow-1 比会误杀合法的第 2 个。
2. **slow < 2 的作用？** 避免 slow-2 下标越界，同时前两位无论如何都合法。
3. **和 26 怎么记？** 26 看「末尾 1 个」；80 看「末尾 2 个」→ 比较位置差 1（slow vs slow-2）。
4. **推广**：最多 k 个 → 和 `nums[slow-k]` 比。
