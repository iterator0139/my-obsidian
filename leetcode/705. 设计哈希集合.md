不使用任何内建的哈希表库设计一个哈希集合（HashSet）。

实现 `MyHashSet` 类：

- `MyHashSet()` 初始化一个空的集合
- `void add(int key)` 向集合中插入值 `key`
- `void remove(int key)` 从集合中移除值 `key`
- `bool contains(int key)` 如果集合中包含 `key`，则返回 `true`；否则返回 `false`

**示例：**

**输入：**
`["MyHashSet", "add", "add", "contains", "contains", "add", "remove", "contains"]`
`[[], [1], [2], [1], [3], [2], [2], [2]]`

**输出：**
`[null, null, null, true, false, null, null, false]`

**解释：**
```
MyHashSet myHashSet = new MyHashSet();
myHashSet.add(1);
myHashSet.add(2);
myHashSet.contains(1); // 返回 True
myHashSet.contains(3); // 返回 False
myHashSet.add(2);
myHashSet.remove(2);
myHashSet.contains(2); // 返回 False
```

**提示：**

- `0 <= key <= 10^6`
- 最多调用 `10^4` 次 `add`、`remove` 和 `contains`

## 五分钟读题法分析

### 第一步：分析性质

#### 识别信号

> **实现 O(1) 的增删查 → 哈希表；key 范围有界时可直达数组，否则桶 + 拉链法处理冲突。**

#### 题目性质

- **数据规模**：最多 10⁴ 次操作，每次均摊 O(1) 即可
- **数据结构**：设计题，实现 Set 语义（无重复、O(1) 查存在）
- **目标类型**：模拟 / 设计数据结构
- **key 范围**：`0 <= key <= 10^6`，**有界且不大**——这是选实现的关键
- **操作特征**：add / remove / contains，不要求有序、不要求遍历

#### 性质 → 方法

| 性质         | 本题体现      | 若不满足则…                     |
| ---------- | --------- | -------------------------- |
| 需 O(1) 增删查 | Set 三操作   | 有序 → 平衡树 O(log n)          |
| key 范围小且有界 | 0 ~ 10⁶   | 范围极大 / 字符串 key → 真·哈希 + 拉链 |
| 不允许用内建哈希库  | 自己实现桶结构   | 面试常考拉链法                    |
| 元素唯一       | add 重复无效果 | 需计数 → HashMap              |

**判断流程**：

```
实现 Set，O(1) 增删查？
  ├── key 范围有界且可接受 O(max_key) 空间？
  │     ├── 是 → ✅ 布尔数组直接寻址（本题捷径）
  │     └── 否 → 桶数组 + 哈希函数 + 冲突处理
  │               ├── 拉链法（链表挂桶）→ ✅ 通用写法
  │               └── 开放寻址（线性探测等）
  └── 否 → 其他结构
```

#### 方法约束

- **约束**：哈希函数应均匀分散；桶数量与操作数同量级（如 10⁴ 次调用 → 桶 ~10³–10⁴）可保证均摊 O(1)
- **本题**：两种写法都过——布尔数组利用 key 上界；拉链法展示「设计」能力
- **易混淆**：这是 **Set**（只存存在性），不是 HashMap（存 key-value）

### 第二步：读题与盲猜

**题目核心**：不用内建哈希库，实现支持 add / remove / contains 的集合。

**第一直觉**：`list` 存所有 key，contains 线性扫——10⁴ 次操作最坏 O(10⁸)，可能卡边界。

**盲猜优化方向**：

- **数据结构**：桶数组 + 链表（拉链法），或 `key` 范围固定时用布尔数组
- **时间复杂度**：均摊 O(1)
- **关键洞察**：`hash(key) = key % bucket_size` 定位桶；冲突用链表挂在桶上

---

### 第三步：最优解法

#### 核心转换

HashSet 底层 = **桶数组** + **哈希函数** + **冲突处理**。

```
add(key):      bucket = key % SIZE → 若桶中无 key 则插入
remove(key):   bucket = key % SIZE → 从桶链表删除 key
contains(key): bucket = key % SIZE → 在桶链表中查找 key
```

#### 写法 A：拉链法（通用设计，面试主推）

**状态定义**

- `buckets`：长度为 `SIZE` 的数组，每个元素是该桶的 key 列表（或链表）
- `SIZE`：桶数量，取质数或 `10^4` 量级，减少冲突

**核心状态转移（破局眼）**

```
index = key % SIZE
add:      if key not in buckets[index]: append
remove:   if key in buckets[index]: remove
contains: return key in buckets[index]
```

#### 写法 B：布尔数组（利用 key ∈ [0, 10⁶]）

**破局眼**：key 本身就是下标，O(1) 直达，无需哈希函数。

```
data = [False] * (10^6 + 1)
add:      data[key] = True
remove:   data[key] = False
contains: return data[key]
```

空间 O(10⁶) ≈ 1MB 布尔值，本题完全可接受；若 key 是字符串或范围极大，必须用写法 A。

#### 关键实现细节

- **桶大小**：建议 `SIZE = 10007`（质数）或 `1000~10000`，与 10⁴ 次操作匹配
- **add 去重**：插入前先 contains，避免链表重复
- **remove 安全**：不存在时静默返回，不报错
- **拉链 vs 开放寻址**：拉链实现简单、删除容易；开放寻址缓存友好但删除需标记

### 核心代码（Python）

**写法 A：拉链法**

```python
class MyHashSet:
    def __init__(self):
        self.size = 10007
        self.buckets = [[] for _ in range(self.size)]

    def _index(self, key: int) -> int:
        return key % self.size

    def add(self, key: int) -> None:
        idx = self._index(key)
        if key not in self.buckets[idx]:
            self.buckets[idx].append(key)

    def remove(self, key: int) -> None:
        idx = self._index(key)
        bucket = self.buckets[idx]
        if key in bucket:
            bucket.remove(key)

    def contains(self, key: int) -> bool:
        return key in self.buckets[self._index(key)]
```

**写法 B：布尔数组（本题捷径）**

```python
class MyHashSet:
    def __init__(self):
        self.data = [False] * 1_000_001

    def add(self, key: int) -> None:
        self.data[key] = True

    def remove(self, key: int) -> None:
        self.data[key] = False

    def contains(self, key: int) -> bool:
        return self.data[key]
```

| 方法 | add | remove | contains | 空间 | 适用性 |

3. **何时用布尔数组？** key 范围有界且空间可接受——本题 `0~10^6` 正好
