给定一个含有 `n` 个正整数的数组和一个正整数 `target`。

找出该数组中满足其总和 **大于等于** `target` 的长度最小的 **连续子数组** `[nums_l, nums_l+1, ..., nums_r-1, nums_r]`，并返回其长度。如果不存在符合条件的子数组，返回 `0`。

**示例 1：**

```
输入：target = 7, nums = [2,3,1,2,4,3]
输出：2
解释：子数组 [4,3] 是该条件下的长度最小的子数组。
```

**示例 2：**

```
输入：target = 4, nums = [1,4,4]
输出：1
```

**示例 3：**

```
输入：target = 11, nums = [1,1,1,1,1,1,1,1]
输出：0
```

**提示：**

- `1 <= target <= 10^9`
- `1 <= nums.length <= 10^5`
- `1 <= nums[i] <= 10^4`

**进阶：** 如果你已经实现 O(n) 时间复杂度的解法，请尝试设计一个在 O(n log n) 时间复杂度内解决本题的方法。

## 五分钟读题法分析

### 第一步：分析性质

#### 识别信号

> **求连续子数组最短长度，约束是窗口和 ≥ target——正整数数组上扩窗和变大、缩窗和变小，满足后缩左窗找更短。**

#### 题目性质

- **数据规模**：n ≤ 10⁵，暴力 O(n²) 会 TLE
- **数据结构**：正整数数组（**全是正数**是关键）
- **目标类型**：最短连续子数组（最值 + **连续**）
- **范围约束**：子数组和 ≥ target
- **单调性**：扩右 → 和增大；缩左（正整数）→ 和减小

#### 性质 → 方法

| 性质 | 本题体现 | 若不满足则… |
|------|---------|------------|
| 连续子数组 | 必须是一段 | 不连续 → DP / 其他 |
| 目标和约束 | sum ≥ target | 等于 target → 类似，缩窗逻辑相同 |
| **元素全为正** | 缩左后和严格减小 | 有负数 → 缩窗可能失效，要前缀和+二分或 DP |
| 求 **最短** | 满足后尽量缩左 | 求最长且 ≤ target → 扩窗为主（如 1004） |

**判断流程**：

```
求连续子数组，和 ≥ target，要最短长度？
  ├── 元素全为正？
  │     └── ✅ 滑动窗口：扩右累加，sum≥target 时缩左更新最小长度
  ├── 有负数？
  │     └── 前缀和 + 二分 / 线段树，不是纯滑窗
  └── 不要求连续？
        └── 子序列 → DP
```

#### 方法约束

- **约束**：滑窗求 **最短** 需要「缩左后仍可能满足 / 不满足有单调性」——正整数保证缩左和递减
- **本题**：满足
- **易混淆**：
  - LC 1004 / 3：求 **最长**，窗口合法时扩右，不合法时缩左
  - **本题**：求 **最短**，先扩到合法（sum ≥ target），再 **尽量缩左** 看能否更短
  - LC 560 和为 K：不要求连续，用前缀和 + 哈希，不是滑窗

### 第二步：读题与盲猜

**题目核心**：找和 ≥ target 的最短连续子数组，没有则返回 0。

**第一直觉**：枚举所有子数组 `[i,j]`，求和比较。O(n²)，10⁵ 会 TLE。

**盲猜优化方向**：

- **数据结构**：滑动窗口（左右指针）+ 窗口和
- **时间复杂度**：O(n)（每个元素最多进出窗口各一次）
- **关键洞察**：全正数 → 扩右只会让和变大，一旦 sum ≥ target，缩左不会漏掉更短解（缩左后和变小，但我们在缩左 **过程中** 每一步都更新答案）

---

### 第三步：最优解法

#### 核心转换

```
最短、和 ≥ target 的连续子数组
  ⇔ 右指针扩窗累加，sum ≥ target 时记录长度并缩左
```

#### 状态定义

- `left`：窗口左边界
- `right`：窗口右边界（for 循环）
- `window_sum`：当前窗口元素和
- `res`：目前为止的最短长度，初值 `inf`

#### 核心状态转移（破局眼）

```python
window_sum += nums[right]
while window_sum >= target:
    res = min(res, right - left + 1)
    window_sum -= nums[left]
    left += 1
```

#### 关键实现细节

- **先扩右再 while 缩左**：右指针每次右移后，尽可能收缩左边界
- **为什么全正数很重要？** 缩左后 `window_sum` 减小，若仍 ≥ target 可继续缩；若 < target 则停，等下次扩右——不会漏解
- **无解**：`res` 仍为 `inf` 时返回 0
- **与 1004 对比**：

| | LC 1004 最长 | LC 209 最短 |
|--|-------------|-------------|
| 目标 | 最长合法窗 | 最短合法窗 |
| 合法条件 | 0 的个数 ≤ k | 和 ≥ target |
| 主循环 | 扩右；不合法则缩左 | 扩右；合法则 while 缩左 |

### 核心代码（Python）

```python
def minSubArrayLen(target: int, nums: list[int]) -> int:
    left = 0
    window_sum = 0
    res = float("inf")

    for right in range(len(nums)):
        window_sum += nums[right]
        while window_sum >= target:
            res = min(res, right - left + 1)
            window_sum -= nums[left]
            left += 1

    return 0 if res == float("inf") else res
```

#### 进阶：前缀和 + 二分 O(n log n)

全正数时，前缀和单调递增，对每个右端点 `right`，二分找最左 `left` 使 `prefix[right+1] - prefix[left] >= target`。面试主答滑窗即可。

### 第四步：拆解记忆点

#### 一句话破局眼

> **LeetCode 209 长度最小的子数组：正整数滑窗，扩右累加，和 ≥ target 就缩左更新最短。**

#### 复杂度对比

| 方法 | 时间 | 空间 | 适用性 |
|------|------|------|--------|
| 暴力枚举子数组 | O(n²) | O(1) | n≤10⁴ 勉强 |
| 滑动窗口 | O(n) | O(1) | ✅ 最优（全正数前提） |
| 前缀和 + 二分 | O(n log n) | O(n) | 进阶写法 |

#### 关键理解点

1. **为什么是 while 缩左，不是 if？** `[2,3,1,2,4,3], target=7`：窗口 `[2,3,1,2]` 和=8≥7，缩掉 2 后 `[3,1,2]` 和=6<7，但 `[3,1,2,4]` 扩右后和=10，while 会连续缩到 `[4,3]` 得长度 2。
2. **全正数能去掉吗？** 不能。有负数时缩左可能让和反而变大，滑窗求最短失效。
3. **和 1004 怎么记？** 1004 求最长：不合法才缩；209 求最短：合法就尽量缩。
4. **返回值 0**：任何单元素或子数组和都 < target 时（如全 1、target=11）。
