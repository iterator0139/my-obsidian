给你一个整数数组 `arr` 和一个整数 `k` 。现需要从数组中恰好移除 `k` 个元素，请找出移除后数组中不同整数的最少数目。

**示例 1：**

**输入：**arr = [5,5,4], k = 1
**输出：**1
**解释：**移除 1 个 4 ，数组中只剩下 5 一种整数。

**示例 2：**

**输入：**arr = [4,3,1,1,3,3,2], k = 3
**输出：**2
**解释：**先移除 4、2 ，然后再移除两个 1 中的任意 1 个或者三个 3 中的任意 1 个，最后剩下 1 和 3 两种整数。

**提示：**

- `1 <= arr.length <= 10^5`
- `1 <= arr[i] <= 10^9`
- `0 <= k <= arr.length`

---

## 破局眼 🎯

> **统计频率 → 按频率升序排序 → 从频率最小的数字开始"整组移除"。贪心：要最小化剩余种类，先干掉出现次数最少的数。**

**为什么贪心成立：** 消灭一个数字必须移除它的所有出现次数。用最少移除次数消灭最多种类 → 优先移除频率最小的。

## 代码

```python
def findLeastNumOfUniqueInts(self, arr: List[int], k: int) -> int:
    freq = Counter(arr)
    sorted_freq = sorted(freq.values())

    for i, f in enumerate(sorted_freq):
        if k >= f:
            k -= f
        else:
            return len(sorted_freq) - i   # 剩下的都是保留的
    return 0
```

### `Counter` 用法

`Counter` 是 `collections` 模块的计数器，专门用来统计可哈希对象出现次数。

```python
from collections import Counter

arr = [4, 3, 1, 1, 3, 3, 2]

freq = Counter(arr)          # Counter({3: 3, 1: 2, 4: 1, 2: 1})
freq[3]                      # 3
freq[99]                     # 0（不存在的 key 返回 0，不会报错）

# 常用方法
freq.keys()                  # dict_keys([4, 3, 1, 2])
freq.values()                # dict_values([1, 3, 2, 1])
freq.most_common()           # [(3,3), (1,2), (4,1), (2,1)] 按频率降序
freq.most_common(2)          # [(3,3), (1,2)] 前 2 个
```

### `sorted` 用法

`sorted(iterable, key=None, reverse=False)` — 对任何可迭代对象排序，**返回新列表**（不修改原对象）。

```python
# 基础
sorted([3, 1, 2])                        # [1, 2, 3]
sorted([3, 1, 2], reverse=True)          # [3, 2, 1]

# 按 key 函数排序
sorted([-3, -1, 2], key=abs)             # [-1, 2, -3]（按绝对值排）

# 对字典的值排序
freq = Counter([4,3,1,1,3,3,2])          # {4:1, 3:3, 1:2, 2:1}
sorted(freq)                             # [1, 2, 3, 4]（默认对 key 排）
sorted(freq.values())                    # [1, 1, 2, 3]（对 value 排）
sorted(freq, key=freq.get)               # [4, 2, 1, 3]（按 value 排 key）

# enumerate + sorted 常用组合
for i, f in enumerate(sorted(freq.values())):
    print(i, f)
```

> ⚠️ 区分 `sorted()` vs `list.sort()`：`sorted()` 返回新列表，`list.sort()` 原地修改、返回 `None`。

## 什么性质的题可以用这个解法？

本题本质是 **"贪心 + 频率统计 → 优先处理最小代价项"** 模式。

### 必要条件

| 性质 | 本题体现 | 反例（不能用） |
|------|---------|-------------|
| **消除一个元素的代价是其出现次数** | 要删除某数字必须删完所有 | 删除单个元素独立计费 → 随便删 |
| **目标是最小化剩余种类** | 求最少不同整数 | 无法量化目标 → 不是贪心 |
| **各元素无依赖关系** | 移除 4 不影响 3 的频率 | 移除影响其他项的频率 → 需动态调整 |
| **贪心选择性质成立** | 先移除频率最小的必定最优 | 局部最优不等于全局最优 → 需 DP |

### 贪心成立的两大条件

```
1️⃣ 最优子结构：子问题（k' = k - freq，剩余数字）的最优解 → 原问题最优解
2️⃣ 贪心选择性质：每次选择频率最小的数字移除 → 最终结果最优

本题两者都满足 ✅
```

### 判断流程

```
目标是最小化/最大化某类计数？
  ├── 每个元素有"代价"和"收益"？
  │     ├── 是 → 考虑贪心
  │     │     ├── 代价与收益独立 → ✅ 按"性价比"排序
  │     │     └── 有依赖关系 → DP
  │     └── 否 → 考虑其他方法
  └── 能否通过频率/计数来排序？
        ├── 能 → ✅ Counter + 排序 + 贪心
        └── 不能 → 考虑其他数据结构
```
