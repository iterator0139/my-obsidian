hashset的思路是，把所有数字变成快速查找的set，然后对每个item，判断是不是序列起点，如果是的话就开始查找后面的元素，直到无法扩展，然后更新全局最大值吗






```
def quick_select(nums: List[int], left: int, right: int):
	if left > right:
		return
	n = len(nums)
	pivot = random(n)
	
	# 放在最右边，就是读写指针交换
	nums[right], nums[pivot] = nums[pivot], nums[right]
	
	left = 0 # left是下一个小于nums[pivot]的位置
	right = 0
	
	for right in range(left, right+1):
		if nums[right] < pivot:
			nums[left], nums[right] = nums[right], nums[left]
			left += 1
	nums[left], nums[right] = nums[right], nums[left]
	quick_select(nums, , pivot -1)
	quick_select(nums, pivot+1,right)
	return left
	
```
