给你个整数数组 `arr`，其中每个元素都 **不相同**。

请你找到所有具有最小绝对差的元素对，并且按升序的顺序返回。

每对元素对 `[a,b`] 如下：

- `a , b` 均为数组 `arr` 中的元素
- `a < b`
- `b - a` 等于 `arr` 中任意两个元素的最小绝对差

**示例 1：**

**输入：**arr = [4,2,1,3]
**输出：**[[1,2],[2,3],[3,4]]

**示例 2：**

**输入：**arr = [1,3,6,10,15]
**输出：**[[1,3]]

**示例 3：**

**输入：**arr = [3,8,-10,23,19,-4,-14,27]
**输出：**[[-14,-10],[19,23],[23,27]]

**提示：**

- `2 <= arr.length <= 10^5`
- `-10^6 <= arr[i] <= 10^6`

---

## 破局眼 🎯

> **排序后，最小绝对差必然出现在相邻元素之间。找最小差，再收集所有满足该差值的相邻对。**

你的思路完全正确——排序后两两相邻计算就行了，不需要两两比较所有组合。

### 代码

```python
def minimumAbsDifference(self, arr: List[int]) -> List[List[int]]:
    arr.sort()
    min_diff = min(arr[i+1] - arr[i] for i in range(len(arr) - 1))

    ans = []
    for i in range(len(arr) - 1):
        if arr[i+1] - arr[i] == min_diff:
            ans.append([arr[i], arr[i+1]])
    return ans
```

**为什么相邻的最小？** 排序后，`|arr[i] - arr[j]|`（j ≥ i+2）一定 ≥ `|arr[i+1] - arr[i]|`，因为中间隔着元素，差距只可能更大。

**注意：** 一次遍历也能同时找最小差和收集结果：

```python
def minimumAbsDifference(self, arr: List[int]) -> List[List[int]]:
    arr.sort()
    min_diff = float('inf')
    ans = []
    for i in range(len(arr) - 1):
        diff = arr[i+1] - arr[i]
        if diff < min_diff:
            min_diff = diff
            ans = [[arr[i], arr[i+1]]]
        elif diff == min_diff:
            ans.append([arr[i], arr[i+1]])
    return ans
```

O(n log n) 时间，O(1) 额外空间（不计输出）。

## 什么性质的题可以用这个解法？

本题本质是 **"排序消除绝对差的位置依赖"** 模式。

### 必要条件

| 性质 | 本题体现 | 反例 |
|------|---------|------|
| **绝对差有三角不等式** | `|a-c| ≤ |a-b| + |b-c|`（排后相邻差最小） | 非欧距离（如编辑距离）→ 不能排序 |
| **数组无序且无位置约束** | 任意两元素都可比较 | 有位置约束（如下标差）→ 不能排序 |
| **元素互异** | 元素不相同 | 有重复 → 差为 0，相邻即答案 |
| **只关心差值大小，不关心位置** | 求最小绝对差 | 求最接近 target → 排序 + 双指针 |

### 判断流程

```
求数组中两元素的最小/最大差值？
  ├── 元素无序且无位置约束？
  │     ├── 是 → ✅ 排序 + 相邻计算
  │     └── 否 → 必须考虑原始位置 → 其他算法
  └── 求最小差还是最接近 target？
        ├── 最小差 → ✅ 排序后相邻
        └── 最接近 target → 排序 + 双指针
```

### 同类题

| 题目                | 目标          | 解法            |
| ----------------- | ----------- | ------------- |
| **LC 1200 最小绝对差** | **所有最小差的对** | **排序 + 相邻**   |
| LC 539 最小时间差      | 时间字符串最小差    | 排序 + 相邻（注意循环） |
| LC 16 最接近的三数之和    | 和最接近 target | 排序 + 双指针      |

> **核心：求差值最值且元素可重排 → 排序永远是第一步。**
