给你一个整数数组 `nums` ，请你找出一个具有最大和的连续子数组（子数组最少包含一个元素），返回其最大和。

**子数组**是数组中的一个连续部分。

**示例 1：**

**输入：**nums = [-2,1,-3,4,-1,2,1,-5,4]
**输出：**6
**解释：**连续子数组 [4,-1,2,1] 的和最大，为 6 。

**示例 2：**

**输入：**nums = [1]
**输出：**1

**示例 3：**

**输入：**nums = [5,4,-1,7,8]
**输出：**23

**提示：**

- `1 <= nums.length <= 105`
- `-104 <= nums[i] <= 104`

**进阶：**如果你已经实现复杂度为 `O(n)` 的解法，尝试使用更为精妙的 **分治法** 求解。


这道题本质是一道dp的题目

状态定义：dp[i]表示以i结尾的连续子数组的最大值
状态转移：对第i个元素来说，有两个选择，一个是脸上前面的数组，另一个是自己新开一个数组。所以 $dp[i] = max(dp[i-1] + nums[i], nums[i])$ 
最后的结果就是 $max(dp[i])$

简化一下的话，就用res维护最大值，cur维护当前窗口值

```
def maxSubarray(nums: List[int]) -> int:
	res = nums[0]
	cur = nums[0]
	
	for i in range(1, len(nums)):
		cur = max(cur + nums[i], nums[i])
		res = max(res, cur)
		
	return res
```
