给你一个整数数组 `coins`，表示不同面额的硬币；以及一个整数 `amount`，表示总金额。

计算并返回可以凑成总金额所需的 **最少的硬币个数**。如果没有任何一种硬币组合能组成总金额，返回 `-1`。

你可以认为每种硬币的数量是无限的。

**示例 1：**

**输入：** coins = [1, 2, 5], amount = 11
**输出：** 3
**解释：** 11 = 5 + 5 + 1

**示例 2：**

**输入：** coins = [2], amount = 3
**输出：** -1

**示例 3：**

**输入：** coins = [1], amount = 0
**输出：** 0

**提示：**

- `1 <= coins.length <= 12`
- `1 <= coins[i] <= 2^31 - 1`
- `0 <= amount <= 10^4`

## 五分钟读题法分析

### 第一步：分析性质

#### 识别信号

> **每种硬币无限枚、凑固定金额、求最少枚数 → 完全背包（unbounded knapsack）最值 DP；也可 BFS 最短路。**

#### 题目性质

- **数据规模**：amount ≤ 10⁴，coins ≤ 12，DP O(amount · |coins|) 可行
- **数据结构**：硬币面额数组 + 目标金额
- **目标类型**：最值（最少硬币数）
- **操作特征**：每种硬币可**无限次**使用
- **背包信号**：物品 = 硬币，重量/价值 = 面额，容量 = amount，求装满的最少物品数

#### 性质 → 方法

| 性质 | 本题体现 | 若不满足则… |
|------|---------|------------|
| 硬币无限用 | 同一面额可重复选 | 每种只能用一次 → 0/1 背包，倒序 |
| 凑固定和 | amount 为目标 | 问方案数 → DP 计数 |
| 求最少枚数 | min 优化 | 问可行性 → bool DP |
| 无顺序要求 | 组合问题 | 排列问题 → 外层循环顺序不同 |

**判断流程**：

```
无限硬币凑 amount，求最少枚数？
  ├── 完全背包 DP → dp[i] = min(dp[i-coin]+1) ✅ 主推
  ├── BFS 层序 → 每扩一层多一枚硬币 ✅ 等价最短路
  └── 贪心 → ❌ 面额无整除关系时会错
```

#### 方法约束

- **约束**：完全背包 **正序** 遍历 amount（同一硬币可重复使用）；`dp[0]=0`，其余初始化为 `inf`
- **本题**：满足
- **易混淆**：和 518「零钱兑换 II」区别——322 求最少枚数（min），518 求方案数（count）；和 494 区别——494 每个数用一次（0/1 背包）

### 第二步：读题与盲猜

**题目核心**：用无限硬币凑出 `amount`，求最少需要几枚。

**第一直觉**：贪心——每次选最大面额。`coins=[1,3,4], amount=6` 贪心得 `4+1+1=3` 枚，最优 `3+3=2` 枚，贪心错。

**盲猜优化方向**：

- **数据结构**：一维 DP 或 BFS 队列
- **时间复杂度**：O(amount · |coins|)
- **关键洞察**：`dp[i]` = 凑出金额 `i` 的最少硬币数；对每个硬币尝试「先用一枚」

---

### 第三步：最优解法

#### 核心转换

```
dp[i] = 凑出金额 i 所需的最少硬币数
dp[0] = 0
dp[i] = min(dp[i - coin] + 1)  对所有 coin ≤ i
答案 = dp[amount]，若仍为 inf 则 -1
```

完全背包：外层遍历硬币，内层 **正序** 遍历 amount（允许同一硬币在同一轮多次贡献）。

#### 状态定义

- `dp[i]`：凑出金额 `i` 的最少硬币个数
- 初始：`dp[0] = 0`，`dp[1..amount] = +∞`

#### 核心状态转移（破局眼）

```
for coin in coins:
    for i from coin to amount:
        dp[i] = min(dp[i], dp[i - coin] + 1)
```

正序：计算 `dp[i]` 时 `dp[i-coin]` 可能本轮已用过该 coin，等价无限次。

#### 写法 B：BFS（最短路视角）

把金额当状态，加一枚硬币 = 走一条边，求 `0 → amount` 最短步数：

```
queue = [0], visited = {0}
while queue:
    for each curr in level:
        for coin in coins:
            nxt = curr + coin
            if nxt == amount: return steps + 1
            if nxt < amount and nxt not in visited: enqueue
```

BFS 和 DP 本质相同，都是最短路；DP 通常更省空间、更好写。

#### 关键实现细节

- **为何不能贪心？** 大面额不一定在最优解里，需全局 min
- **正序 vs 倒序**：完全背包正序；0/1 背包倒序——494/416 是倒序
- **amount = 0**：返回 0，不需硬币
- **无解**：`dp[amount]` 仍为 `inf` → 返回 -1

### 核心代码（Python）

**写法 A：完全背包 DP（推荐）**

```python
def coinChange(coins: list[int], amount: int) -> int:
    dp = [float('inf')] * (amount + 1)
    dp[0] = 0
    for coin in coins:
        for i in range(coin, amount + 1):
            dp[i] = min(dp[i], dp[i - coin] + 1)
    return dp[amount] if dp[amount] != float('inf') else -1
```

**写法 B：BFS**

```python
from collections import deque

def coinChange_bfs(coins: list[int], amount: int) -> int:
    if amount == 0:
        return 0
    q = deque([0])
    visited = {0}
    steps = 0
    while q:
        steps += 1
        for _ in range(len(q)):
            curr = q.popleft()
            for coin in coins:
                nxt = curr + coin
                if nxt == amount:
                    return steps
                if nxt < amount and nxt not in visited:
                    visited.add(nxt)
                    q.append(nxt)
    return -1
```

### 第四步：拆解记忆点

#### 一句话破局眼

> **LeetCode 322 零钱兑换：完全背包最值，dp[i]=min(dp[i-coin]+1)，正序遍历 amount。**

#### 复杂度对比

| 方法 | 时间复杂度 | 空间复杂度 | 适用性 |
|------|-----------|-----------|--------|
| 贪心 | O(n) | O(1) | **会错** |
| **完全背包 DP** | **O(amount · \|coins\|)** | **O(amount)** | **本题最优** |
| BFS | O(amount · \|coins\|) | O(amount) | 直观，等价最短路 |

#### 关键理解点

1. **为什么是完全背包？** 每种硬币无限枚 = 同一物品可重复选 → 内层正序
2. **为什么贪心错？** `6 = 3+3` 优于 `4+1+1`，局部选大面额不保证全局最优
3. **和 518 的区别？** 322 求 min（最值 DP）；518 求方案数（`dp[i] += dp[i-coin]`）
4. **和 494 的区别？** 494 每个数用一次 → 0/1 背包倒序；322 硬币无限 → 完全背包正序
