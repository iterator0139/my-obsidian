给你一个整数数组 `nums`，请你返回该数组中恰有四个因数的这些整数的各因数之和。如果数组中不存在满足题意的整数，则返回 `0` 。

**示例 1：**

**输入：**nums = [21,4,7]
**输出：**32
**解释：**
21 有 4 个因数：1, 3, 7, 21
4 有 3 个因数：1, 2, 4
7 有 2 个因数：1, 7
答案仅为 21 的所有因数的和。

**示例 2:**

**输入:** nums = [21,21]
**输出:** 64

**示例 3:**

**输入:** nums = [1,2,3,4,5]
**输出:** 0

**提示：**

- `1 <= nums.length <= 104`
- `1 <= nums[i] <= 105`

---

## 破局眼 🎯

> **恰有 4 个因数的数只有两种形式：`p³`（质数立方）或 `p × q`（两个不同质数之积）。**

你的思路方向是对的——**拆解因数**，但不用局限在 1-9。核心是找到因数的**质数性质**。

### 数学性质

一个数有且仅有 4 个因数，当且仅当它是以下两种形式之一：

| 形式                | 因数           | 示例                  |
| ----------------- | ------------ | ------------------- |
| **p³**（质数立方）      | 1, p, p², p³ | 8 = 2³ → 1,2,4,8    |
| **p × q**（不同质数乘积） | 1, p, q, pq  | 21 = 3×7 → 1,3,7,21 |

其他情况均不可能恰好 4 个因数：
- 质数（p）→ 只有 2 个因数：1, p
- p² → 3 个因数：1, p, p²
- 合数（有 3 个以上质因子）→ 至少 6 个因数

### 你的优化思路验证

你说"从 1 到 9，只要有一个非质数的因子就可以排除"——这是利用了：

> 如果找到的某个因子是合数（如 4、6、8、9），它必然引入更多质因子 → 因数个数一定超过 4，直接跳过。

比如 12 的因子有 4（合数），同时 2、3 也是因子 → 至少有 1,2,3,4,6,12 六个因数。

但这只是剪枝优化，并不是充分条件（大质因子也会导致 4 因数），最终仍需完整判断。

## 代码

### 解法一：枚举因子计数（通用）

```python
def sumFourDivisors(self, nums: List[int]) -> int:
    total = 0
    for num in nums:
        divisors = set()
        for i in range(1, int(sqrt(num)) + 1):
            if num % i == 0:
                divisors.add(i)
                divisors.add(num // i)
                if len(divisors) > 4:   # 超过 4 个直接放弃
                    break
        if len(divisors) == 4:
            total += sum(divisors)
    return total
```

### 解法二：数学判定（更高效）

```python
def sumFourDivisors(self, nums: List[int]) -> int:
    def is_prime(x: int) -> bool:
        if x < 2: return False
        for i in range(2, int(sqrt(x)) + 1):
            if x % i == 0: return False
        return True

    total = 0
    for num in nums:
        # 情况 1: n = p³
        root = round(num ** (1/3))
        if root ** 3 == num and is_prime(root):
            total += 1 + root + root**2 + root**3
            continue

        # 情况 2: n = p × q（p < q，p ≠ q）
        for p in range(2, int(sqrt(num)) + 1):
            if num % p == 0:
                q = num // p
                if p != q and is_prime(p) and is_prime(q):
                    total += 1 + p + q + num
                break   # 找到一个因子就够了，不管是不是都 break
    return total
```

## 什么性质的题可以用这个解法？

本题本质是 **"因数个数 + 数论性质判定"** 模式。

### 必要条件

| 性质 | 本题体现 | 反例 |
|------|---------|------|
| **条件为数论性质** | 恰有 4 个因数 | 非数论条件 → 其他解法 |
| **可因式分解判定** | 4 因数 = p³ 或 p×q | 条件复杂（如因子和 = n）→ 枚举所有因子 |
| **数据范围有限**（num ≤ 10⁵） | 开方枚举不超 317 | num 极大（10¹²）→ 需素数筛预处理 |
| **各数独立判定** | 每个 num 互不影响 | 结果相互依赖 → 不同解法 |

### 判断流程

```
问题涉及数的"因数/因子"？
  ├── 关心因数的个数还是和？
  │     ├── 个数 → 套因数个数公式（质因数分解）
  │     └── 和 → 套因数和公式
  ├── 数据范围？
  │     ├── 小（n ≤ 10⁵）→ ✅ 开方枚举因子
  │     └── 大（n ≥ 10⁶）→ 预处理筛 + 质因数分解
  └── 有特殊性质可利用？
        ├── 恰有 4 个 → ✅ p³ 或 p×q
        ├── 恰有 3 个 → p²
        ├── 恰有 2 个 → 质数
        └── 无特殊 → 暴力枚举
```

### 因数个数速查

| 因数个数 | 形式 | 示例 |
|---------|------|------|
| 2 | p（质数） | 2,3,5,7 |
| 3 | p² | 4,9,25 |
| **4** | **p³ 或 p×q** | **8,27 / 6,21** |
| 5 | p⁴ | 16,81 |
