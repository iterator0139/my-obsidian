你是一位系统管理员，手里有一份文件夹列表 `folder`，你的任务是要删除该列表中的所有 **子文件夹**，并以 **任意顺序** 返回剩下的文件夹。

如果文件夹 `folder[i]` 位于另一个文件夹 `folder[j]` 下，那么 `folder[i]` 就是 `folder[j]` 的 **子文件夹** 。`folder[j]` 的子文件夹必须以 `folder[j]` 开头，后跟一个 `"/"`。例如，`"/a/b"` 是 `"/a"` 的一个子文件夹，但 `"/b"` 不是 `"/a/b/c"` 的一个子文件夹。

文件夹的「路径」是由一个或多个按以下格式串联形成的字符串：'/' 后跟一个或者多个小写英文字母。

- 例如，`"/leetcode"` 和 `"/leetcode/problems"` 都是有效的路径，而空字符串和 `"/"` 不是。

**示例 1：**

**输入：**folder = ["/a","/a/b","/c/d","/c/d/e","/c/f"]
**输出：**["/a","/c/d","/c/f"]
**解释：**"/a/b" 是 "/a" 的子文件夹，而 "/c/d/e" 是 "/c/d" 的子文件夹。

**示例 2：**

**输入：**folder = ["/a","/a/b/c","/a/b/d"]
**输出：**["/a"]
**解释：**文件夹 "/a/b/c" 和 "/a/b/d" 都会被删除，因为它们都是 "/a" 的子文件夹。

**示例 3：**

**输入:** folder = ["/a/b/c","/a/b/ca","/a/b/d"]
**输出:** ["/a/b/c","/a/b/ca","/a/b/d"]

**提示：**

- `1 <= folder.length <= 4 * 104`
- `2 <= folder[i].length <= 100`
- `folder[i]` 只包含小写字母和 `'/'`
- `folder[i]` 总是以字符 `'/'` 起始
- `folder` 每个元素都是 **唯一** 的

## 破局眼 🎯

> **按字典序排序后，父文件夹紧挨在子文件夹前面。遍历时只需判断当前路径是否以"上一个保留路径 + /"开头。**

你说的前缀树（Trie）确实可以，但**排序后一行判断**是最优雅的解法——利用了字典序天然把父子路径排在一起的性质。

### 解法一：排序 + 前缀判断（最优，推荐）

```python
def removeSubfolders(self, folder: List[str]) -> List[str]:
    folder.sort()
    ans = []
    for path in folder:
        # 如果 ans 非空，且 path 以"上一个保留路径 + /"开头 → 是子文件夹，跳过
        if not ans or not path.startswith(ans[-1] + '/'):
            ans.append(path)
    return ans
```

**为什么排序后用 `ans[-1]` 判断就够了？**

字典序排序后：
```
["/a", "/a/b", "/a/b/c", "/a/b/ca", "/c", "/c/d"]
  ↑父     ↑子       ↑子       ↑不是子（"ca"≠"c/"）  ↑无关  ↑子
```
- `/a/b` 以 `/a/` 开头 → 子文件夹，跳过
- `/a/b/c` 以 `/a/` 开头 → 是 `/a` 的子文件夹（不是 `/a/b` 的，但 `/a` 还在 ans 里）
- `/a/b/ca` 以 `/a/` 开头？→ 检查：`/a/b/ca` 以 `/a/` 开头 → 是 `/a` 的子文件夹！所以 ans 中只需要保留 `/a`，所有以 `/a/` 开头的都是它的后代。

等等，修正一下思路——`ans[-1]` 可以不是直属父文件夹，但只要是**某个祖先**即可。因为当路径以 `ans[-1] + '/'` 开头时，它一定是 `ans[-1]` 的后代；如果不是，那它可能跟 `ans[-1]` 同级或无关，此时它自己就是新的根。

**验证示例 3：**
```
folder = ["/a/b/c","/a/b/ca","/a/b/d"]
排序后不变：
"/a/b/c"  → ans=[] → 加入 → ans=["/a/b/c"]
"/a/b/ca" → 以 "/a/b/c/" 开头？→ "a/b/ca" → 不是，加入 → ans=["/a/b/c","/a/b/ca"]
"/a/b/d"  → 以 "/a/b/ca/" 开头？→ 不是，加入 → ans=["/a/b/c","/a/b/ca","/a/b/d"] ✅
```

### 解法二：哈希集合（较直观）

```python
def removeSubfolders(self, folder: List[str]) -> List[str]:
    s = set(folder)
    ans = []
    for path in folder:
        # 逐级向上检查父路径是否存在
        parent = path
        is_sub = False
        while '/' in parent[1:]:    # 从第二个字符开始找 '/'
            parent = parent[:parent.rfind('/')]
            if parent in s:
                is_sub = True
                break
        if not is_sub:
            ans.append(path)
    return ans
```

### 解法三：前缀树（你的思路）

> 前缀树能解但较繁琐，面试时**排序法是最优选择**。

### 三种对比

| 方法 | 时间 | 空间 | 代码量 | 推荐 |
|------|------|------|-------|------|
| ✅ **排序 + 前缀判断** | O(n log n) | O(1) | 5 行 | ⭐ 最优 |
| 哈希集合 | O(n·L) | O(n) | 10 行 | 可接受 |
| 前缀树（Trie） | O(n·L) | O(n·L) | 20+ 行 | 不推荐 |

> L = 路径最大长度，n = 文件夹数量

## 什么性质的题可以用这个解法？

本题本质是 **"前缀匹配 + 去重/过滤"** 模式。

### 必要条件

| 性质             | 本题体现              | 反例                   |
| -------------- | ----------------- | -------------------- |
| **父子关系通过前缀定义** | `/a/b` 以 `/a/` 开头 | 其他层级关系（如树形 ID）→ 哈希集合 |
| **路径有明确分隔符**   | 以 `/` 分隔          | 无分隔符 → Trie 更合适      |
| **字典序分组父子**    | 排序后父在子前           | 自定义排序规则 → 无法直接利用字典序  |
| **只需保留父文件夹**   | 删除所有子目录           | 需要保留所有层级 → 不同逻辑      |

### 判断流程

```
字符串列表需要按前缀过滤？
  ├── 排序后父路径就在子路径前面？
  │     ├── 是 → ✅ 排序 + startswith 判断（最优）
  │     └── 否 → 能否用哈希集合逐级检查？
  │           ├── 是 → 从短到长检查父前缀是否存在
  │           └── 否 → 用 Trie 构建前缀树
  └── 数据量？
        ├── 小 → 任意方法
        └── 大（> 10⁴）→ 优先排序法 O(n log n)
```
