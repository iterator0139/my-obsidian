给定一个字符串 `s` ，请你找出其中不含有重复字符的 **最长 子串** 的长度。

**示例 1:**

**输入:** s = "abcabcbb"
**输出:** 3 
**解释:** 因为无重复字符的最长子串是 `"abc"`，所以其长度为 3。注意 "bca" 和 "cab" 也是正确答案。

**示例 2:**

**输入:** s = "bbbbb"
**输出:** 1
**解释:** 因为无重复字符的最长子串是 `"b"`，所以其长度为 1。

**示例 3:**

**输入:** s = "pwwkew"
**输出:** 3
**解释:** 因为无重复字符的最长子串是 `"wke"`，所以其长度为 3。
     请注意，你的答案必须是 **子串** 的长度，`"pwke"` 是一个_子序列，_不是子串。

**提示：**

- `0 <= s.length <= 5 * 104`
- `s` 由英文字母、数字、符号和空格组成


采用滑动窗口，
维护每个字符出现的最后一个位置
一旦出现重复的字符，且这个字符在窗口范围内，破坏了无重复字符的约束。需要进行窗口收缩，左边界收缩到重复字符的下一个位置


```

def longestSubstr(s: str) -> int:
	pos = {}
	left, right = 0, 0
	res = 0
	n = len(s)
	for right in range(n):
		# if char exit in window, shrink the window
		char = s[right]
		if char in pos.keys() and pos[char] >= left:
			# update left to the next pos of the repeate char
			left = pos[char] + 1
		pos[char] = right
		res = max(res, right - left + 1)
	return res

```
