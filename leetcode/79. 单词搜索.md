给定一个 `m x n` 二维字符网格 `board` 和一个字符串单词 `word` 。如果 `word` 存在于网格中，返回 `true` ；否则，返回 `false` 。

单词必须按照字母顺序，通过相邻的单元格内的字母构成，其中“相邻”单元格是那些水平相邻或垂直相邻的单元格。同一个单元格内的字母不允许被重复使用。

**示例 1：**

![](https://assets.leetcode.com/uploads/2020/11/04/word2.jpg)

**输入：**board = [['A','B','C','E'],['S','F','C','S'],['A','D','E','E']], word = "ABCCED"
**输出：**true

**示例 2：**

![](https://assets.leetcode.com/uploads/2020/11/04/word-1.jpg)

**输入：**board = [['A','B','C','E'],['S','F','C','S'],['A','D','E','E']], word = "SEE"
**输出：**true

**示例 3：**

![](https://assets.leetcode.com/uploads/2020/10/15/word3.jpg)

**输入：**board = [['A','B','C','E'],['S','F','C','S'],['A','D','E','E']], word = "ABCB"
**输出：**false

**提示：**

- `m == board.length`
- `n = board[i].length`
- `1 <= m, n <= 6`
- `1 <= word.length <= 15`
- `board` 和 `word` 仅由大小写英文字母组成

**进阶：**你可以使用搜索剪枝的技术来优化解决方案，使其在 `board` 更大的情况下可以更快解决问题？

这个题目的思路时每次去匹配当前开头的字符，然后还有剩余字符

dfs传递当前目标，和字符串，返回是否匹配成功
匹配成功之后，更新状态，匹配下一个位置
这里也可以用匹配位置索引传递


```
from typing import List

def searchWords(board: List[List[int]], word: str) -> bool:
	m = len(board)
	n = len(board[0])
	l = len(word)
	def dfs(i, j, k: int) -> bool:
	# dfs定义为，从(i,j)这个位置开始去匹配word[k:]
		nonlocal n
		if k == l:
			return True
		if i < 0 or i >= m or j < 0 or j >= n:
			return False
		if board[i][j] != word[k]:
			return False
		
		# 标记当前使用过
		board[i][j] = "#"
		
		# 往左走
		left = dfs(i, j-1, k+1)
		
		# 往右走
		right = dfs(i, j+1, k+1)
		
		# 往上走
		up = dfs(i-1, j, k+1)
		
		# 往下走
		down = dfs(i+1, j, k+1)
		
		board[i][j] = word[k]
		
		return left or right or up or down
	# --- 补上了外部调用入口 --- 
	for r in range(m): 
		for c in range(n): # 只有当首字母匹配时，才启动 DFS，这也算一种剪枝 
			if board[r][c] == word[0]: 
				if dfs(r, c, 0): 
					return True

```

代码的review意见

1 四个方向没有短路，在找到可行路线时应该直接返回

改成 `res = dfs(i, j-1, k+1) or dfs(i, j+1, k+1) or dfs(i-1, j, k+1) or dfs(i+1, j, k+1)`


2 两个剪枝思路
- 预检查：统计board所有字母的频率和word字符的频率，如果存在board里字符频率低于word中频率的情况，那绝对不可能匹配成功，直接返回False
- 路径优选：如果单词是 `"aaaaaaaab"`，而网格里全都是 `'a'`，从前往后搜会产生大量的深层回溯。如果从`b`开始搜，可以避免反复从board里`a`作为起点搜索的情况。从源头上避免很多无效分支
