给出二叉树的根节点 `root`，树上每个节点都有一个不同的值。

如果节点值在 `to_delete` 中出现，我们就把该节点从树上删去，最后得到一个森林（一些不相交的树构成的集合）。

返回森林中的每棵树。你可以按任意顺序组织答案。

**示例 1：**

**![](https://assets.leetcode.cn/aliyun-lc-upload/uploads/2019/07/05/screen-shot-2019-07-01-at-53836-pm.png)**

**输入：**root = [1,2,3,4,5,6,7], to_delete = [3,5]
**输出：**[[1,2,null,4],[6],[7]]

**示例 2：**

**输入：**root = [1,2,4,null,3], to_delete = [3]
**输出：**[[1,2,4]]

**提示：**

- 树中的节点数最大为 `1000`。
- 每个节点都有一个介于 `1` 到 `1000` 之间的值，且各不相同。
- `to_delete.length <= 1000`
- `to_delete` 包含一些从 `1` 到 `1000`、各不相同的值。

## 破局眼 🎯

> **后序遍历（先处理子节点），如果当前节点被删除，就把子节点加入结果并返回 None 断开连接。**

你的思路方向是对的，但顺序需要修正：**不是中序遍历，是后序遍历**。

为什么必须是后序？

```text
中序（左→根→右）：处理到根时右子树还没访问，如果根被删了，右子树没法返回
后序（左→右→根）：子节点处理完了，根被删了直接返回子节点做新根 ✅
```

### 代码

```python
def delNodes(self, root: TreeNode, to_delete: List[int]) -> List[TreeNode]:
    to_delete = set(to_delete)
    ans = []

    def dfs(node):
        if not node:
            return None
        # 后序：先处理左右子树
        node.left = dfs(node.left)
        node.right = dfs(node.right)

        if node.val in to_delete:
            if node.left:
                ans.append(node.left)
            if node.right:
                ans.append(node.right)
            return None          # 删除当前节点，断开连接
        return node              # 保留当前节点

    root = dfs(root)
    if root:
        ans.append(root)
    return ans
```

**执行过程（示例 1）：**

```text
root = [1,2,3,4,5,6,7], to_delete = {3,5}

后序遍历的顺序：4 → 5 → 2 → 6 → 7 → 3 → 1

节点 4：不在删除集 → 返回 4
节点 5：在删除集 → left/right=None → 返回 None（断开）
节点 2：left=4, right=None, 不在删除集 → 返回 2
节点 6：不在删除集 → 返回 6
节点 7：不在删除集 → 返回 7
节点 3：在删除集 → left=6, right=7 加入 ans → 返回 None（断开）
节点 1：left=2, right=None, 不在删除集 → 返回 1

ans = [[6],[7]], 最后 root=1 不为空 → ans = [[1,2,4],[6],[7]]
```

## 什么性质的题可以用这个解法？

本题本质是 **"树上的删除 + 分裂"** 模式。

### 必要条件

| 性质 | 本题体现 | 反例 |
|------|---------|------|
| **树形结构** | 二叉树 | 图（有环）→ 需 visited 集合 |
| **值唯一** | 每个节点值不同 | 有重复值 → 不能单靠值判断 |
| **子节点独立** | 删除节点后子树变新树 | 删除后需要合并子树 → 更复杂 |
| **断开即分裂** | 删一个节点分裂成多棵树 | 删后需合并相邻碎片 → 不同逻辑 |

### 判断流程

```
树上的删除/剪枝问题？
  ├── 删除后子节点变成新树？
  │     ├── 是 → ✅ 后序遍历 + 加入结果
  │     └── 否 → 只是标记/计数
  ├── 遍历顺序？
  │     ├── 子节点状态影响父节点 → 后序（本题）
  │     ├── 父节点状态影响子节点 → 前序
  │     └── 按顺序处理 → 中序（BST）
  └── 能否原地修改？
        ├── 能 → 直接改 left/right 指针
        └── 不能 → 复制节点再修改
```

### 同类题

| 题目 | 操作 | 遍历顺序 |
|------|------|---------|
| **LC 1110 删点成林** | **删节点，子树变新树** | **后序** |
| LC 450 删除 BST 节点 | 删一个节点，保持 BST | 前序/后序 + 找后继 |
| LC 814 二叉树剪枝 | 删不含 1 的子树 | 后序 |
| LC 1325 删除给定值的叶子节点 | 反复删除叶子 | 后序 |

> **树的删除问题中，后序遍历是万能的——先处理孩子，再决定自己的命运。**
