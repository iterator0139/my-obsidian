给定一个二进制数组 `nums` , 找到含有相同数量的 `0` 和 `1` 的最长连续子数组，并返回该子数组的长度。

**示例 1：**

**输入：**nums = [0,1]
**输出：**2
**说明：**[0, 1] 是具有相同数量 0 和 1 的最长连续子数组。

**示例 2：**

**输入：**nums = [0,1,0]
**输出：**2
**说明：**[0, 1] (或 [1, 0]) 是具有相同数量 0 和 1 的最长连续子数组。

**示例 3：**

**输入：**nums = [0,1,1,1,1,1,0,0,0]
**输出：**6
**解释：**[1,1,1,0,0,0] 是具有相同数量 0 和 1 的最长连续子数组。

**提示：**

- `1 <= nums.length <= 105`
- `nums[i]` 不是 `0` 就是 `1`

## 五分钟读题法分析

### 第一步：读题与盲猜（1分钟）

**题目核心**：找到含有相同数量 0 和 1 的最长连续子数组

**第一直觉**：暴力搜索 + 剪枝。遍历所有子数组 `[i,j]`，统计 0 和 1 的数量。但剪枝空间有限，复杂度仍是 O(n²)，对 n=10⁵ 会超时。

**盲猜优化方向**：
- **数据结构**：前缀和 + 哈希表（记录首次出现的索引）
- **时间复杂度**：O(n)
- **关键洞察**：把 0 看成 -1，问题就变成了**找和为 0 的最长子数组**

---

### 第二步：最优解法（核心逻辑）

#### 🔑 核心转换
```
0 → -1
1 → +1
```
这样 **"0 和 1 数量相同"** 等价于 **"子数组和为 0"**

#### 📐 状态定义
`prefix[i]` = 从起点到位置 i 的前缀和
```
如果 nums[i] = 1：prefix[i] = prefix[i-1] + 1
如果 nums[i] = 0：prefix[i] = prefix[i-1] - 1
```

#### 🎯 核心状态转移（破局眼）
```
如果 prefix[i] == prefix[j] (i < j)
→ 说明从 (i+1) 到 j 的子数组和为 0
→ 这个子数组的 0 和 1 数量相同
→ 长度 = j - i
```

#### 🗺️ 哈希表的作用
```javascript
哈希表：key=前缀和，value=该前缀和最早出现的索引

对于每个位置 j：
1. 计算 prefix[j]
2. 如果 prefix[j] 之前在哈希表中出现过（比如在位置 i）
   → 找到符合条件的子数组，更新答案：ans = max(ans, j - i)
3. 如果 prefix[j] 没出现过，存入哈希表（只存第一次！）
```

> **LeetCode 525 连续数组：把 0 当成 -1，问题转化为找和为 0 的最长子数组，用前缀和 + 哈希表记录首次索引**

### 💡 核心代码（Python）

```python
def findMaxLength(nums):
    # 前缀和 → 首次出现的索引
    prefix_map = {0: -1}  # 初始状态：前缀和 0 在索引 -1（虚拟起点）

    prefix = 0
    ans = 0

    for j, num in enumerate(nums):
        prefix += 1 if num == 1 else -1

        if prefix in prefix_map:
            # 找到符合条件的子数组，更新答案
            ans = max(ans, j - prefix_map[prefix])
        else:
            # 只存第一次出现的索引！
            prefix_map[prefix] = j

    return ans
```

**测试用例**：
```python
print(findMaxLength([0, 1]))        # 2
print(findMaxLength([0, 1, 0]))     # 2
print(findMaxLength([0, 1, 1, 1, 1, 1, 0, 0, 0]))  # 6
```

### 🧠 关键理解点

1. **为什么 map.set(0, -1)？** 处理从数组开头就满足条件的情况，如 `[0,1]`
2. **为什么只存首次索引？** 要找最长子数组，所以要用最早的 i，这样 `j-i` 最大
3. **前缀和相等意味着什么？** 中间那段子数组的增量抵消了，和为 0
