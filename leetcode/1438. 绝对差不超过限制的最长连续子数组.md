给你一个整数数组 `nums` ，和一个表示限制的整数 `limit`，请你返回最长连续子数组的长度，该子数组中的任意两个元素之间的绝对差必须小于或者等于 `limit`_。_

**示例 1：**

**输入：**nums = [8,2,4,7], limit = 4
**输出：**2 
**解释：**所有子数组如下：
[8] 最大绝对差 |8-8| = 0 <= 4.
[8,2] 最大绝对差 |8-2| = 6 > 4. 
[8,2,4] 最大绝对差 |8-2| = 6 > 4.
[8,2,4,7] 最大绝对差 |8-2| = 6 > 4.
[2] 最大绝对差 |2-2| = 0 <= 4.
[2,4] 最大绝对差 |2-4| = 2 <= 4.
[2,4,7] 最大绝对差 |2-7| = 5 > 4.
[4] 最大绝对差 |4-4| = 0 <= 4.
[4,7] 最大绝对差 |4-7| = 3 <= 4.
[7] 最大绝对差 |7-7| = 0 <= 4. 
因此，满足题意的最长子数组的长度为 2 。

**示例 2：**

**输入：**nums = [10,1,2,4,7,2], limit = 5
**输出：**4 
**解释：**满足题意的最长子数组是 [2,4,7,2]，其最大绝对差 |2-7| = 5 <= 5 。

**示例 3：**

**输入：**nums = [4,2,2,2,4,4,2,2], limit = 0
**输出：**3

**提示：**

- `1 <= nums.length <= 105`
- `1 <= nums[i] <= 109`
- `0 <= limit <= 109`

## 破局眼 🎯

> **滑动窗口 + 维护窗口内的最大值和最小值。条件是 `max - min ≤ limit`，不是新元素和每个元素逐个diff。**

你的直觉"新元素和窗口内所有元素 diff"其实等价于检查 `新元素与 max/min`——因为**任意两数差 ≤ limit 等价于 max - min ≤ limit**。

**核心难点**：窗口收缩时（左指针右移），可能移除当前的 max 或 min，需要高效找到下一个 max/min。

有两种经典做法：

## 解法一：两个双端队列（单调队列）⭐ O(n)

用两个 deque 分别维护窗口内最大值和最小值的**下标**（单调递减 / 单调递增）。

```python
def longestSubarray(self, nums: List[int], limit: int) -> int:
    from collections import deque
    max_q = deque()   # 单调递减，队头是当前窗口最大值
    min_q = deque()   # 单调递增，队头是当前窗口最小值
    left = 0
    ans = 0

    for right, x in enumerate(nums):
        # 维护 max_q：新元素从队尾入队，移除所有比它小的（保持递减）
        while max_q and nums[max_q[-1]] < x:
            max_q.pop()
        max_q.append(right)

        # 维护 min_q：新元素从队尾入队，移除所有比它大的（保持递增）
        while min_q and nums[min_q[-1]] > x:
            min_q.pop()
        min_q.append(right)

        # 如果窗口不满足条件，收缩左边界
        while nums[max_q[0]] - nums[min_q[0]] > limit:
            left += 1
            # 如果队头下标已经移出窗口，弹出
            if max_q[0] < left:
                max_q.popleft()
            if min_q[0] < left:
                min_q.popleft()

        ans = max(ans, right - left + 1)

    return ans
```

**为什么两个 deque 能 work？**
- `max_q` 队头始终是当前窗口最大值的下标，且单调递减 → 新最大值会淘汰队尾所有更小的
- `min_q` 队头始终是当前窗口最小值的下标，且单调递增 → 新最小值会淘汰队尾所有更大的
- 左指针右移时，若队头下标过期，直接 popleft

## 解法二：有序容器（SortedList）O(n log n)

```python
from sortedcontainers import SortedList

def longestSubarray(self, nums: List[int], limit: int) -> int:
    sl = SortedList()
    left = 0
    ans = 0

    for right, x in enumerate(nums):
        sl.add(x)
        while sl[-1] - sl[0] > limit:
            sl.remove(nums[left])
            left += 1
        ans = max(ans, len(sl))

    return ans
```

**特点：** 代码更短但 O(n log n)，面试时写 deque 版本更显功底。

## 为什么你的"新元素和窗口内所有元素 diff"可以优化

| 你的思路 | 优化后 |
|---------|-------|
| 新元素和窗口内每个元素算 diff → O(n) per right | 只需要知道窗口的 max 和 min → O(1) per right |
| 每次都要遍历窗口 | 两个 deque 实时维护极值 |

> 核心洞察：**绝对差 ≤ limit 这个条件不关心具体每一对，只关心极值差。**

## 什么性质的题可以用这个解法？

本题的解法实际上是 **"滑动窗口 + 单调队列（双端队列维护极值）"** 模式。符合以下性质的问题都可以套用：

### 必要条件

| 性质                           | 本题体现                     | 反例（不能用）                    |
| ---------------------------- | ------------------------ | -------------------------- |
| **连续子数组/子串**                 | 求的是连续子数组                 | 求子序列（可以不连续）→ 用 DP          |
| **约束条件关于窗口极值**               | `max - min ≤ limit`      | 约束是"和 ≤ target" → 用前缀和/双指针 |
| **窗口单调性**：窗口越大条件越难满足，窗口越小越容易 | 加入新元素只会让 `max-min` 变大或不变 | 条件不单调（如精确等于某个值）→ 用哈希表      |
| **约束固定，求最长/最短/个数**           | limit 固定，求最长             | 求所有满足的子数组个数 → 可能需要额外技巧     |

### 判断流程图

```
问题是否求连续子数组？
  ├── 否 → 不用滑动窗口
  └── 是 → 约束条件是否关于窗口的"统计量"（max/min/sum/unique count）？
        ├── 否 → 不用
        └── 是 → 窗口移动时统计量能 O(1) 维护？
              ├── 否 → 考虑有序容器 O(n log n)
              └── 是 → ✅ 滑动窗口 + 单调队列 / 双指针
```

### 同类题型一览

| 题目 | 约束条件 | 维护的数据结构 |
|------|---------|-------------|
| LC 1438 绝对差不超过限制 | `max - min ≤ limit` | 两个 deque（max + min） |
| LC 239 滑动窗口最大值 | 求每个窗口的 max | 一个 deque（单调递减） |
| LC 1499 满足不等式的最大值 | `yi + yj + \|xi - xj\|` | 一个 deque（单调递减） |
| LC 862 和至少为 K 的最短子数组 | `sum ≥ k` | 单调队列（前缀和） |
| LC 995 K 连续位的最小翻转次数 | 翻转约束 | 滑动窗口 + 队列记录翻转 |

> **一句话总结：连续子数组 + 条件单调（扩窗变差缩窗变好）+ 能通过维护极值/统计量判断 → 滑动窗口 + 单调队列。**
