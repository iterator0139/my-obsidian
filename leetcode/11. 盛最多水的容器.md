给你一个长度为 `n` 的整数数组 `height`，有 `n` 条垂线，第 `i` 条线的两个端点是 `(i, 0)` 和 `(i, height[i])`。

找出其中的两条线，使得它们与 `x` 轴共同构成的容器可以容纳最多的水。

返回容器可以储存的最大水量。

**说明：** 你不能倾斜容器。

**示例 1：**

```
输入：height = [1,8,6,2,5,4,8,3,7]
输出：49
解释：图中垂直线代表输入数组 [1,8,6,2,5,4,8,3,7]。在此情况下，容器可以容纳水（表示为蓝色部分）的最大值为 49。
```

**示例 2：**

```
输入：height = [1,1]
输出：1
```

**提示：**

- `n == height.length`
- `2 <= n <= 10^5`
- `0 <= height[i] <= 10^4`

## 五分钟读题法分析

### 第一步：分析性质

#### 识别信号

> **两端夹逼：宽度在缩，面积由短板决定；移长板不可能变大，只能移短板碰运气。**

#### 题目性质

- **数据规模**：n 最大 10⁵，O(n²) 暴力会超时
- **数据结构**：一维数组，每个元素是一条竖线的高度
- **目标类型**：求最大值（最大面积）
- **范围约束**：选 **两条** 线（两个下标），不是连续子数组
- **操作特征**：面积 = `min(h[l], h[r]) × (r - l)`，宽度随指针靠近而单调减小

#### 性质 → 方法

| 性质        | 本题体现                  | 若不满足则…          |
| --------- | --------------------- | --------------- |
| 两端夹逼有单调方向 | 宽度只减，移长板面积必不增         | 不能无脑双指针，要枚举/DP  |
| 面积由短板决定   | `min(h[l], h[r])` 是瓶颈 | 若目标与 min 无关，换公式 |
| 只需最大值     | 不用记录所有配对              | 贪心 + 双指针即可，不必哈希 |

**判断流程**：

```
要最大化 min(h[l],h[r]) × (r-l)，且 l < r？
  ├── 是 → 对撞双指针：左右端出发，每次移较短边
  └── 否 → 暴力 O(n²) 或换模型
```

#### 方法约束

- **约束**：对撞指针有效，需要「移一边只会让某个维度单调变差，移另一边才可能变好」
- **本题**：满足。宽度单调减；移 **较长** 边只会让 min 不变或变小 → 必不可能更优
- **易混淆**：和「接雨水」(LC 42) 不同——接雨水按列累加，本题只选 **两条边** 围成容器

### 第二步：读题与盲猜

**题目核心**：选两条竖线，使 `短板高度 × 两线间距` 最大。

**第一直觉**：双重循环枚举所有 `(i, j)` 对，算面积取 max。O(n²)，10⁵ 会 TLE。

**盲猜优化方向**：

- **数据结构**：双指针（对撞）
- **时间复杂度**：O(n)
- **关键洞察**：宽度在缩，当前面积由短板决定；移长板 = 宽度减 + 高度不可能增 → 可以安全丢掉

### 第三步：最优解法

#### 核心转换

面积公式：

```
area = min(height[left], height[right]) × (right - left)
```

#### 状态定义

`left = 0`，`right = n - 1`：当前候选容器的左右边界。

#### 核心状态转移（破局眼）

```
若 height[left] < height[right]：
    left += 1    # 移短板，才有可能遇到更高的左边界
否则：
    right -= 1   # 移短板（右边更短或相等）
每步更新 max_area
```

**为什么移短板？**

- 当前面积 = `短 × 宽`
- 移长板：宽度 -1，短板高度不变或更小 → 面积一定 ≤ 当前
- 移短板：宽度 -1，但短板可能变高 → **唯一可能变大的方向**

#### 关键实现细节

- 相等时移哪边都行（`left++` 或 `right--` 均可），常见写法是 `if height[l] < height[r]: l++ else: r--`
- 循环条件 `while left < right`，不是 `<=`
- 不要写成「移较高的那边」——那是反的

### 核心代码（Python）

```python
def maxArea(height: list[int]) -> int:
    left, right = 0, len(height) - 1
    res = 0
    while left < right:
        h = min(height[left], height[right])
        res = max(res, h * (right - left))
        if height[left] < height[right]:
            left += 1
        else:
            right -= 1
    return res
```

### 第四步：拆解记忆点

#### 一句话破局眼

> **LeetCode 11 盛最多水的容器：宽度在缩，面积看短板，永远移较短的那一侧。**

#### 复杂度对比

| 方法 | 时间 | 空间 | 适用性 |
|------|------|------|--------|
| 暴力枚举 | O(n²) | O(1) | n 小可过 |
| 对撞双指针 | O(n) | O(1) | ✅ 最优 |

#### 关键理解点

1. **为什么是移短板？** 移长板宽度减、高度不可能超过短板，面积必不增。
2. **移短板会漏解吗？** 不会。以短板在左为例，以它为左边界的最优解，右边界一定在某个 `right'`，当前 `right` 已是最大宽度；移走左指针后，右指针仍可能扫到更优配对。
3. **和最长回文子串的区别**：回文是「中心向外扩」；本题是「两端向中间夹」，且移动方向由单调性决定。
