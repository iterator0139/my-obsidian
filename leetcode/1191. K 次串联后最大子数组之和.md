给定一个整数数组 `arr` 和一个整数 `k` ，通过重复 `k` 次来修改数组。

例如，如果 `arr = [1, 2]` ， `k = 3` ，那么修改后的数组将是 `[1, 2, 1, 2, 1, 2]` 。

返回修改后的数组中的最大的子数组之和。注意，子数组长度可以是 `0`，在这种情况下它的总和也是 `0`。

由于 **结果可能会很大**，需要返回结果对 `109 + 7` 取 **模**。

**示例 1：**

**输入：**arr = [1,2], k = 3
**输出：**9

**示例 2：**

**输入：**arr = [1,-2,1], k = 5
**输出：**2

**示例 3：**

**输入：**arr = [-1,-2], k = 7
**输出：**0

**提示：**

- `1 <= arr.length <= 105`
- `1 <= k <= 105`
- `-104 <= arr[i] <= 104`

---

## 破局眼 🎯

> **Kadane 算一份和两份的最大子数组和。如果 `sum(arr) > 0`，把两份的结果加上 `(k-2) × sum(arr)` 就是 k 份的答案。**

分类讨论：

| 条件 | 最大子数组在哪 | 公式 |
|------|-------------|------|
| k = 1 | 一份内部 | Kadane(arr) |
| sum(arr) ≤ 0 | 最多跨两份边界 | max(Kadane(arr), Kadane(arr+arr)) |
| sum(arr) > 0 | 跨所有 k 份 | Kadane(arr+arr) + (k-2) × sum(arr) |

### 代码

```python
def kConcatenationMaxSum(self, arr: List[int], k: int) -> int:
    MOD = 10 ** 9 + 7

    def kadane(a):
        cur = best = 0
        for x in a:
            cur = max(x, cur + x)
            best = max(best, cur)
        return best

    if k == 1:
        return kadane(arr) % MOD

    total = sum(arr)
    best_one = kadane(arr)
    best_two = kadane(arr + arr)      # 两份串联

    if total <= 0:
        return max(best_one, best_two) % MOD
    else:
        return (best_two + (k - 2) * total) % MOD
```

**为什么 `sum(arr) > 0` 时能加 `(k-2)×total`？**
- `best_two` 已经包含了跨两份边界的最优子数组（后缀 + 前缀）
- 如果总和中途加上完整的一份 arr，和会增加 `total > 0`
- 中间有 `k-2` 份完整的 arr 可以插入，所以加 `(k-2) × total`

### 图解

```text
arr = [5, -2, 5], k = 3, total = 8

best_one = Kadane([5, -2, 5]) = 8
best_two = Kadane([5,-2,5,5,-2,5]) = 16

[ 5, -2, 5 | 5, -2, 5 | 5, -2, 5 ]
  └──────┬──────┘
    best_two = 16
           +  ─────────   ← 中间加 (k-2)*total = 8
  └────────────────┬─────┘
            答案 = 16 + 8 = 24
```

## 什么性质的题可以用这个解法？

本题本质是 **"Kadane + 循环数组/重复数组"** 模式。

### 必要条件

| 性质                          | 本题体现       | 反例                |
| --------------------------- | ---------- | ----------------- |
| **子数组和（连续）**                | 最大子数组和     | 求子序列 → DP         |
| **数组重复 k 次**                | 完全相同重复     | 拼接不同数组 → 不同逻辑     |
| **可空子数组**（允许和为 0）           | 长度可为 0     | 长度 ≥ 1 → 不能全负时取 0 |
| **单调扩增**：total > 0 则串联越多和越大 | 决定 k 的公式分支 | 不单调 → 必须暴力 DP     |

### 判断流程

```
求最大子数组和？
  ├── 数组是否重复/可循环？
  │     ├── 重复 k 次 → ✅ Kadane(1份) + Kadane(2份) + total 分支判断
  │     ├── 可循环（首尾相连）→ Kadane 在 arr+arr 上，上限 n
  │     └── 不重复 → 标准 Kadane
  └── 结果要取模？
        ├── 是 → 注意 Python 不溢出但最后 % MOD
        └── 否 → 正常返回
```
