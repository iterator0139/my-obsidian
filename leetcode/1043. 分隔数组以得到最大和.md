给你一个整数数组 `arr`，请你将该数组分隔为长度 **最多** 为 k 的一些（连续）子数组。分隔完成后，每个子数组的中的所有值都会变为该子数组中的最大值。

返回将数组分隔变换后能够得到的元素最大和。本题所用到的测试用例会确保答案是一个 32 位整数。

**示例 1：**

**输入：**arr = [1,15,7,9,2,5,10], k = 3
**输出：**84
**解释：**数组变为 [15,15,15,9,10,10,10]

**示例 2：**

**输入：**arr = [1,4,1,5,7,3,6,1,9,9,3], k = 4
**输出：**83

**示例 3：**

**输入：**arr = [1], k = 1
**输出：**1

**提示：**

- `1 <= arr.length <= 500`
- `0 <= arr[i] <= 109`
- `1 <= k <= arr.length`

43. 分隔数组以得到最大和 这道题呢

这道题是极其经典的“线性划分型动态规划（Partition DP）”问题（LeetCode 1043. 分隔数组以得到最大和）。

面对“将一个数组切分成若干连续段，求某种最值”的题型，暴力回溯去枚举所有切分点会带来指数级的复杂度。而利用动态规划，我们可以通过“瞻前顾后”的视角，在 O(N×K) 的时间内完美破局。

### 破局眼 🎯

**倒推最后一步（专注于最后一段）**： 假设我们已经知道了把前 `i` 个元素（`arr[0...i-1]`）进行最优化切分能得到的最大和，记为 `dp[i]`。 现在我们要推导 `dp[i]` 的值，我们可以把视线聚焦在**最后切出来的这一个子数组**上。这个子数组的长度 `j` 是可变的，但由于题目限制，`j` 的范围只能是 `1` 到 `k`：

- 如果最后一段长度是 `1`，那么最大和就是：前 `i-1` 个元素的最优解 + 最后这 1 个元素自己变成最大值。
    
- 如果最后一段长度是 `2`，那么最大和就是：前 `i-2` 个元素的最优解 + 最后这 2 个元素都变成它们当中的最大值。
    
- 依此类推……我们只要枚举所有可能的最后一段长度 `j`，取其中的最大值即可。
    

### 解法：状态转移方程

- **状态定义**：`dp[i]` 表示前 `i` 个元素（即 `arr[0 ... i-1]`）分割后能得到的最大总和。
    
- **状态转移方程**：
    
    dp[i]=1≤j≤min(i,k)max​{dp[i−j]+max(arr[i−j...i−1])×j}
    

Python

```
def maxSumAfterPartitioning(arr: list[int], k: int) -> int:
    n = len(arr)
    # dp[i] 表示前 i 个元素划分后的最大和。size 为 n + 1
    dp = [0] * (n + 1)
    
    # 遍历每一个结束位置 i (1 到 n)
    for i in range(1, n + 1):
        cur_max = 0
        # 尝试最后一段的所有可能长度 j (从 1 到 k，且不能超过当前数组总长度 i)
        for j in range(1, min(i, k) + 1):
            # 随着最后一段向左扩展，动态更新最后这一段中的最大值
            cur_max = max(cur_max, arr[i - j])
            
            # 转移：前 i-j 个元素的最优解 + 当前这一段膨胀后的和
            dp[i] = max(dp[i], dp[i - j] + cur_max * j)
            
    return dp[n]
```

### 过程图解（以 `arr = [1, 15, 7], k = 2` 为例）

- **初始状态**：`dp = [0, 0, 0, 0]`
    
- **`i = 1`（处理前1个数 `[1]`）**：
    
    - `j = 1`：最后一段是 `[1]`，`cur_max = 1`。`dp[1] = dp[0] + 1*1 = 0 + 1 = 1`。
        
- **`i = 2`（处理前2个数 `[1, 15]`）**：
    
    - `j = 1`：最后一段是 `[15]`，`cur_max = 15`。`dp[2] = dp[1] + 15*1 = 1 + 15 = 16`
        
    - `j = 2`：最后一段是 `[1, 15]`，`cur_max = 15`。`dp[2] = max(16, dp[0] + 15*2) = max(16, 30) = 30`。
        
    - 最终 `dp[2] = 30`。
        
- **`i = 3`（处理前3个数 `[1, 15, 7]`）**：
    
    - `j = 1`：最后一段是 `[7]`，`cur_max = 7`。`dp[3] = dp[2] + 7*1 = 30 + 7 = 37`
        
    - `j = 2`：最后一段是 `[15, 7]`，`cur_max = 15`。`dp[3] = max(37, dp[1] + 15*2) = max(37, 1 + 30) = 37`。
        
    - 最终 `dp[3] = 37`。
        

### 什么性质的题可以用这个解法？

本题本质是 **“划分型动态规划（Partition DP）”** 模式。

#### 必要条件

|性质|本题体现|反例（不能用此解法）|
|---|---|---|
|**连续性约束**|必须切分成**连续**的子数组，不能打乱原数组的顺序去分组。|允许自由组合无序元素（那是背包问题或子集问题）。|
|**无后效性**|后面各段怎么切、最大值是多少，**完全不影响**前面各段已经算好的最优解 `dp[i-j]`。|后面段的切分收益取决于前面段具体切在了哪些数字上（如需要满足前后段均值递增）。|
|**显式或隐式的“最后一步”**|每一段的长度受到明确的局部限制（如 ≤k），使得我们可以单层循环枚举最后一段。|划分段数有严格全局限制（比如必须刚好切成 M 段 → 需要写成二维 DP `dp[i][j]`）。|

#### "划分型 DP" 破局决策树

Plaintext

```
问题描述为：将一个连续序列切分成若干段，求最值或方案数？
  ├── 如果段数没有限制，只限制每段的长度/性质
  │     └── ✅ 一维 DP：dp[i] 表示前 i 个元素的最优解，枚举最后一段的长度（本题）
  └── 如果严格限制必须切成 M 段
        └── ✅ 二维 DP：dp[i][j] 表示前 i 个元素切成 j 段的最优解
```

### 滚动复习

**1043. 分隔数组以得到最大和：** 属于最标准的连续划分型 DP。破局点在于“聚焦于最后切出的那一个窗口”。状态 `dp[i]` 由前方的 `dp[i-j]` 加上当前窗口元素“膨胀”后的总和递推而来。由于窗口长度固定 ≤k，双重循环控制在 O(N×K) 复杂度内，完美利用了动态规划消除重复子问题计算的性质。
