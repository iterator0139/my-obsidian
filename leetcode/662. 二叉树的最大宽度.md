给你一棵二叉树的根节点 `root`，返回树的 **最大宽度**。

树的 **最大宽度** 是所有层中最大的 **宽度**。

每一层的 **宽度** 被定义为该层最左和最右的非空节点之间的长度（两端之间的空节点也计入长度）。

**示例 1：**

**输入：** root = [1,3,2,5,3,null,9]
**输出：** 4
**解释：** 最大宽度出现在第 3 层，长度为 4（5, null, null, 9）。

**示例 2：**

**输入：** root = [1,3,2,5,null,null,9,6,null,7]
**输出：** 7
**解释：** 最大宽度出现在第 4 层，长度为 7。

**示例 3：**

**输入：** root = [1,3,2,5]
**输出：** 2

**提示：**

- 树中节点的数目在范围 `[1, 3000]` 内
- `-100 <= Node.val <= 100`

## 五分钟读题法分析

### 第一步：分析性质

#### 识别信号

> **按层统计、层与层之间有关联 → BFS 层序遍历；宽度 = 最左到最右的「编号差」，把树嵌入满二叉树坐标系即可。**

#### 题目性质

- **数据规模**：节点 ≤ 3000，BFS O(n) 足够
- **数据结构**：二叉树
- **目标类型**：最值（所有层中宽度的最大值）
- **范围约束**：宽度包含**中间的空位**（null 占位），不是「节点个数」
- **层与层关系**：同一层节点有左右顺序，子节点位置由父节点位置决定

#### 性质 → 方法

| 性质        | 本题体现                | 若不满足则…            |
| --------- | ------------------- | ----------------- |
| 按层处理      | 每层算一个宽度             | 不分层 → DFS 难对齐左右边界 |
| 空位计入宽度    | 5 和 9 之间有 null 占位   | 只数节点 → 直接数每层节点数   |
| 子节点位置由父决定 | 左子 `2*i`，右子 `2*i+1` | 无位置关系 → 无法算跨度     |
| 求各层最值     | max(每层宽度)           | —                 |

**判断流程**：

```
是否按层统计二叉树信息？
  ├── 是 → BFS 层序遍历
  │     └── 宽度含 null 占位？
  │           ├── 是 → ✅ 满二叉树编号：左 2i，右 2i+1，宽度 = 末编号 - 首编号 + 1
  │           └── 否 → 数每层节点数即可
  └── 否 → DFS + 其他信息
```

#### 方法约束

- **约束**：编号方案需与「满二叉树下标」一致，才能保证同层节点编号连续反映左右跨度
- **本题**：满足；节点 3000 层数有限，编号用 `2*i` 不会溢出 int，可不归一化
- **易混淆**：宽度 ≠ 该层节点数；空子节点不占队列，但编号跨度已包含中间空位

---

### 第二步：读题与盲猜

**题目核心**：找所有层里，「最左节点到最右节点（含中间空位）」的最大跨度。

**第一直觉**：DFS 记录每层节点列表，每层算 `len(list)`——错，漏了中间 null 占位。

**盲猜优化方向**：

- **数据结构**：BFS 队列，存 `(node, index)`
- **时间复杂度**：O(n)
- **关键洞察**：把树嵌入满二叉树：根编号 0，左子 `2*i`，右子 `2*i+1`；同层宽度 = 该层最大编号 - 最小编号 + 1

---

### 第三步：最优解法

#### 核心转换

题目中的「宽度」等价于：把树画进一棵**满二叉树**里，同一层最左、最右非空节点的**下标之差 + 1**。

```
        1(0)
       /    \
    3(1)    2(2)
   /  \        \
 5(3) 3(4)     9(7)

第 3 层：最左编号 3，最右 7 → 宽度 = 7 - 3 + 1 = 4
```

中间没有节点 5、6 的位置，但编号 5、6 被「空位」占着，自然计入宽度。

#### 状态定义

- `queue`：BFS 队列，元素 `(node, index)`
- `ans`：目前见过的最大宽度
- 每层处理：记录该层队首 `left`、队尾 `right` 的编号

#### 核心状态转移（破局眼）

```
BFS 按层遍历：
  每层 width = queue[-1].index - queue[0].index + 1
  ans = max(ans, width)
  子节点入队：left → 2*index，right → 2*index+1
```

#### 关键实现细节

- **按层批量处理**：`size = len(queue)`，只处理当前层，再处理下一层
- **空节点不入队**：没有 `(null, index)`，但父节点编号已决定子节点编号，跨度仍正确
- **防溢出（可选）**：极深树可用 `index - min_index` 归一化再算 `2*(i-min)`，本题 3000 节点不必
- **别数节点数**：`[5, null, null, 9]` 只有 2 个节点，宽度却是 4

### 核心代码（Python）

```python
from collections import deque

class Solution:
    def widthOfBinaryTree(self, root: Optional[TreeNode]) -> int:
        if not root:
            return 0
        q = deque([(root, 0)])
        ans = 0
        while q:
            size = len(q)
            left_idx = q[0][1]
            right_idx = q[-1][1]
            ans = max(ans, right_idx - left_idx + 1)
            for _ in range(size):
                node, i = q.popleft()
                if node.left:
                    q.append((node.left, 2 * i))
                if node.right:
                    q.append((node.right, 2 * i + 1))
        return ans
```

**可选：编号归一化防溢出**（竞赛/更深树时用）

```python
for _ in range(size):
    node, i = q.popleft()
    if node.left:
        q.append((node.left, 2 * (i - left_idx)))
    if node.right:
        q.append((node.right, 2 * (i - left_idx) + 1))
```

### 第四步：拆解记忆点

#### 一句话破局眼

> **LeetCode 662 二叉树的最大宽度：BFS 层序 + 满二叉树编号，每层宽度 = 末编号 - 首编号 + 1。**

#### 复杂度对比

| 方法 | 时间复杂度 | 空间复杂度 | 适用性 |
|------|-----------|-----------|--------|
| DFS 收集每层节点再数 len | O(n) | O(n) | 错：漏算 null 占位 |
| **BFS + 编号** | **O(n)** | **O(n)** | **本题最优** |

#### 关键理解点

1. **宽度不是节点数**：中间 null 占位要算进跨度，所以用编号差而不是 `len(level)`
2. **为什么 2i / 2i+1？** 与满二叉树数组下标一致，同层编号反映左右相对位置
3. **空节点为何不入队？** 只需非空节点携带编号；跨度由同层最左、最右编号决定
4. **为什么按层批处理？** 一层处理完再算宽度，避免层与层混在一起
