给你一个字符串 `s`。`s` 中的 **相邻重复项** 会被反复删除，直到无法继续删除。

返回最终得到的字符串。答案中的字符顺序应该与输入中的字符顺序一致。

**示例 1：**

**输入：** s = "abbaca"
**输出：** "ca"
**解释：**
例如，在 "abbaca" 中，我们可以删除 "bb" 得到 "aaca"，然后再删除 "aa"，得到 "ca"。

**示例 2：**

**输入：** s = "azxxzy"
**输出：** "ay"

**提示：**

- `1 <= s.length <= 10^5`
- `s` 仅由小写英文字母组成

## 五分钟读题法分析

### 第一步：分析性质

#### 识别信号

> **新字符只需要和「消除后保留串的最后一个字符」比较——这是栈的经典信号。**

#### 题目性质

- **数据规模**：n ≤ 10⁵，必须 O(n)，反复扫串 O(n²) 会 TLE
- **数据结构**：字符串，顺序处理
- **目标类型**：模拟消除后的最终结果（构造/模拟）
- **操作特征**：只删**相邻相同**的一对；删后左右拼接，可能连锁
- **局部性**：每次消除只涉及「当前字符」与「已保留序列的末尾」

#### 性质 → 方法

| 性质             | 本题体现                       | 若不满足则…              |
| -------------- | -------------------------- | ------------------- |
| 消除只看相邻元素       | 删 `xx` 对                   | 删任意回文 → 中心扩展 / 不同模型 |
| 消除后可能连锁        | `ab**ba**` → 删 `bb` → `aa` | 无连锁 → 一遍扫描，不必维护历史   |
| 只需知道「当前保留串的末尾」 | 新字符只和最后一个比                 | 需要全局信息 → DP / 预处理   |
| n 大，需 O(n)     | 10⁵                        | n 小 → 反复扫串也能过       |

**判断流程**：

```
反复删除相邻相同字符？
  ├── 消除只看当前字符 vs 已保留序列末尾 → ✅ 栈模拟（配对消除）
  ├── 理解为删任意回文子串 → ❌ 过度建模，不是本题
  └── 每次删 k 个相同（k>2）→ 栈存 (字符, 计数)，见 LC 1541
```

#### 方法约束

- **约束**：栈配对消除要求「新字符只需与结果串最后一个字符比较」；本题消除规则满足这一点
- **本题**：满足——相邻消一对，连锁由栈顶 pop 自然处理
- **常见误判**：套「回文 DP / 中心扩展」——本题只删长度为 2 的相邻对，不是扫任意回文

### 第二步：读题与盲猜

**题目核心**：反复删除字符串中相邻且相同的两个字符，直到删不动，返回最终字符串。

**第一直觉**：从左到右扫描，发现相邻相同字符就删掉，删完后字符串变短、左右拼接，可能产生新的相邻对，需要继续删。若每次删完都从头重扫，最坏 O(n²)。

**盲猜优化方向**：
- **数据结构**：栈（或字符串当栈）
- **时间复杂度**：O(n)
- **关键洞察**：每次只删长度为 2 的相邻相同对（即 `xx` 这种 2-回文）；删完后左右字符 newly 相邻，连锁消除可在一次遍历中用栈顶配对完成

**与第一步一致性**：性质分析已定「栈模拟」；盲猜的「重扫整串」是同一思路的暴力版，栈是 O(n) 优化。

**用户思路校验（删回文串）**：
- ✅ 「删相邻重复 = 删长度为 2 的回文」——方向对
- ❌ 「找任意回文子串删掉」——不对，只删相邻相同的一对
- ⚠️ 「删完重扫整串」——能跑但慢；栈顶配对是 O(n) 优化

### 第三步：最优解法

#### 核心转换

把「反复删相邻重复」等价成：**顺序扫描，当前字符与栈顶相同则弹出（消一对），否则入栈**。

#### 状态定义

栈 `stk`：当前尚未被消除的字符序列（从左到右）。

#### 核心状态转移（破局眼）

```
若 stk 非空 且 stk[-1] == c：pop（消一对）
否则：push(c)
```

#### 关键实现细节

- 用 `list` 当栈，`append` / `pop` 均为 O(1)
- 新字符只需与栈顶比较，连锁消除在一次遍历内完成
- 例：`abbaca` → `a`→`[a]`，`b`→`[ab]`，`b`→消→`[a]`，`a`→消→`[]`，`c`→`[c]`，`a`→`[ca]`

### 核心代码（Python）

```python
def removeDuplicates(s: str) -> str:
    stk = []
    for c in s:
        if stk and stk[-1] == c:
            stk.pop()
        else:
            stk.append(c)
    return ''.join(stk)
```

**测试用例**：

```python
print(removeDuplicates("abbaca"))  # "ca"
print(removeDuplicates("azxxzy"))  # "ay"
```

### 第四步：拆解记忆点

#### 一句话破局眼

> **LeetCode 1047 删除字符串中的所有相邻重复项：栈顶与当前字符相同就弹出，否则入栈——相邻消消乐的配对消除，不是扫任意回文串。**

### 复杂度对比

| 方法 | 时间复杂度 | 空间复杂度 | 适用性 |
|------|-----------|-----------|--------|
| 反复扫串删对 | O(n²) | O(n) | 直觉对，会 TLE |
| **栈模拟** | **O(n)** | **O(n)** | **最优** |

### 关键理解点

1. **只删相邻相同对**，不是任意回文；`abba` 能变空是因为先删中间 `bb` 再删 `aa`，不是一次删掉整个回文。
2. **栈顶 = 当前结果串的最后一个字符**，新字符只和它比，等价于删完后立刻检查新相邻。
3. 连锁消除不需要二次遍历，栈在一次扫描里完成。
4. 与 **LC 1541**（删 k 个相邻相同）同族：栈里存 `(字符, 计数)` 即可扩展。
