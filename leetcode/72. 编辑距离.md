给你两个单词 `word1` 和 `word2`， _请返回将 `word1` 转换成 `word2` 所使用的最少操作数_  。

你可以对一个单词进行如下三种操作：

- 插入一个字符
- 删除一个字符
- 替换一个字符

**示例 1：**

**输入：**word1 = "horse", word2 = "ros"
**输出：**3
**解释：**
horse -> rorse (将 'h' 替换为 'r')
rorse -> rose (删除 'r')
rose -> ros (删除 'e')

**示例 2：**

**输入：**word1 = "intention", word2 = "execution"
**输出：**5
**解释：**
intention -> inention (删除 't')
inention -> enention (将 'i' 替换为 'e')
enention -> exention (将 'n' 替换为 'x')
exention -> exection (将 'n' 替换为 'c')
exection -> execution (插入 'u')

**提示：**

- `0 <= word1.length, word2.length <= 500`
- `word1` 和 `word2` 由小写英文字母组成

## 五分钟读题法分析

### 第一步：分析性质

#### 识别信号

> **两个字符串对齐比较、每步三种局部选择（插/删/替），子问题重叠且求最少步数——经典二维 DP / 编辑距离（Levenshtein）。**

#### 题目性质

- **数据规模**：m, n ≤ 500，O(mn) 二维 DP 可过
- **数据结构**：两个字符串
- **目标类型**：最值（最少操作数）
- **范围约束**：只能对 `word1` 做三种原子操作，使其变成 `word2`
- **操作特征**：当前决策影响后续对齐位置，存在最优子结构

#### 性质 → 方法

| 性质 | 本题体现 | 若不满足则… |
|------|---------|------------|
| 两序列比较 | word1 vs word2 | 单串 → 一维 DP |
| 求最少操作数 | 插 / 删 / 替 | 只删不插 → LC 583；能否一步完成 → LC 161 |
| 子问题重叠 | 前缀 `word1[:i]` → `word2[:j]` | 无重叠 → 回溯即可 |
| 末位字符对齐决策 | 看两串最后一位是否相等 | 带通配符 `.*` → LC 10 / 44 |
| 字符匹配可跳过 | 相等则代价 0 | 必须连续匹配 → 双指针 / KMP |

**判断流程**：

```
两个字符串，求转换 / 匹配？
  ├── 只允许插入和删除（无替换）？
  │     └── 是 → m + n - 2·LCS（LC 583）
  ├── 三种操作求最少步数？
  │     └── 是 → ✅ 编辑距离 DP
  ├── 求最长公共子序列？
  │     └── 是 → LC 1143（相等 +1，不等取 max）
  └── 带正则 / 通配符？
        └── LC 10 / 44
```

#### 方法约束

- **约束**：状态必须概括「word1 前 i 个字符」到「word2 前 j 个字符」的最优代价；转移只看 `i-1` 和 `j-1` 方向
- **本题**：满足。三种操作都可归结为「处理末位字符后」的子问题 + 1
- **易混淆**：
  - 不是 LCS——LCS 求「最长」取 `max`；编辑距离求「最少步数」取 `min` 且允许替换
  - 插入/删除对称：`word1` 插入 ≡ `word2` 删除，转移式里 `dp[i][j-1]` 和 `dp[i-1][j]` 可互换理解

### 第二步：读题与盲猜

**题目核心**：把 `word1` 变成 `word2` 的最少单步操作（插入、删除、替换）次数。

**第一直觉**：比较两串最后一位——相等则问题缩小；不等则试三种操作，取最小。你笔记里的思路完全正确。

**盲猜优化方向**：

- **数据结构**：二维 DP 表 `dp[i][j]`
- **时间复杂度**：O(mn)
- **关键洞察**：`dp[i][j]` = `word1` 前 i 个字符变成 `word2` 前 j 个字符的最少操作数；边界 `dp[i][0]=i`（全删）、`dp[0][j]=j`（全插）

### 第三步：最优解法

#### 核心转换

```
编辑距离
  ⇔ 双指针对齐两串前缀，末位相等则免费推进
  ⇔ 末位不等时三选一：删 word1 末位 / 插 word2 末位 / 替换 word1 末位
```

与 LCS 的对照：

| | LCS (1143) | 编辑距离 (72) |
|---|---|---|
| 末位相等 | `dp[i-1][j-1] + 1` | `dp[i-1][j-1]`（+0） |
| 末位不等 | `max(上, 左)` | `1 + min(上, 左, 左上)` |

#### 状态定义

`dp[i][j]` = 将 `word1[0:i]` 转换为 `word2[0:j]` 的最少操作数（`i`、`j` 为长度，非下标）

#### 核心状态转移（破局眼）

```python
if word1[i-1] == word2[j-1]:
    dp[i][j] = dp[i-1][j-1]
else:
    dp[i][j] = 1 + min(
        dp[i-1][j],    # 删 word1[i-1]
        dp[i][j-1],    # 插 word2[j-1]（word1 侧补一位）
        dp[i-1][j-1],  # 替换 word1[i-1] → word2[j-1]
    )
```

**三种操作的子问题含义**（对应你笔记）：

| 操作 | 含义 | 子问题 |
|------|------|--------|
| 删除 | 去掉 `word1` 末位 | `dp[i-1][j] + 1` |
| 插入 | 给 `word1` 补上 `word2` 末位 | `dp[i][j-1] + 1` |
| 替换 | 把 `word1` 末位改成 `word2` 末位 | `dp[i-1][j-1] + 1` |

#### 关键实现细节

- **初始化**：`dp[i][0] = i`，`dp[0][j] = j`——一方为空时只能全删或全插
- **下标**：`dp[i][j]` 对应 `word1[i-1]` 与 `word2[j-1]`，避免 off-by-one
- **空间优化**：滚动一维数组 O(min(m,n))，内层 j 从右到左更新防覆盖
- **与 LCS 关系**：若只允许插/删，`edit = m + n - 2·LCS`；有替换则必须走完整 DP

### 核心代码（Python）

```python
def minDistance(word1: str, word2: str) -> int:
    m, n = len(word1), len(word2)
    dp = [[0] * (n + 1) for _ in range(m + 1)]

    for i in range(m + 1):
        dp[i][0] = i
    for j in range(n + 1):
        dp[0][j] = j

    for i in range(1, m + 1):
        for j in range(1, n + 1):
            if word1[i - 1] == word2[j - 1]:
                dp[i][j] = dp[i - 1][j - 1]
            else:
                dp[i][j] = 1 + min(
                    dp[i - 1][j],      # 删
                    dp[i][j - 1],      # 插
                    dp[i - 1][j - 1],  # 替
                )
    return dp[m][n]
```

**一维滚动**（面试可提）：

```python
def minDistance(word1: str, word2: str) -> int:
    dp = list(range(len(word2) + 1))
    for i in range(1, len(word1) + 1):
        prev = dp[0]
        dp[0] = i
        for j in range(1, len(word2) + 1):
            temp = dp[j]
            if word1[i - 1] == word2[j - 1]:
                dp[j] = prev
            else:
                dp[j] = 1 + min(prev, dp[j], dp[j - 1])
            prev = temp
    return dp[-1]
```

### 第四步：拆解记忆点

#### 一句话破局眼

> **LeetCode 72 编辑距离：二维 DP 对齐两串前缀；末位相等免费，不等则「删 / 插 / 替」三选一取 min + 1。**

#### 复杂度对比

| 方法 | 时间 | 空间 | 适用性 |
|------|------|------|--------|
| 暴力回溯 | 指数级 | O(m+n) 栈 | 超时 |
| 二维 DP | O(mn) | O(mn) | ✅ 标准解 |
| 一维滚动 | O(mn) | O(n) | ✅ 空间优化 |

#### 关键理解点

1. **为什么看「最后一位」？** 任意合法操作序列的最后一步，一定是在处理两串当前末尾的对齐关系；最优子结构保证只需关心前缀。
2. **插入为什么变成 `dp[i][j-1]`？** 给 `word1` 插入 `word2[j-1]` 后，`word2` 末位被「消耗」，问题变为 `word1[:i]` → `word2[:j-1]`。
3. **和 LCS 怎么区分？** LCS 是「能配就配、不能配就跳过一边」取最长；编辑距离是「不能配就花 1 步修正」取最短。
4. **边界为什么是 `dp[i][0]=i`？** `word2` 为空 → 只能把 `word1` 的 i 个字符全删掉。
