给你两个单词 `word1` 和 `word2`， _请返回将 `word1` 转换成 `word2` 所使用的最少操作数_  。

你可以对一个单词进行如下三种操作：

- 插入一个字符
- 删除一个字符
- 替换一个字符

**示例 1：**

**输入：**word1 = "horse", word2 = "ros"
**输出：**3
**解释：**
horse -> rorse (将 'h' 替换为 'r')
rorse -> rose (删除 'r')
rose -> ros (删除 'e')

**示例 2：**

**输入：**word1 = "intention", word2 = "execution"
**输出：**5
**解释：**
intention -> inention (删除 't')
inention -> enention (将 'i' 替换为 'e')
enention -> exention (将 'n' 替换为 'x')
exention -> exection (将 'n' 替换为 'c')
exection -> execution (插入 'u')

**提示：**

- `0 <= word1.length, word2.length <= 500`
- `word1` 和 `word2` 由小写英文字母组成

思路是要求word1到word2的编辑距离的话

比较两个单词最后一个位置的情况
- 如果两个单词最后一个位置是一样的，那最后的结果就等于除了最后一个位置的两个字符串的编辑距离了，同理去求子问题
- 如果两个单词最后位置不一样，那我们就有三种选择
	- 替换：这种情况，操作数+1，但是子问题和最后位置字符一样的情况一下，那最后的结果就等于除了最后一个位置的两个字符串的编辑距离 + 1
	- 插入：这种情况，插入的位置和另外一个单词的最后一个位置结果一样，操作数加一，然后匹配问题可以忽略另外一个单词的最后一个位置了
	- 删除：这种情况，直接忽略删除的这个单词的最后一个问题
	- 最后取这三种情况里面最小的就好了。
