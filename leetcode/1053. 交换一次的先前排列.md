### 破局眼 🎯

要找到“按字典序排列小于 `arr` 的**最大**排列”，核心贪心思想是：**尽可能保持高位（左边）不动，在尽可能低的位（右边）进行微调。**

1. **逆序寻找突破口 `i`**：对于一个无法再变小的终点状态，从右往左看数字应当是单调递减（越来越小）的。一旦看到某个位置破环了这种递减性，即 **`arr[i] > arr[i+1]`**，说明我们抓到了一个可以变小的“高位点”。
    
2. **在右侧寻找最佳替换人选 `j`**：为了让变小后的新数组尽量大，我们要在 `i` 右侧的所有人里，挑选一个**严格小于 `arr[i]` 且数值最大**的数 `arr[j]` 来跟它交换。
    
3. ⚠️ **重复值陷阱（最左原则）**：若右侧这个“小于 `arr[i]` 的最大值”存在多个重复数字，**必须选择最左边的那个**。这样交换后，较大的 `arr[i]` 就会被换到更靠右的低位，从而保证新排列的字典序最大。
    

### 解法：贪心 + 逆序双指针

Python

```
def prevPermOpt1(arr: list[int]) -> list[int]:
    n = len(arr)
    
    # 1. 从右向左扫描，寻找第一个打破“从右往左单调递减”规律的数
    # 也就是找第一个满足高位大于低位的位置：arr[i] > arr[i+1]
    i = n - 2
    while i >= 0 and arr[i] <= arr[i+1]:
        i -= 1
        
    # 如果整个数组已经是从左到右单调递增的（从右到左单调递减），说明已经是最小排列，直接返回
    if i < 0:
        return arr
        
    # 2. 在 arr[i] 的右侧区域中，从右向左寻找第一个严格小于 arr[i] 的数
    # 因为 i 右侧原本具备从右往左递减的特性，所以从右往左看，第一个小于 arr[i] 的数就是“右侧小于它的最大值”
    j = n - 1
    while arr[j] >= arr[i]:
        j -= 1
        
    # 3. 规避重复值陷阱：如果有多个相同的最大值，必须一路向左推到这个重复区间的【最左端】
    while j > 0 and arr[j] == arr[j-1]:
        j -= 1
        
    # 4. 交换 i 和 j，完成单次就地修改
    arr[i], arr[j] = arr[j], arr[i]
    
    return arr
```

### 过程图解（以 `arr = [3, 5, 2, 2, 7]` 为例）

**第一步：逆序定位高位点 `i`**

- 从末尾开始往前看：`7 -> 2`（减少），`2 -> 2`（平），`2 -> 5`（**突增！破坏了从右往左越来越小的递减性**）。
    
- 循环在 `i = 1` 处停止，此时 `arr[i] = 5`。
    

**第二步：在右侧区域 `[2, 2, 7]` 中定位低位替换点 `j`**

- 从右往左找第一个严格小于 5 的数：
    
    - `7` 不小于 5，跳过。
        
    - `2`（索引 3）严格小于 5，命中！
        

**第三步：处理重复值（最左原则）**

- 我们发现选中的 `arr[3] == 2`，而它左边的 `arr[2]` 也是 `2`。
    
- 为了让换过去的 `5` 挪到更低的数位，指针 `j` 必须向左推到重复区间的边界，最终锁定 `j = 2`。
    

**第四步：执行交换**

- 交换 `arr[1]`(5) 和 `arr[2]`(2)，原数组由 `[3, 5, 2, 2, 7]` 蜕变为 `[3, 2, 5, 2, 7]`。
    

### 什么性质的题可以用这个解法？

本题本质是 **“邻域字典序最值调整 / 局部贪心交换”** 模式。

#### 必要条件

|**性质**|**本题体现**|**反例（不能用单次交换贪心）**|
|---|---|---|
|**单次操作限制**|题目严格限制**只能交换一次**数字位置。|允许无限次交换 $\rightarrow$ 直接降序排序。|
|**局部单调破坏性**|寻找最右侧破坏整体单调性的拐点，来最小化高位变动产生的影响。|元素之间存在跨越空间的求和、乘积等非线性约束。|
|**字典序权重一票否决**|高位数值变小一点点，对整体字典序变小的贡献远大于低位剧烈变动。|比较的是各排列下的全局权值（如最长递增子序列）。|

#### "字典序排列变换" 破局决策树

Plaintext

```
要求通过有限次/单次交换改变数组，使其字典序最邻近大/小？

        ├── 找下一个更大排列 → 从右往左看，一旦变小(arr[i] < arr[i+1])，即为破局点

```

### 滚动复习

**1053. 交换一次的先前排列：** 属于典型依靠逆序扫描控制影响范围的字典序贪心题。破局点在于：**“从右往左看，数字应该越来越小；一旦发现某个高位数字变大了，就打破了最小状态。此时在右侧挑一个小于它的最大值（有重复选最左）进行单次交换。”** 这种利用局部单调性在 $O(N)$ 时间、 $O(1)$ 空间内达成最邻近字典序调整的方法在排列类问题中极为通用。
