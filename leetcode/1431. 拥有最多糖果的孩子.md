有 `n` 个有糖果的孩子。给你一个数组 `candies`，其中 `candies[i]` 代表第 `i` 个孩子拥有的糖果数目，和一个整数 `extraCandies` 表示你所有的额外糖果的数量。

返回一个长度为 `n` 的布尔数组 `result`，如果把所有的 `extraCandies` 给第 `i` 个孩子之后，他会拥有所有孩子中 **最多** 的糖果，那么 `result[i]` 为 `true`，否则为 `false`。

注意，允许有多个孩子同时拥有 **最多** 的糖果数目。

**示例 1：**

**输入：**candies = [2,3,5,1,3], extraCandies = 3
**输出：**[true,true,true,false,true] 
**解释：**如果你把额外的糖果全部给：
孩子 1，将有 2 + 3 = 5 个糖果，是孩子中最多的。
孩子 2，将有 3 + 3 = 6 个糖果，是孩子中最多的。
孩子 3，将有 5 + 3 = 8 个糖果，是孩子中最多的。
孩子 4，将有 1 + 3 = 4 个糖果，不是孩子中最多的。
孩子 5，将有 3 + 3 = 6 个糖果，是孩子中最多的。

**示例 2：**

**输入：**candies = [4,2,1,1,2], extraCandies = 1
**输出：**[true,false,false,false,false] 
**解释：**只有 1 个额外糖果，所以不管额外糖果给谁，只有孩子 1 可以成为拥有糖果最多的孩子。

**示例 3：**

**输入：**candies = [12,1,12], extraCandies = 10
**输出：**[true,false,true]

**提示：**

- `n == candies.length`
- `2 <= n <= 100`
- `1 <= candies[i] <= 100`
- `1 <= extraCandies <= 50`

---

## 破局眼 🎯

> **先找原始最大值，再看每个孩子加上 extra 后能否 ≥ 这个最大值。一次遍历搞定。**

注意允许多个孩子同时并列最多，所以判断条件是 `≥` 而不是 `>`。

## 代码

```python
def kidsWithCandies(self, candies: List[int], extraCandies: int) -> List[bool]:
    max_candy = max(candies)
    return [c + extraCandies >= max_candy for c in candies]
```

复杂度 O(n)，一行列表推导式搞定。

## 什么性质的题可以用这个解法？

本题本质是 **"全局统计量 + 逐元素阈值判断"** 模式。

| 性质 | 本题体现 | 反例（不能用） |
|------|---------|-------------|
| **全局基准值固定** | 最大值在分配 extra 前就确定了 | 分配会影响他人 → 需重新计算 |
| **条件只需比较基准值** | `当前值 + extra ≥ 基准值` | 条件涉及多个元素互动 → 不同解法 |
| **各元素独立判断** | 每个孩子的结果不影响他人 | 结果相互依赖 → 需动态规划 |
| **数据量极小**（n ≤ 100） | 完全够用 | 无此约束也能过 |

**判断流程：**

```
问题是对每个元素做"是否满足某个条件"的判断？
  ├── 条件依赖于一个全局固定的基准值？
  │     ├── 是 → ✅ 先算基准值，再逐个判断
  │     └── 否 → 条件是否依赖于其他元素的当前位置？
  │           ├── 是 → 滑动窗口 / 单调栈
  │           └── 否 → 其他数据结构
  └── 判断结果相互独立？
        ├── 是 → ✅ 一次遍历
        └── 否 → 需要联立求解
```

**同类题：**

| 题目 | 基准值 | 逐元素判断 |
|------|-------|-----------|
| LC 1431 最多糖果 | 原始最大值 | `c + extra ≥ max` |
| LC 1656 设计有序流 | 当前期望指针 | `ptr == id` |
| LC 1768 交替合并字符串 | 双指针索引 | i < len && j < len |
