给定两个大小分别为 `m` 和 `n` 的正序（从小到大）数组 `nums1` 和 `nums2`。请你找出并返回这两个正序数组的 **中位数** 。

算法的时间复杂度应该为 `O(log (m+n))` 。

**示例 1：**

**输入：**nums1 = [1,3], nums2 = [2]
**输出：**2.00000
**解释：**合并数组 = [1,2,3] ，中位数 2

**示例 2：**

**输入：**nums1 = [1,2], nums2 = [3,4]
**输出：**2.50000
**解释：**合并数组 = [1,2,3,4] ，中位数 (2 + 3) / 2 = 2.5

**提示：**

- `nums1.length == m`
- `nums2.length == n`
- `0 <= m <= 1000`
- `0 <= n <= 1000`
- `1 <= m + n <= 2000`
- `-106 <= nums1[i], nums2[i] <= 106`

### 💡 核心架构思想：割线法（Partition）

把寻找中位数，转化为“把两个数组切成长度相等的左右两半”的问题。

假设我们有两个数组 $A$ 和 $B$，长度分别是 $m$ 和 $n$。

如果我们能在 $A$ 和 $B$ 中各画一条竖线（割线），把它们分别切成左右两部分：

$$A\text{左} \quad | \quad A\text{右}$$

$$B\text{左} \quad | \quad B\text{右}$$

我们要寻找的这条“完美割线”必须满足两个绝对条件：

1. **长度均分**：$A\text{左} + B\text{左}$ 的元素个数，必须等于 $A\text{右} + B\text{右}$ 的元素个数。（如果总数是奇数，我们让左边多一个）。
    
2. **交叉小等于大**：左边最大的元素，必须小于等于右边最小的元素。
    
    - 即：`A左的最大值 <= B右的最小值` 且 `B左的最大值 <= A右的最小值`。
        

只要找到了这条割线，中位数就呼之欲出了：

- **总长度为奇数**：中位数就是左半部分的最大值。
    
- **总长度为偶数**：中位数就是 `(左半部分最大值 + 右半部分最小值) / 2.0`。

为了让二分查找最快且不越界，我们**永远在较短的那个数组（假设为 $A$）上做二分查找**。

1. 假设我们在 $A$ 中的第 $i$ 个位置切一刀（$i$ 表示 $A$ 左半部分有 $i$ 个元素）。
    
2. 因为“左半部分总长度”是固定的公式：$total\_left = \lfloor \frac{m + n + 1}{2} \rfloor$。
    
3. 那么 $B$ 数组的割线位置 $j$ 就被自动决定了：$j = total\_left - i$。
    

我们在 $A$ 数组的 $[0, m]$ 范围内用二分查找移动 $i$：

- 如果 `A[i - 1] > B[j]`：说明 $A$ 左边的元素太大了，割线 $i$ 需要**往左移**。
    
- 如果 `B[j - 1] > A[i]`：说明 $B$ 左边的元素太大了，这就倒逼 $A$ 的割线 $i$ 必须**往右移**以分担压力。
    
- 当两者都满足交叉小于等于时，我们找到了完美割线！

```
class Solution:
    def findMedianSortedArrays(self, nums1: list[int], nums2: list[int]) -> float:
        # 核心防御：永远保证 nums1 是较短的那个数组，以此来避免 j 越界
        if len(nums1) > len(nums2):
            nums1, nums2 = nums2, nums1
            
        m, n = len(nums1), len(nums2)
        left, right = 0, m
        
        # 左半部分的总长度 (加 1 是为了兼容总长度奇偶数)
        total_left = (m + n + 1) // 2 
        
        while left <= right:
            # i 是 nums1 的割线位置，j 是 nums2 的割线位置
            i = (left + right) // 2
            j = total_left - i
            
            # 提取四个边界值，处理越界（用无穷大/无穷小代替）
            # A_left_max, A_right_min, B_left_max, B_right_min
            nums1_left_max = float('-inf') if i == 0 else nums1[i - 1]
            nums1_right_min = float('inf') if i == m else nums1[i]
            
            nums2_left_max = float('-inf') if j == 0 else nums2[j - 1]
            nums2_right_min = float('inf') if j == n else nums2[j]
            
            # 验证割线是否完美
            if nums1_left_max <= nums2_right_min and nums2_left_max <= nums1_right_min:
                # 完美割线！计算中位数
                if (m + n) % 2 == 1:
                    # 总长为奇数，左半部分多一个，取左半部分的最大值
                    return float(max(nums1_left_max, nums2_left_max))
                else:
                    # 总长为偶数，取左半边最大和右半边最小的平均值
                    return (max(nums1_left_max, nums2_left_max) + 
                            min(nums1_right_min, nums2_right_min)) / 2.0
                            
            elif nums1_left_max > nums2_right_min:
                # nums1 左边太大了，说明割线 i 划得太靠右了，往左逼近
                right = i - 1
            else:
                # nums2 左边太大了，倒逼 nums1 的割线 i 往右逼近
                left = i + 1
```

三个注意的点
- 定义了左边的个数大于等有右边个数，所以total_left = (m + n + 1) // 2
- AB各越界逻辑
	- A左越界时，说明A左没有元素，A左 <= B右一定要成立，所以是负无穷
	- A右越界时，说明B左小于等于A右一定成立，所以是正无穷
- 只能再较短的数组上二分，防止二分过程中数组越界
