给你一个 **只包含正整数** 的 **非空** 数组 `nums` 。请你判断是否可以将这个数组分割成两个子集，使得两个子集的元素和相等。

**示例 1：**

**输入：**nums = [1,5,11,5]
**输出：**true
**解释：**数组可以分割成 [1, 5, 5] 和 [11] 。

**示例 2：**

**输入：**nums = [1,2,3,5]
**输出：**false
**解释：**数组不能分割成两个元素和相等的子集。

**提示：**

- `1 <= nums.length <= 200`
- `1 <= nums[i] <= 100`

分割两个子集，使得两个子集元素和相等

先算一个target，$target = sum(nums)  //  2$

现在问题变成能否从数组里面进行有限背包凑成target值

这个问题的定义是

假设我们有[a, b, c, d]要凑成target，我们可以选d作为最后一个item，这个时候我们只需要关注子问题
target = target - a, item = [a, b, c,] 

在转化一下，也就是我们在前4个元素，凑成target可以转换成前3个元素凑成target-a

$dp[i][j] = dp[i-1][j-nums[i]]$

```
def split(nums: List[int]) -> bool
	if sum(nums) % 2 == 1:
		return false
	target == sum(nums) // 2
	n = len(nums)
	
	# 物品维度大小设为 n + 1，行索引从 0 到 n，垫高一层
	dp = [[False] * (target+1) for _ in range(n + 1)]
	
	# 【唯一初始化】一个物品都不选，只能凑出容量 0 
	dp[0][0] = True
	
	for i in range(1, n):
		for j in range(1, target+1)
			if j < nums[i]:
				dp[i][j] = dp[i-1][j] 
			else:
				dp[i][j] = dp[i-1][j] or dp[i-1][j-nums[i]]
				
	return dp[-1][-1]
```
