给你一个 **只包含正整数** 的 **非空** 数组 `nums` 。请你判断是否可以将这个数组分割成两个子集，使得两个子集的元素和相等。

**示例 1：**

**输入：**nums = [1,5,11,5]
**输出：**true
**解释：**数组可以分割成 [1, 5, 5] 和 [11] 。

**示例 2：**

**输入：**nums = [1,2,3,5]
**输出：**false
**解释：**数组不能分割成两个元素和相等的子集。

**提示：**

- `1 <= nums.length <= 200`
- `1 <= nums[i] <= 100`

分割两个子集，使得两个子集元素和相等

先算一个target，$target = sum(nums)  //  2$

现在问题变成能否从数组里面进行有限背包凑成target值

这个问题的定义是

假设我们有[a, b, c, d]要凑成target，我们可以选d作为最后一个item，这个时候我们只需要关注子问题
target = target - a, item = [a, b, c,] 

在转化一下，也就是我们在前4个元素，凑成target可以转换成前3个元素凑成target-a

$dp[i][j] = dp[i-1][j-nums[i]]$

```
dp = [False] * len(nums)

for j in range(target):
	for i in range(len(nums)):
		dp[i][j] = dp[i-1][j - nums[i]]
		
```
