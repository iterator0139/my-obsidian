给定一个非负整数数组 `arr`，你最开始位于该数组的起始下标 `start` 处。当你位于下标 `i` 处时，你可以跳到 `i + arr[i]` 或者 `i - arr[i]`。

请你判断自己是否能够跳到对应元素值为 0 的 **任一** 下标处。

注意，不管是什么情况下，你都无法跳到数组之外。

**示例 1：**

**输入：**arr = [4,2,3,0,3,1,2], start = 5
**输出：**true
**解释：**
到达值为 0 的下标 3 有以下可能方案： 
下标 5 -> 下标 4 -> 下标 1 -> 下标 3 
下标 5 -> 下标 6 -> 下标 4 -> 下标 1 -> 下标 3 

**示例 2：**

**输入：**arr = [4,2,3,0,3,1,2], start = 0
**输出：**true 
**解释：**
到达值为 0 的下标 3 有以下可能方案： 
下标 0 -> 下标 4 -> 下标 1 -> 下标 3

**示例 3：**

**输入：**arr = [3,0,2,1,2], start = 2
**输出：**false
**解释：**无法到达值为 0 的下标 1 处。

**提示：**

- `1 <= arr.length <= 5 * 10^4`
- `0 <= arr[i] < arr.length`
- `0 <= start < arr.length`

---

## 破局眼 🎯

> **把数组看作一张图，每个下标 i 有两条出边：`i+arr[i]` 和 `i-arr[i]`（在界内）。DFS/BFS 看能否从 start 走到任意 0。**

你的**反向逐层扩散**思路完全可行——从所有 0 出发反向 BFS，看能不能到达 start。两种方向都能用。

### 解法一：正向 BFS/DFS（最直观）

从 start 出发，按规则跳，标记已访问，遇到 0 返回 true。

```python
def canReach(self, arr: List[int], start: int) -> bool:
    n = len(arr)
    visited = [False] * n
    q = [start]

    for i in q:
        if arr[i] == 0:
            return True
        if visited[i]:
            continue
        visited[i] = True
        for nxt in (i + arr[i], i - arr[i]):
            if 0 <= nxt < n and not visited[nxt]:
                q.append(nxt)
    return False
```

O(n) 时间，O(n) 空间。

### 解法二：反向逐层 BFS（你的思路）

**核心：** 先建**反向邻接表**——对每个位置 j，谁可以跳到它？然后从所有 0 出发 BFS。

```python
def canReach(self, arr: List[int], start: int) -> bool:
    n = len(arr)
    # 建反向图：rev[j] = 所有能跳到 j 的位置
    rev = [[] for _ in range(n)]
    for i in range(n):
        for nxt in (i + arr[i], i - arr[i]):
            if 0 <= nxt < n:
                rev[nxt].append(i)

    # 从所有 0 出发反向 BFS（逐层扩散）
    q = [i for i in range(n) if arr[i] == 0]
    visited = [False] * n
    for cur in q:
        visited[cur] = True

    for cur in q:
        if cur == start:
            return True
        for prev in rev[cur]:          # 能跳到 cur 的位置
            if not visited[prev]:
                visited[prev] = True
                q.append(prev)
    return False
```

**两种方向对比：**

| | 正向（从 start 出发） | 反向（从 0 出发） |
|--|-------------------|----------------|
| 建图 | 不需要（边规则固定） | 需要 O(n) 建反向表 |
| BFS 规模 | 到找到 0 为止 | 可能要遍历全图 |
| 代码量 | 少 | 略多 |
| 适用场景 | **本题最佳** | 多个起点要判断时 |

## 什么性质的题可以用这个解法？

本题本质是 **"图上的可达性（BFS/DFS）"** 模式。

### 必要条件

| 性质 | 本题体现 | 反例 |
|------|---------|------|
| **状态转移固定** | 从 i 到 i±arr[i] | 状态转移有额外条件 → 更复杂 |
| **无负面作用**（无状态影响） | 跳到哪只看位置 | 资源消耗类（如跳跃游戏 II）→ DP |
| **目标可达即可**（不是最值） | 只要到达 0 | 求最短/最长路径 → BFS 层级 / DP |
| **图是隐式的**（边由规则生成） | 每次动态计算下一跳 | 显式给出图 → 直接遍历 |

### 判断流程

```
数组/棋盘跳跃问题？
  ├── 能否到达目标？（可达性）
  │     ├── 规则固定，无消耗 → ✅ BFS/DFS 即可
  │     └── 有消耗（步数/体力）→ 最短路径 / DP
  └── 最多/最少步数？
        ├── 步数就是跳跃次数 → BFS 求最短路
        └── 需要决策 → DP / 贪心
```

### 同类题

| 题目 | 跳跃方式 | 目标 |
|------|---------|------|
| LC 1306 跳跃游戏 III | i→i±arr[i] | 到达任意 0 |
| LC 55 跳跃游戏 | i→i+[1..arr[i]] | 能否到终点 |
| LC 45 跳跃游戏 II | i→i+[1..arr[i]] | 最少步数到终点 |
| LC 1345 跳跃游戏 IV | i±1 或跳到同值 | 最少步数到终点 |

> **核心：跳跃规则就是图的边。BFS/DFS 是这类题的通用解法，区别只在"怎么跳"。**
