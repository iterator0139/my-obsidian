

方法一：中心扩展法（双指针）

**不是**有序数组的「左右夹逼求和」，而是 **从每个可能的中心向两侧对撞展开**。

#### 双指针怎么放

| 回文长度 | 初始位置 | 例子 `babad` |
|---------|---------|-------------|
| 奇数 | `left = right = i` | 中心 `a`(下标2) → 扩成 `aba` |
| 偶数 | `left = i, right = i+1` | 中心 `ab`(下标1,2) → 扩成 `bab` 不行，但 `bb` 可以 |

每个下标 `i` 试两次（奇中心 + 偶中心），共 `2n-1` 个中心。

#### 核心循环（破局眼）

```python
while left >= 0 and right < n and s[left] == s[right]:
    left -= 1      # 左指针向左
    right += 1     # 右指针向右
# 多走了一步，回文区间是 [left+1, right)
return s[left + 1 : right]
```

#### 完整代码

```python
def longestPalindrome(s: str) -> str:
    def expand(left: int, right: int) -> str:
        while left >= 0 and right < len(s) and s[left] == s[right]:
            left -= 1
            right += 1
        return s[left + 1 : right]

    res = ""
    for i in range(len(s)):
        res = max(res, expand(i, i), expand(i, i + 1), key=len)
    return res
```

#### 易错点

- 边界写 `left >= 0`，**不能**写 `left > 0`（会漏掉以 `s[0]` 开头的回文）
- 返回值是 `s[left+1:right]`，不是 `s[left:right]`（循环退出时已经多扩了一步）

复杂度：时间 $O(n^2)$，空间 $O(1)$。

```
def longestPalindrome(s: str) -> str:

def expand(s: str, left: int, right: int) -> str:
	n = len(s)
	if left < 0 or right >= n:
		return ""
	while left >= 0 and right < n and s[left] == s[right]:
		left -= 1
		right += 1
	# 循环退出时多走了一步，有效区间是 [left+1, right)
	return s[left + 1 : right]
```



方法二：动态规划法
通过计算s[i:j+1]是否是回文串来遍历所有的子串，计算的方式通过动态规划，如果判断是子串那么就可以进行最长长度的更新。
- 状态定义：$dp[i][[j]$ 表示$s[i:j+1]$的字符串是否是回文串
- 状态转移
	- 如果$s[i]$和$s[j]$相等，那么$dp[i][j] = dp[i+1][j-1]$
	- 如果$s[i]$和$s[j]$不相等，那么$dp[i][j] = false$
- 如果$dp[i][[j]$ 为true的时候，更新最大长度
复杂度：时间复杂度$O(n^2)$，空间复杂度$O(n^2)$

```
def longestPalindrome(s: str) -> str:
	n = len(s)
	res = ""
	dp = [[False] * n for _ in range(n)]
	# dp[i][j] 表示s[i:j+1]是不是回文
	# 如果s[i] == s[j]: dp[i][j] = dp[i+1][j-1]
	# i要从大算到小，j要从小算到大
	
	# initialize，长度为1的元素可以看成回文，如果要初始化就要初始化长度为1和长度为2，然后更新res，这里就不背这个模板了，直接背下面这个版本
	# for i in range(n):
	# 	dp[i][i] = True
		
	# 这道题我写的时候犯了一个错误，状态转移的条件是 j - i + 1 >= 3，也就是要三个字符以上
	# 如果只有一个或者两个的时候，dp[i][j] = s[i] == s[j]
	for i in range(n-1, -1, -1):
		for j in range(i, n): 
			if s[i] == s[j]:
				if j - i >= 2:
					dp[i][j] = s[i] == s[j]
				else:
					dp[i][j] = dp[i+1][j-1]
				if j - i + 1 > len(res):
					res = s[i:j+1]
	return res
	
```
