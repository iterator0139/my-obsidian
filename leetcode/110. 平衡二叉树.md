给定一个二叉树，判断它是否是 平衡二叉树  

**示例 1：**

![](https://assets.leetcode.com/uploads/2020/10/06/balance_1.jpg)

**输入：**root = [3,9,20,null,null,15,7]
**输出：**true

**示例 2：**

![](https://assets.leetcode.com/uploads/2020/10/06/balance_2.jpg)

**输入：**root = [1,2,2,3,3,null,null,4,4]
**输出：**false

**示例 3：**

**输入：**root = []
**输出：**true

**提示：**

- 树中的节点数在范围 `[0, 5000]` 内
- `-104 <= Node.val <= 104`



平衡二叉树的定义是，左子树的高度和右子树的高度相差不大于1，同时左子树也是平衡二叉树，右子树也是平衡二叉树

```
from typ
class TreeNode:
	def __init__(self, val=0, left=None, right=None):
		self.val = val
		self.left = left
		self.right = right
		
def isBalance(root: Optional[TreeNode]) -> bool:
	
	# 这里如果dfs定义成返回子树的高度
	# 那每次都要重复计算，所以考虑把dfs定义成通过高度来判断是否是平衡，如果有高度，那就是平衡的
	def dfs(root: Optional[TreeNode]) -> int:
		if root is None:
			return 0
		
		left_height = dfs(root.left)
		right_height = dfs(root.right)
		
		if left_height < 0 or right_height < 0:
			return -1
		
		if abs(right_height - left_height) < 2:
			return max(right_height, left_height) + 1
		else:
			return -1
	
	return dfs(root) != -1
		
	
```

1 这里也可以有短路的机制，如果左子树都不平衡了，右子树就不用看了
```
from typ
class TreeNode:
	def __init__(self, val=0, left=None, right=None):
		self.val = val
		self.left = left
		self.right = right
		
def isBalance(root: Optional[TreeNode]) -> bool:
	
	# 这里如果dfs定义成返回子树的高度
	# 那每次都要重复计算，所以考虑把dfs定义成通过高度来判断是否是平衡，如果有高度，那就是平衡的
	def dfs(root: Optional[TreeNode]) -> int:
		if root is None:
			return 0
		
		left_height = dfs(root.left)
		if left_height == -1:
			return -1
			
		right_height = dfs(root.right)
		if right_height == -1: # 优化：右边已经不平衡了，直接返回 -1 
			return -1

		if abs(right_height - left_height) < 2:
			return max(right_height, left_height) + 1
		else:
			return -1
	
	return dfs(root) != -1
```
