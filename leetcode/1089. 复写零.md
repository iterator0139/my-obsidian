给你一个长度固定的整数数组 `arr` ，请你将该数组中出现的每个零都复写一遍，并将其余的元素向右平移。

注意：请不要在超过该数组长度的位置写入元素。请对输入的数组 **就地** 进行上述修改，不要从函数返回任何东西。

**示例 1：**

**输入：**arr = [1,0,2,3,0,4,5,0]
**输出：**[1,0,0,2,3,0,0,4]
**解释：**调用函数后，输入的数组将被修改为：[1,0,0,2,3,0,0,4]

**示例 2：**

**输入：**arr = [1,2,3]
**输出：**[1,2,3]
**解释：**调用函数后，输入的数组将被修改为：[1,2,3]

**提示：**

- `1 <= arr.length <= 104`
- `0 <= arr[i] <= 9`

### 破局眼 🎯

先通过正向遍历，算出有多少个元素能“幸存”在最终的数组里，并找到最后一个幸存元素的索引。然后**从后往前**开始复写和移动，这样空出来的位置正好可以被直接覆盖，绝不会丢失数据。

⚠️ 核心陷阱：**边缘 0 的截断问题**。如果最后一个幸存的元素刚好是 0，且它只能放进数组一个位置（没空间复制第二个 0 了），需要特殊处理。

### 解法：双指针（从后往前填补）

Python

```
def duplicateZeros(arr: list[int]) -> None:
    n = len(arr)
    zeros = 0
    i = 0
    
    # 第一步：正向遍历，找出有多少个 0 可以被真正复写，并确定最后一个幸存元素的边界
    while i < n - zeros:
        if arr[i] == 0:
            # 特殊边界情况：如果这个 0 刚好是最后一个能塞进原数组的元素，但没有空间复写它了
            if i == n - zeros - 1:
                arr[n - 1] = 0  # 只能填一个 0 在末尾
                n -= 1          # 数组有效边界缩减 1
                break
            zeros += 1
        i += 1
        
    # 此时，从后往前填补的起点是 i - 1，要写入的目标位置是 n - 1
    src = i - 1
    dest = n - 1
    
    # 第二步：从后往前进行复写和移动 (O(N) 时间，不占用额外空间)
    while src >= 0:
        if arr[src] == 0:
            arr[dest] = 0
            dest -= 1
            arr[dest] = 0
        else:
            arr[dest] = arr[src]
        
        dest -= 1
        src -= 1
```

### 过程图解（arr = [1,0,2,3,0,4,5,0]）

**第一步（正向统计）：**

- `i=0` (1), `i=1` (0, `zeros=1`), `i=2` (2), `i=3` (3), `i=4` (0, `zeros=2`), `i=5` (4)。
    
- 此时 `i` 变成 6，由于 $6 \ge 8 - 2$，循环结束。
    
- 结论：真正能保留下来的元素到索引 `src = 5`（也就是数字 4）为止。后面的 `5, 0` 会被挤出数组。
    

**第二步（反向填补）：** `src = 5`，`dest = 7`

Plaintext

```
src=5 (4) -> 非0，移过去   -> arr[7]=4, dest降为6
src=4 (0) -> 是0，复写两个 -> arr[6]=0, arr[5]=0, dest降为4
src=3 (3) -> 非0，移过去   -> arr[4]=3, dest降为3
src=2 (2) -> 非0，移过去   -> arr[3]=2, dest降为2
src=1 (0) -> 是0，复写两个 -> arr[2]=0, arr[1]=0, dest降为0
src=0 (1) -> 非0，移过去   -> arr[0]=1, dest降为-1，结束
```

最终数组成功变为：`[1, 0, 0, 2, 3, 0, 0, 4]`

### 什么性质的题可以用这个解法？

本题本质是 **“就地（In-place）修改 + 元素膨胀/覆盖”** 的双指针逆序操作模式。

#### 必要条件

|**性质**|**本题体现**|**反例（不能用反向双指针）**|
|---|---|---|
|**就地修改（In-place）**|题目明确要求不能返回新数组，必须改原数组。|允许返回新数组 $\rightarrow$ 直接开辟新空间正向复制更简单。|
|**空间膨胀/覆盖**|遇到 0 长度要翻倍，后面的元素要整体右移。|元素删除/缩减（如移除指定元素） $\rightarrow$ 应该用**快慢指针正向遍历**。|
|**覆盖无害性**|从后往前写时，`dest` 永远在 `src` 的右边（或重合），不会覆盖还没处理的源数据。|数据互相依赖（如动态规划状态迁移） $\rightarrow$ 需要特定的遍历顺序。|

#### "就地数组修改" 破局决策树

Plaintext

```
需要在原数组上进行增/删/改操作？
  ├── 属于“删除”或者“压缩”元素（空间变小）
  │     └── ✅ 快慢指针（从左往右，慢指针在后面收数据）
  └── 属于“添加”或者“扩充”元素（空间变大/右移）
        └── ✅ 双指针（先算好最终边界，再从右往左倒序填补）
```
