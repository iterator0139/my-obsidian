给你一个非负整数 `num` ，请你返回将它变成 0 所需要的步数。 如果当前数字是偶数，你需要把它除以 2 ；否则，减去 1 。

**示例 1：**

**输入：**num = 14
**输出：**6
**解释：**
步骤 1) 14 是偶数，除以 2 得到 7 。
步骤 2） 7 是奇数，减 1 得到 6 。
步骤 3） 6 是偶数，除以 2 得到 3 。
步骤 4） 3 是奇数，减 1 得到 2 。
步骤 5） 2 是偶数，除以 2 得到 1 。
步骤 6） 1 是奇数，减 1 得到 0 。

**示例 2：**

**输入：**num = 8
**输出：**4
**解释：**
步骤 1） 8 是偶数，除以 2 得到 4 。
步骤 2） 4 是偶数，除以 2 得到 2 。
步骤 3） 2 是偶数，除以 2 得到 1 。
步骤 4） 1 是奇数，减 1 得到 0 。

**示例 3：**

**输入：**num = 123
**输出：**12

**提示：**

- `0 <= num <= 10^6`

---

## 破局眼 🎯

> **直接模拟，偶数 ÷2，奇数 −1，数步数就行。位运算也能做，但模拟已经够简单。**

### 解法一：模拟（够用）

```python
def numberOfSteps(self, num: int) -> int:
    steps = 0
    while num:
        if num % 2:
            num -= 1
        else:
            num //= 2
        steps += 1
    return steps
```

O(log n)，完全够用。

### 解法二：位运算（面试亮点）

```python
def numberOfSteps(self, num: int) -> int:
    if num == 0: return 0
    bits = num.bit_length()          # 二进制位数
    ones = bin(num).count('1')       # 1 的个数
    return bits + ones - 1
```

**为什么成立：**
- 每个 `1` 位需要 2 步（减 1 变成 0，然后除以 2 右移）
- 每个 `0` 位需要 1 步（除以 2 右移）
- 最高位的 `1` 只需要 1 步（最后一步减 1 变 0，不用再除 2）

**公式：** `steps = 位数 + 1的个数 - 1`

验证：num=14（1110，4位，3个1）→ 4+3-1=6 ✅

## 什么性质的题可以用这个解法？

本题本质是 **"按照固定规则模拟 + 可数学优化"** 模式。

| 性质 | 本题体现 | 反例 |
|------|---------|------|
| **规则确定、无分支** | 偶数÷2，奇数−1 | 规则有多个选择 → 决策问题 |
| **单调递减** | 每次操作 num 都变小 | 操作可能增大 → 无限循环 |
| **必然终止**（num ≥ 0） | 只会减到 0 | 可能死循环 |
| **小范围**（num ≤ 10⁶） | 最多约 20 步 | 范围极大 → 必须用位运算 O(1) |

**判断流程：**

```
题目是按固定规则把数字变到 0？
  ├── 规则简单、步数少 → ✅ 直接模拟
  └── 数据范围大 / 追求常数时间？
        ├── 规则和二进制位相关（±1, ÷2） → ✅ 位运算公式
        └── 规则复杂 → 模拟 + 记忆化加速
```
