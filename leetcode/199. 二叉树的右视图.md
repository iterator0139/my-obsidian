给定一个二叉树的 **根节点** `root`，想象自己站在它的右侧，按照从顶部到底部的顺序，返回从右侧所能看到的节点值。

**示例 1：**

**输入：**root = [1,2,3,null,5,null,4]

**输出：**[1,3,4]

**解释：**

**示例 2：**

**输入：**root = [1,2,3,4,null,null,null,5]

**输出：**[1,3,4,5]

**解释：**

![](https://assets.leetcode.com/uploads/2024/11/24/tmpkpe40xeh-1.png)

**示例 3：**

**输入：**root = [1,null,3]

**输出：**[1,3]

**示例 4：**

**输入：**root = []

**输出：**[]

**提示:**

- 二叉树的节点个数的范围是 `[0,100]`
- `-100 <= Node.val <= 100`

两种解法

解法一：层序遍历，把每层的最后一个加入结果列表
解法二：DFS深度遍历，右左根，每次第一次进入某一层的时候可以把答案加入

这里有个问题，右左根和右根左在这里有区别吗？
第二问题，怎么知道我们是第一次加入这一层，这里有个想法，结果列表其实就能带这个信息，如果结果列表的大小是3，那就说明已经去过3层了，那么当前level是4的时候我们就要加到结果列表，这样后面再进入第四层的时候就知道已经去过了。

这里必须要是根，右，左。因为你每次新到一层，需要把该节点就记录下来，才能通过结果列表维护已到的最大深度
