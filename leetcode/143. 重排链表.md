给定一个单链表 `L` 的头节点 `head`，单链表 `L` 表示为：

L0 → L1 → … → Ln - 1 → Ln

请将其重新排列后变为：

L0 → Ln → L1 → Ln - 1 → L2 → Ln - 2 → …

不能只是单纯的改变节点内部的值，而是需要实际的进行节点交换。

**示例 1：**

**输入：** head = [1,2,3,4]
**输出：** [1,4,2,3]

**示例 2：**

**输入：** head = [1,2,3,4,5]
**输出：** [1,5,2,4,3]

**提示：**

- 链表的长度范围为 `[1, 5 * 10^4]`
- `1 <= node.val <= 1000`

## 五分钟读题法分析

### 第一步：分析性质

#### 识别信号

> **原地重排链表、不能改值只能改指针 → 快慢指针找中点 + 反转后半段 + 交替合并；三件套组合题。**

#### 题目性质

- **数据规模**：n ≤ 5×10⁴，O(n) 必须
- **数据结构**：单链表
- **目标类型**：原地重排（改 next 指针，不改值）
- **操作特征**：前半与后半**交叉**拼接——`L0, Ln, L1, Ln-1, …`
- **模式信号**：找中点、反转、合并——三个独立技巧拼在一起

#### 性质 → 方法

| 性质 | 本题体现 | 若不满足则… |
|------|---------|------------|
| 原地改指针 | 不能新建节点存值 | 可新建 → 数组存值再重连 |
| 前后半交叉 | 前半第 i 个接后半第 n-1-i 个 | 简单拼接 → 直接 merge |
| 需知道中点 | 快慢指针 O(n) | 数组 → 可直接双指针 |
| 后半要逆序访问 | 反转后半链表 | 栈存后半 → O(n) 空间 |

**判断流程**：

```
单链表原地重排，前后半交叉？
  ├── 找中点断开 → 快慢指针 ✅
  ├── 后半逆序 → 反转链表 ✅
  └── 两半交替合并 → 双指针改 next ✅
```

#### 方法约束

- **约束**：三步都 O(n)、O(1) 额外空间；合并时先保存 `next` 再改指针，避免断链
- **本题**：满足
- **易混淆**：中点断开位置——奇数长度时中点归前半（后半更短），如 `1→2→3→4→5` 断在 3 后

### 第二步：读题与盲猜

**题目核心**：把链表重排成 `L0→Ln→L1→Ln-1→…`，只能改指针。

**第一直觉**：把值放进数组，按新顺序重连——O(n) 但 O(n) 空间，不满足「原地」精神。

**盲猜优化方向**：

- **数据结构**：快慢指针 + 原地反转 + 交替 merge
- **时间复杂度**：O(n)
- **关键洞察**：交叉拼接 = 前半 `1→2→3` 与后半逆序 `5→4` 交替取节点 → `1→5→2→4→3`

### 第三步：最优解法

#### 核心转换

```
原链表：  1 → 2 → 3 → 4 → 5
Step1 找中点断开：
          1 → 2 → 3    4 → 5
Step2 反转后半：
          1 → 2 → 3    5 → 4
Step3 交替合并：
          1 → 5 → 2 → 4 → 3
```

#### 三步破局

**① 快慢指针找中点并断开**

```
slow, fast = head, head
while fast and fast.next:
    slow = slow.next
    fast = fast.next.next
second = slow.next
slow.next = None    # 断开，前半以 head 结尾
```

`slow` 停在前半最后一个节点；奇数长度时中点归前半。

**② 反转后半链表**

```
prev = None
while second:
    nxt = second.next
    second.next = prev
    prev = second
    second = nxt
second = prev         # second 现在是反转后的头
```

**③ 交替合并两半**

```
first = head
while second:
    tmp1 = first.next
    tmp2 = second.next
    first.next = second
    second.next = tmp1 if tmp1 else None
    first = tmp1
    second = tmp2
```

#### 关键实现细节

- **先断开再反转**：避免反转时影响前半
- **合并时保存 next**：改指针前先 `tmp1 = first.next`、`tmp2 = second.next`
- **奇数长度**：多出的中点节点自然留在前半末尾（如 `1→5→2→4→3` 的 3）
- **fast 初始为 head**：找的是「前半尾节点」，不是中点下一个

### 核心代码（Python）

```python
def reorderList(head: Optional[ListNode]) -> None:
    if not head or not head.next:
        return

    # 1. 找中点并断开
    slow, fast = head, head
    while fast and fast.next:
        slow = slow.next
        fast = fast.next.next
    second = slow.next
    slow.next = None

    # 2. 反转后半
    prev = None
    while second:
        nxt = second.next
        second.next = prev
        prev = second
        second = nxt
    second = prev

    # 3. 交替合并
    first = head
    while second:
        tmp1, tmp2 = first.next, second.next
        first.next = second
        second.next = tmp1
        first = tmp1
        second = tmp2
```

### 第四步：拆解记忆点

#### 一句话破局眼

> **LeetCode 143 重排链表：快慢指针找中点断开 → 反转后半 → 两半交替 merge。**

#### 复杂度对比

| 方法 | 时间复杂度 | 空间复杂度 | 适用性 |
|------|-----------|-----------|--------|
| 数组存值再重连 | O(n) | O(n) | 直观但不原地 |
| **三步法** | **O(n)** | **O(1)** | **本题最优** |

#### 关键理解点

1. **为什么是三步？** 交叉取节点 = 前半正序 + 后半逆序 + 交替拼接，各需一个技巧
2. **中点怎么断？** `slow` 停在前半末尾，`slow.next = None`；奇数时中点留在前半
3. **合并为何先存 next？** 改 `first.next = second` 会丢原 `first.next`，必须先备份
4. **和 206 / 21 的关系**：206 反转模板；21 合并两链；143 = 找中点 + 206 + 变形 21
