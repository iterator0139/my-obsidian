给定一个二叉树, 找到该树中两个指定节点的最近公共祖先。

[百度百科](https://baike.baidu.com/item/%E6%9C%80%E8%BF%91%E5%85%AC%E5%85%B1%E7%A5%96%E5%85%88/8918834?fr=aladdin)中最近公共祖先的定义为：“对于有根树 T 的两个节点 p、q，最近公共祖先表示为一个节点 x，满足 x 是 p、q 的祖先且 x 的深度尽可能大（**一个节点也可以是它自己的祖先**）。”

**示例 1：**

![](https://assets.leetcode.com/uploads/2018/12/14/binarytree.png)

**输入：**root = [3,5,1,6,2,0,8,null,null,7,4], p = 5, q = 1
**输出：**3
**解释：**节点 `5` 和节点 `1` 的最近公共祖先是节点 `3 。`

**示例 2：**

![](https://assets.leetcode.com/uploads/2018/12/14/binarytree.png)

**输入：**root = [3,5,1,6,2,0,8,null,null,7,4], p = 5, q = 4
**输出：**5
**解释：**节点 `5` 和节点 `4` 的最近公共祖先是节点 `5 。`因为根据定义最近公共祖先节点可以为节点本身。

**示例 3：**

**输入：**root = [1,2], p = 1, q = 2
**输出：**1

**提示：**

- 树中节点数目在范围 `[2, 105]` 内。
- `-109 <= Node.val <= 109`
- 所有 `Node.val` `互不相同` 。
- `p != q`
- `p` 和 `q` 均存在于给定的二叉树中。

对于p和q的最近公共祖先a来说，需要满足

1 a的左子树有p，右子树有q
2 a的左子树有q，右子树有p
3 a是p，a的左子树或者右子树有q
4 a是q，a的左子树或者右子树有p

dfs的定义是是否找到p或者q，如果找到了就返回p或者q

对节点r来说，
如果节点是p或者q就返回该节点
如果节点的左右子树分别找到了p和q，那返回什么呢？这里dfs定义是返回p或者q
如果只找到一个节点，那就返回该节点


***上面的分析dfs定义出错了，我们要知道的是答案候选***

dfs返回的是“node 这棵子树里面，已经确定的最近公共祖先结果”
```
dfs(node) 返回：

1. nil
   说明这棵子树没有 p/q

2. p 或 q
   说明这棵子树只找到了其中一个

3. LCA节点
   说明这棵子树已经找到了最近公共祖先
```

如果题目不保证同时有p或者q，确实不能这么定义，因为如果只有p，最后传导回去的会是p

如果不保证的话，需要同时传导多个信息，包括node，foundP，foundQ信息
```
func lowestCommonAncestor(root, p, q *TreeNode) *TreeNode {
    node, foundP, foundQ := dfs(root, p, q)
    if foundP && foundQ {
        return node
    }
    return nil
}

func dfs(root, p, q *TreeNode) (*TreeNode, bool, bool) {
    if root == nil {
        return nil, false, false
    }

    leftNode, lp, lq := dfs(root.Left, p, q)
    rightNode, rp, rq := dfs(root.Right, p, q)

    foundP := lp || rp || root == p
    foundQ := lq || rq || root == q

    // 当前节点是 LCA 的条件
    if root == p || root == q {
        return root, foundP, foundQ
    }

    if leftNode != nil && rightNode != nil {
        return root, foundP, foundQ
    }

    if leftNode != nil {
        return leftNode, foundP, foundQ
    }

    return rightNode, foundP, foundQ
}
```
