给你两个长度相同的字符串，`s` 和 `t`。

将 `s` 中的第 `i` 个字符变到 `t` 中的第 `i` 个字符需要 `|s[i] - t[i]|` 的开销（开销可能为 0），也就是两个字符的 ASCII 码值的差的绝对值。

用于变更字符串的最大预算是 `maxCost`。在转化字符串时，总开销应当小于等于该预算，这也意味着字符串的转化可能是不完全的。

如果你可以将 `s` 的子字符串转化为它在 `t` 中对应的子字符串，则返回可以转化的最大长度。

如果 `s` 中没有子字符串可以转化成 `t` 中对应的子字符串，则返回 `0`。

**示例 1：**

**输入：**s = "abcd", t = "bcdf", maxCost = 3
**输出：**3
**解释：**s 中的 "abc" 可以变为 "bcd"。开销为 3，所以最大长度为 3。

**示例 2：**

**输入：**s = "abcd", t = "cdef", maxCost = 3
**输出：**1
**解释：**s 中的任一字符要想变成 t 中对应的字符，其开销都是 2。因此，最大长度为 `1。`

**示例 3：**

**输入：**s = "abcd", t = "acde", maxCost = 0
**输出：**1
**解释：**a -> a, cost = 0，字符串未发生变化，所以最大长度为 1。

**提示：**

- `1 <= s.length <= 105`
- `t.length == s.length`
- `0 <= maxCost <= 106`
- `s` 和 `t` 都只含小写英文字母。

## 破局眼 🎯

> **每个位置算一个 cost，然后用滑动窗口找最长的连续段使其和 ≤ maxCost。**

⚠️ **不是"从小到大排序取最小"**——那是子序列的做法，但本题要求**连续子串**，排序会破坏连续性。

### 解法：滑动窗口

```python
def equalSubstring(self, s: str, t: str, maxCost: int) -> int:
    n = len(s)
    left = cur_cost = 0
    ans = 0

    for right in range(n):
        cur_cost += abs(ord(s[right]) - ord(t[right]))

        while cur_cost > maxCost:
            cur_cost -= abs(ord(s[left]) - ord(t[left]))
            left += 1

        ans = max(ans, right - left + 1)

    return ans
```

**过程图解（s="abcd", t="bcdf", maxCost=3）：**

```
cost: [1, 0, 1, 2]

right=0, cost=1            → cur=1, 窗口=[0,0], len=1
right=1, cost=0            → cur=1, 窗口=[0,1], len=2
right=2, cost=1            → cur=2, 窗口=[0,2], len=3
right=3, cost=2 → cur=4>3 → left右移, cur=3 → 窗口=[1,3], len=3
                                                   ↑ ans=3
```

也可以用**二分答案**（对长度二分，判断是否存在长度为 mid 的窗口满足条件），但滑动窗口 O(n) 已经最优。

## 什么性质的题可以用这个解法？

本题本质是 **"连续子数组 + 和约束"** 的滑动窗口模式。

### 必要条件

| 性质 | 本题体现 | 反例（不能用滑动窗口） |
|------|---------|---------------------|
| **要求连续**（子串/子数组） | 子字符串 | 子序列（可不连续）→ 排序贪心 |
| **约束是子段的和** | 总 cost ≤ maxCost | 约束是子段极值（max-min）→ 单调队列 |
| **单调性**：扩窗和增大，缩窗和减小 | 加入右边 cost+，移走左边 cost- | 无单调性 → 前缀和 + 二分 |
| **求最长** | 最大长度 | 求最短 → 也是滑动窗口（不同收缩逻辑） |

### "子串 vs 子序列" 判断

```
问题要求从 s 中选取一段？
  ├── 必须连续 → 子串/子数组
  │     ├── 条件满足单调性 → ✅ 滑动窗口
  │     └── 条件有负值（不单调）→ 前缀和 + 单调队列
  └── 可以不连续 → 子序列
        ├── 排序不影响结果 → ✅ 排序贪心 / 计数
        └── 排序影响结果（需保序）→ DP
```

### 同类题

| 题目 | 约束 | 解法 |
|------|------|------|
| **LC 1208 等子串** | **cost 和 ≤ maxCost** | **滑动窗口** |
| LC 209 长度最小子数组 | 和 ≥ target | 滑动窗口 |
| LC 424 替换后的最长重复字符 | 最多替换 k 次 | 滑动窗口 + 频次统计 |
| LC 1004 最大连续1的个数 III | 最多翻转 k 个 0 | 滑动窗口 |

> **滑动窗口的万能条件：窗口扩大让约束变紧（如和变大/种类变多），缩小让约束变松。满足这个单调性就可以用。**
