## 性质 → 算法：核心识别信号（速记）

> 完整版：[[skills/leetcode-five-minute-read/property-algorithm-mapping.md]]

| 想到… | 识别信号（一句话） |
|-------|------------------|
| **栈** | 新元素只和「已处理结果的最后一个」发生关系（相邻配对、嵌套、可撤销） |
| **单调栈** | 每个元素要找左/右 **第一个** 更大/更小的邻居 |
| **对撞双指针** | 有序 + 移一边会让答案单调变大/变小 |
| **滑动窗口** | 连续子串/子数组 + 扩窗时约束统计量单调变差 |
| **哈希** | 需要 O(1) 查「见过吗 / 频次 / 补数」 |
| **DP** | 当前选择影响未来 + 子问题重叠 |
| **二分** | 答案或位置有单调性，可丢一半 |
| **堆** | 只要最大/最小的 K 个，不需全局有序 |

## 解题框架速查（读题 1 分钟内快速判断）

### 1. 滑动窗口 → 单调队列 / 双指针

```
问题是否求连续子数组/子串？
  ├── 否 → 不用滑动窗口
  └── 是 → 约束条件是否关于窗口的”统计量”（max/min/sum/unique count）？
        ├── 否 → 不用
        └── 是 → 窗口移动时统计量能 O(1) 维护？
              ├── 否 → 考虑有序容器 O(n log n)
              └── 是 → ✅ 滑动窗口 + 单调队列 / 双指针
```

**窗口单调性条件**（必满足）：窗口越大条件越难满足（或越容易），扩窗变差缩窗变好。

| 约束类型 | 数据结构 | 代表题 |
|---------|---------|-------|
| `max - min ≤ limit` | 两个 deque | LC 1438 |
| 窗口 max | 一个 deque（单调递减） | LC 239 |
| 和/积 ≤ target | 双指针 | LC 209 |
| 窗口内字符覆盖 | 哈希表 + 双指针 | LC 76 |

### 2. 子数组/子序列 → 动态规划

```
求最值/方案数/可行性？
  ├── 子数组（连续）→ 一维 DP /  Kadane
  ├── 子序列（不连续）→ 二维 DP
  └── 两个序列/字符串 → 二维 DP（LCS / 编辑距离）
```

### 3. 下一个更大/更小元素 → 单调栈

```
求每个元素右侧/左侧第一个比它大/小的元素？
  ├── 求更大 → 单调递减栈（遇到更大的结算）
  └── 求更小 → 单调递增栈（遇到更小的结算）
```

### 4. Top K / 第 K 大 → 堆 / 快速选择

```
求前 K 大/小 或 第 K 大/小？
  ├── 数据量大 → 堆 O(n log k)
  └── 数据量小 → 排序 O(n log n)
```

### 5. 两数/三数/四数之和 → 双指针 / 哈希表

```
求特定和的组合？
  ├── 无序数组 → 哈希表
  ├── 有序数组 → 双指针
  └── 多个数 → 固定一个 + 双指针
```

### 6. 数组有序 / 排序相关

```
数组是否有序？
  ├── 已排序 → 二分查找 / 双指针
  ├── 部分有序（旋转） → 变种二分
  └── 未排序 → 看数据范围决定暴力/哈希/排序
```

### 7. 小数据量 → 暴力

```
数据范围：
  ├── n ≤ 20    → 回溯 / 状态压缩
  ├── n ≤ 100   → O(n³) 暴力
  ├── n ≤ 1000  → O(n²) 双循环
  ├── n ≤ 10^5  → O(n log n) 排序/二分
  └── n ≤ 10^6  → O(n) 贪心/哈希/滑动窗口
```

> **破局第一步不是想算法，而是根据题目特征快速定位到上述某一大类。大类定对了，细节解法呼之欲出。**
