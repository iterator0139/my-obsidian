给定一个只包括 `'('`，`')'`，`'{'`，`'}'`，`'['`，`']'` 的字符串 `s` ，判断字符串是否有效。

有效字符串需满足：

1. 左括号必须用相同类型的右括号闭合。
2. 左括号必须以正确的顺序闭合。
3. 每个右括号都有一个对应的相同类型的左括号。

**示例 1：**

**输入：**s = "()"

**输出：**true

**示例 2：**

**输入：**s = "()[]{}"

**输出：**true

**示例 3：**

**输入：**s = "(]"

**输出：**false

**示例 4：**

**输入：**s = "([])"

**输出：**true

**示例 5：**

**输入：**s = "([)]"

**输出：**false

**提示：**

- `1 <= s.length <= 104`
- `s` 仅由括号 `'()[]{}'` 组成

用栈就能解决。只维护openleft的个数我看也可以


```
def validParathese(s: str) -> bool:
	stack = []
	char_mapping = {
		"(": ")",
		"[": "]",
		"{": "}"
	}
	for char in s:
		if char in char_mapping.keys():
			stack.append(char_mapping[char])
		else:
			if not stack or stack[-1] != char:
				return False
			else:
				stack.pop()
	# 这里一个错误点，最后如果栈不为空时，也是非法的，所以这里要返回最后栈的长度是否等于0
	return len(stack) == 0
```
