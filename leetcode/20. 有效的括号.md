给定一个只包括 `'('`，`')'`，`'{'`，`'}'`，`'['`，`']'` 的字符串 `s` ，判断字符串是否有效。

有效字符串需满足：

1. 左括号必须用相同类型的右括号闭合。
2. 左括号必须以正确的顺序闭合。
3. 每个右括号都有一个对应的相同类型的左括号。

**示例 1：**

**输入：**s = "()"
**输出：**true

**示例 2：**

**输入：**s = "()[]{}"
**输出：**true

**示例 3：**

**输入：**s = "(]"
**输出：**false

**示例 4：**

**输入：**s = "([])"
**输出：**true

**示例 5：**

**输入：**s = "([)]"
**输出：**false

**提示：**

- `1 <= s.length <= 104`
- `s` 仅由括号 `'()[]{}'` 组成

## 五分钟读题法分析

### 第一步：分析性质

#### 识别信号

> **嵌套结构、后开的先关——当前右括号只需和「最近还没闭合的左括号」配对，天然 LIFO，想到栈。**

#### 题目性质

- **数据规模**：n ≤ 10⁴，线性扫描 O(n) 足够
- **数据结构**：只含 6 种括号的字符串
- **目标类型**：可行性判断（是否有效）
- **范围约束**：必须按顺序闭合，不能交叉（`([)]` 非法）
- **操作特征**：左括号「入栈等待」，右括号「立刻与栈顶匹配」

#### 性质 → 方法

| 性质             | 本题体现                 | 若不满足则…                      |
| -------------- | -------------------- | --------------------------- |
| 嵌套 / 后开先关      | `([])` 内层先闭合         | 无嵌套、只相邻配对 → 普通栈消相邻（LC 1047） |
| 多种括号类型         | `()` `[]` `{}` 须类型一致 | 只有一种 `()` → 可用计数器代替栈        |
| 右括号只依赖最近未闭合左括号 | 栈顶即「当前待闭合」           | 需和任意远位置配对 → 哈希 / 预处理        |
| 线性扫描、不回溯       | 从左到右一次遍历             | 需全局最优嵌套 → DP（LC 32）         |

**判断流程**：

```
括号匹配 / 嵌套闭合？
  ├── 多种类型或需记「哪种左括号」？
  │     ├── 是 → ✅ 栈（存左括号或期望右括号）
  │     └── 否，仅 () → 计数器即可
  └── 求最长有效子串？
        ├── 是 → DP / 栈扩展（LC 32）
        └── 否，整串判断 → ✅ 栈 O(n)
```

#### 方法约束

- **约束**：栈方案要求「当前右括号只与最后一个未闭合左括号有关」；扫描结束后栈必须为空
- **本题**：满足。三种括号都符合 LIFO 嵌套模型
- **易混淆**：
  - **「只维护左括号个数」不够**——`"([)]"` 左右数量相等但类型交叉；`"(]"` 数量也对但类型错。单类型 `()` 时计数器等价于栈
  - 不是单调栈——不找「下一个更大」，只做配对弹出

### 第二步：读题与盲猜

**题目核心**：判断括号串是否按类型、顺序全部正确闭合。

**第一直觉**：用栈。遇左括号 push，遇右括号看栈顶是否是对应左括号，匹配则 pop，否则 false。

**盲猜优化方向**：

- **数据结构**：栈（或哈希表存「左→右」映射）
- **时间复杂度**：O(n)
- **关键洞察**：栈里存**期望的右括号**（或存左括号再查表），右括号到来时只和栈顶比——O(1) 判定，无需回头扫描

### 第三步：最优解法

#### 核心转换

```
有效括号串
  ⇔ 线性扫描中，每个右括号都能与「当前最后一个未闭合左括号」同类型配对，且最终无残留
```

#### 状态定义

- `stack`：尚未闭合的左括号对应的**期望右括号**（从底到顶 = 从外到内的嵌套顺序）

#### 核心状态转移（破局眼）

```python
if c 是左括号: stack.append(对应的右括号)
else:          # 右括号
    if not stack or stack[-1] != c: return False
    stack.pop()
return len(stack) == 0
```

#### 关键实现细节

- **两种写法等价**：栈存左括号 `(`，遇 `)` 时查 `mapping[stack.pop()]`；或直接存期望右括号 `)`，遇右括号直接比栈顶
- **右括号到来时栈空** → 没有左括号可配，立刻 `False`（如 `")"`）
- **扫描结束栈非空** → 还有未闭合左括号，如 `"("`、`"([{"`
- **类型必须一致**：`stack[-1] != c` 覆盖 `(]`、`([)]` 等情况
- **常见漏写**：循环结束后忘记检查 `len(stack) == 0`

### 核心代码（Python）

```python
def isValid(s: str) -> bool:
    stack = []
    pairs = {"(": ")", "[": "]", "{": "}"}

    for c in s:
        if c in pairs:
            stack.append(pairs[c])  # 存期望的右括号
        else:
            if not stack or stack[-1] != c:
                return False
            stack.pop()

    return len(stack) == 0
```

**单类型 `()` 的计数器写法**（本题三种括号不适用，但帮助理解栈的本质）：

```python
def isValidSingleType(s: str) -> bool:
    cnt = 0
    for c in s:
        if c == "(": cnt += 1
        else:
            if cnt == 0: return False
            cnt -= 1
    return cnt == 0
```

### 第四步：拆解记忆点

#### 一句话破局眼

> **LeetCode 20 有效的括号：栈维护「待闭合」的嵌套顺序；左进（存期望右括号），右来比对栈顶，扫完栈空才合法。**

#### 复杂度对比

| 方法 | 时间 | 空间 | 适用性 |
|------|------|------|--------|
| 计数器（仅 `()`） | O(n) | O(1) | 单类型可行 |
| 栈 | O(n) | O(n) 最坏 | ✅ 多类型 + 嵌套 |
| 暴力回溯 | 指数级 | — | 不适用 |

#### 关键理解点

1. **为什么不能只数左括号个数？** 三种类型 + 顺序约束：数量相等不代表配对正确，`"([)]"` 和 `"(]"` 都会误判为合法。
2. **为什么栈顶就够？** 嵌套保证「下一个要闭合的」一定是最后入栈的那个；更早的左括号被包在里面，还没轮到。
3. **为什么结束要判栈空？** 右括号都配完了，但左括号还有剩（如 `"((("`）——循环不会报错，必须显式检查。
4. **存左括号还是存期望右括号？** 存期望右括号时，遇右括号直接 `stack[-1] == c`，代码更短；存左括号则 pop 后查映射，逻辑等价。
