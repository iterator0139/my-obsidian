给定整数数组 `nums` 和整数 `k`，请返回数组中第 `**k**` 个最大的元素。

请注意，你需要找的是数组排序后的第 `k` 个最大的元素，而不是第 `k` 个不同的元素。

你必须设计并实现时间复杂度为 `O(n)` 的算法解决此问题。

**示例 1:**

**输入:** `[3,2,1,5,6,4],` k = 2
**输出:** 5

**示例 2:**

**输入:** `[3,2,3,1,2,4,5,5,6],` k = 4
**输出:** 4

**提示：**

- `1 <= k <= nums.length <= 105`
- `-104 <= nums[i] <= 104`


两种解法
第一种维护一个大小为K的小顶堆，遍历完所有数组，返回堆顶即可。算法复杂度
堆操作复杂度，大小为K的堆，push操作O(logk)，pop操作O(logk)
整个循环都会heap的push，最多还会heapPop，每轮最多是O(logk)+O(logk)，常数忽略，仍然是O(logk)。一共循环n次，所以复杂度：O(nlogk)

第二种使用快速排序的思想，找第K大的数，实际就是找索引为(n-k+1)的元素。
快排中，每次选择一个位置，然后把所有大的位置放他右边，把所有小的位置放他左边，这样就能得到他的位置。


```
import heapq

def findKthElement(nums: List[int], k: int) -> int:
	heap = []
	for i, num in enumerate(nums):
		if len(heap) < k:
			heapq.heappush(heap, num)
		else:
			if num > heap[0]:
				heapq.heapreplace(heap, num)
	return heap[0]

```

def findKthElement(nums: List[int], k: int) -> int:
	
	pivot = partition()
	
	# 要找第k大的数，也就是索引位置要等于 n - k
	# 如果pivot小于n - k，这个时候答案在pivot的右边，然后还要更新第k
	# 如果pivot大于n - k，这个时候答案在pivot的左边，这个时候要在左边找，更新第k大变成right - p - 1
	
	n = len(nums) # 核心映射：第 k 个最大的元素，对应的升序索引是 target 
	target = n - k
	
	def quick_select(nums: List[int], left: int, right: int):
		pivot_index = random.randint(left, right) 
		pivot = nums[pivot_index]
		
		lt = left
		gt = right
		i = left
		while i <= gt:
			if nums[i] > pivot # 发现比基准大的值，放到gt位置上
				nums[gt], nums[i] = nums[i], nums[gt]
				gt -= 1# 不能更新i，因为换过来的数字还没处理
			elif nums[i] < pivot # 发现比基准小的值，放到lt位置上
				nums[lt], nums[i] = nums[i], nums[lt]
				lt += 1
				i += 1
			else:
				i += 1
				
		# 这个时候数组分成了三段，我们检查target落在哪一段
		
		# [left, lt - 1] 是小于区 
		# [lt, gt] 是等于区 (里面的值全部等于 pivot) 
		# [gt + 1, right] 是大于区 
		# 检查我们的目标索引 target 落在哪个区域 
		if lt <= target <= gt: 
			# 极其幸运！目标索引正好落在等于区，直接找到了答案！ 
			return nums[target] 
		elif target < lt: 
			# 目标在左边，无情抛弃中、右两部分，只递归左边 
			return quick_select(left, lt - 1) 
		else: 
			# 目标在右边，无情抛弃左、中两部分，只递归右边 
			return quick_select(gt + 1, right)
