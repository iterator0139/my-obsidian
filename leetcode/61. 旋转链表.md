给你一个链表的头节点 `head`，旋转链表，将链表每个节点向右移动 `k` 个位置，其中 `k` 是非负数。

**示例 1：**

```
输入：head = [1,2,3,4,5], k = 2
输出：[4,5,1,2,3]
```

**示例 2：**

```
输入：head = [0,1,2], k = 4
输出：[2,0,1]
```

**提示：**

- 链表中节点的数目在范围 `[0, 500]` 内
- `-100 <= Node.val <= 100`
- `0 <= k <= 2 * 10^9`

---

## 五分钟读题法分析

### 第一步：分析性质

#### 识别信号

> **链表向右旋转 k 位 = 尾部 k 个结点移到前面；先求长度，k 对长度取模，找新尾结点断链再成环。**

#### 题目性质

- **数据规模**：节点 ≤ 500，但 k 可达 2×10⁹，必须 `k % n`
- **数据结构**：单向链表
- **目标类型**：原地改指针，返回新头
- **范围约束**：向右旋转，等价于新头 = 原链表第 `n - k` 个结点（0-indexed）
- **操作特征**：需要知道链表长度和尾结点

#### 性质 → 方法

| 性质 | 本题体现 | 若不满足则… |
|------|---------|------------|
| 旋转 = 尾部拼接 | 尾 k 个挪到前面 | 单步反转 → 反转链表题 |
| k 可能远大于 n | `k %= n` | 忘取模会多走/ TLE |
| 需定位断点 | 新尾在 `n-k-1` 位置 | 数组旋转 → 三次反转 |
| 需尾结点接回头 | 成环后断在新尾 | 只断不接会丢段 |

**判断流程**：

```
链表旋转 k 位？
  ├── 先遍历求 n 和 tail
  ├── k %= n，k==0 直接返回
  └── tail.next = head 成环 → 走 n-k-1 步找新尾 → 断开 → 返回新头
```

#### 方法约束

- **约束**：「成环再断」需要能在 O(n) 内找到新尾位置
- **本题**：满足。新尾 = 从头走 `n - k - 1` 步
- **易混淆**：
  - LC 19 删倒数第 N 个：快慢指针；本题要长度 + 改指针
  - LC 33 旋转 **数组** 搜索：二分；本题是链表指针重连

### 第二步：读题与盲猜

**题目核心**：向右旋转 k 位，返回新头结点。

**第一直觉**：把最后 k 个结点值记下来，整体右移，再填回去。需要额外数组或多次遍历，且链表应改指针而非改值。

**盲猜优化方向**：

- **数据结构**：一趟求 `n` + 尾结点，二趟找断点
- **时间复杂度**：O(n)
- **关键洞察**：`k=2` 于 `[1,2,3,4,5]` → 变 `[4,5,1,2,3]`，即新头在原下标 `n-k` 处

---

### 第三步：最优解法

#### 核心转换

```
向右旋转 k 位
  ⇔ 新头 = 原链表倒数第 k 个结点（即正数第 n-k+1 个）
  ⇔ 在「新头」前一个结点处断链，尾结点接到旧头
```

#### 状态定义

- `n`：链表长度
- `tail`：原尾结点
- `new_tail`：走 `n - k - 1` 步到达的结点
- `new_head = new_tail.next`

#### 核心状态转移（破局眼）

```python
k %= n
if k == 0: return head

tail.next = head          # 1. 成环
# 从头走 n-k-1 步到 new_tail
new_head = new_tail.next
new_tail.next = None      # 2. 断开
return new_head
```

#### 关键实现细节

- **`k %= n` 必做**：`k=4` 于长度 3 的链表 ≡ 旋转 1 位
- **`n==0` 或 `n==1`**：`k%=n` 后为 0，直接返回
- **先成环再断**：`tail.next = head` 后，从 head 走 `n-k-1` 步到 `new_tail`；断 `new_tail.next` 即得 `4→5→1→2→3`
- **走步数**：`n-k-1` 步到 **新尾**，不是 `n-k` 步（那是新头）
- **不要用快慢指针**：快慢适合「未知 n 找倒数第 k」，本题先数长度更直接

### 核心代码（Python）

```python
def rotateRight(head: ListNode, k: int) -> ListNode:
    if not head or not head.next:
        return head

    n = 1
    tail = head
    while tail.next:
        tail = tail.next
        n += 1

    k %= n
    if k == 0:
        return head

    tail.next = head

    cur = head
    for _ in range(n - k - 1):
        cur = cur.next

    new_head = cur.next
    cur.next = None
    return new_head
```

### 第四步：拆解记忆点

#### 一句话破局眼

> **LeetCode 61 旋转链表：k%=n，尾接头成环，走 n-k-1 步找新尾，断开即新头。**

#### 复杂度对比

| 方法 | 时间 | 空间 | 适用性 |
|------|------|------|--------|
| 拷贝值旋转 | O(n) | O(n) | 不符合链表题意 |
| 成环 + 断链 | O(n) | O(1) | ✅ 最优 |

#### 关键理解点

1. **为什么 k 要取模？** 旋转 n 圈回到原状；k 可达 10⁹。
2. **为什么是 n-k-1 步？** 新头在倒数第 k 个，新尾在其前一个；走 n-k-1 步到 new_tail。
3. **为什么要先成环？** 断开后尾结点 `tail` 自然通过环接到 `new_head`，形成 `new_head→…→tail→…→new_tail` 的正确顺序。
4. **和 LC 19 的关系**：都涉及「倒数第 k」，19 用快慢指针一趟；61 先数长度再定位，因为还要改尾指针成环。
