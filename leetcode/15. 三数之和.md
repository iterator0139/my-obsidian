给你一个整数数组 `nums`，判断是否存在三元组 `[nums[i], nums[j], nums[k]]` 满足 `i != j`、`i != k` 且 `j != k`，同时还满足 `nums[i] + nums[j] + nums[k] == 0`。请你返回所有和为 `0` 且 **不重复** 的三元组。

**注意：** 答案中不可以包含重复的三元组。

**示例 1：**

```
输入：nums = [-1,0,1,2,-1,-4]
输出：[[-1,-1,2],[-1,0,1]]
解释：
nums[0] + nums[1] + nums[2] = (-1) + 0 + 1 = 0 。
nums[1] + nums[2] + nums[4] = 0 + 1 + (-1) = 0 。
nums[0] + nums[3] + nums[4] = (-1) + 2 + (-1) = 0 。
不同的三元组是 [-1,0,1] 和 [-1,-1,2] 。
注意，输出的顺序和三元组的顺序并不重要。
```

**示例 2：**

```
输入：nums = [0,1,1]
输出：[]
解释：唯一可能的三元组和不为 0 。
```

**示例 3：**

```
输入：nums = [0,0,0]
输出：[[0,0,0]]
解释：唯一可能的三元组和为 0 。
```

**提示：**

- `3 <= nums.length <= 3000`
- `-10^5 <= nums[i] <= 10^5`

## 五分钟读题法分析

### 第一步：分析性质

#### 识别信号

> **从 n 个数里选 3 个凑和为 0，无序数组先排序，固定一个数后剩下两数之和变成有序数组上的夹逼问题。**

#### 题目性质

- **数据规模**：n ≤ 3000，O(n³) 暴力会 TLE，需要 O(n²)
- **数据结构**：无序整数数组
- **目标类型**：找 **所有** 满足条件的组合（不是只找一个）
- **范围约束**：三个不同下标，元素可重排；答案三元组不能重复
- **单调性**：排序后，移 left → 和变大；移 right → 和变小

#### 性质 → 方法

| 性质        | 本题体现           | 若不满足则…                |
| --------- | -------------- | --------------------- |
| 选 k 个数凑和  | k=3，目标和 0      | k=2 → 两数之和；k=4 → 四数之和 |
| 无序但顺序无关   | 只要求和为 0        | 有位置约束 → 不能先排序         |
| 排序后双指针有方向 | 和太小移左、太大移右     | 移两边都可能变好 → 不能夹逼       |
| 要收集所有解    | 命中时 append 并继续 | 只求一个 → LC 16，不用去重     |
| 有重复元素     | 三层去重           | 无重复 → 可省略 skip 逻辑     |

**判断流程**：

```
从数组选 3 个数，和为固定值？
  ├── 无序、顺序无关 → 先排序
  └── 固定 nums[i] 后
        └── 剩余段 [i+1, n-1] 上双指针找两数之和 = -nums[i]
              ├── sum < 0 → left++
              ├── sum > 0 → right--
              └── sum == 0 → 记录 + 双指针同时跳过重复
```

#### 方法约束

- **约束**：对撞双指针需要排序后「移左单调增、移右单调减」
- **本题**：满足。固定 `i` 后，`left/right` 夹逼两数之和
- **易混淆**：
  - LC 16 最接近三数之和：同框架，但维护最接近值、`sum==target` 早停、**不用去重**
  - LC 18 四数之和：再套一层固定 `j`，内层仍是双指针

### 第二步：读题与盲猜

**题目核心**：找出所有不重复的三元组，使三数之和为 0。

**第一直觉**：三重循环枚举 (i, j, k)，用 set 去重。O(n³) + 去重开销，n=3000 会 TLE。

**盲猜优化方向**：

- **数据结构**：排序 + 固定 i + 双指针
- **时间复杂度**：O(n²)
- **关键洞察**：固定 `nums[i]` 后，问题变成「有序数组找两数之和 = -nums[i]」——和两数之和一模一样，只是多了外层枚举 + 去重

### 第三步：最优解法

#### 核心转换

```
三数之和为 0
  ⇔ 固定 nums[i]，在 nums[i+1..n-1] 找两数之和 = -nums[i]
```

#### 状态定义

- 外层 `i`：第一个数的位置（排序后枚举）
- `left = i + 1`，`right = n - 1`：夹逼剩余两数
- `res`：收集所有不重复三元组

#### 核心状态转移（破局眼）

```python
s = nums[i] + nums[left] + nums[right]
if s < 0:  left += 1
elif s > 0: right -= 1
else:
    res.append([nums[i], nums[left], nums[right]])
    left += 1; right -= 1
    while left < right and nums[left] == nums[left-1]: left += 1    # 去重
    while left < right and nums[right] == nums[right+1]: right -= 1  # 去重
```

#### 关键实现细节

- **先排序**：双指针 + 去重的前提
- **三层去重**（缺一不可）：
  1. 外层 `i`：`if i > 0 and nums[i] == nums[i-1]: continue`
  2. 命中后 `left`：跳过与上一轮相同的值
  3. 命中后 `right`：跳过与上一轮相同的值
- **剪枝**：若 `nums[i] > 0`，后面都 ≥ 0，不可能和为 0，直接 `break`
- **`sum==0` 时双指针同时收缩**（`left++` 且 `right--`），不是只移一边
- 与 LC 11 盛水容器的区别：盛水移短板是贪心剪枝；本题移左/移右由和与 0 的大小关系决定

### 核心代码（Python）

```python
def threeSum(nums: list[int]) -> list[list[int]]:
    nums.sort()
    res = []
    n = len(nums)

    for i in range(n - 2):
        if i > 0 and nums[i] == nums[i - 1]:
            continue
        if nums[i] > 0:
            break

        left, right = i + 1, n - 1
        while left < right:
            s = nums[i] + nums[left] + nums[right]
            if s < 0:
                left += 1
            elif s > 0:
                right -= 1
            else:
                res.append([nums[i], nums[left], nums[right]])
                left += 1
                right -= 1
                while left < right and nums[left] == nums[left - 1]:
                    left += 1
                while left < right and nums[right] == nums[right + 1]:
                    right -= 1
    return res
```

### 第四步：拆解记忆点

#### 一句话破局眼

> **LeetCode 15 三数之和：排序 + 固定 i + 双指针夹逼；和为 0 时记录并双跳，三层 skip 去重。**

#### 复杂度对比

| 方法 | 时间 | 空间 | 适用性 |
|------|------|------|--------|
| 三重枚举 + set 去重 | O(n³) | O(n) | n=3000 TLE |
| 排序 + 双指针 | O(n²) | O(1) 不计输出 | ✅ 最优 |

#### 关键理解点

1. **为什么要排序？** 双指针需要单调方向；去重需要相同值相邻才能 `skip`。
2. **为什么 `sum==0` 时左右都跳？** 当前 `(left, right)` 已记录，只移一边会重复枚举同一对；同时收缩才能继续找新 pair。
3. **去重为什么分三层？** 只去 `i` 不够——`[-1,-1,2]` 可能从不同 `left` 出发重复命中；命中后的 left/right skip 处理同一 `i` 下的重复 pair。
4. **和 LC 16 怎么记？** 同一套骨架：排序 → 固定 i → 双指针。15 = 和为 0 + 收集全部 + 去重；16 = 最接近 target + 维护 res + 命中早停。
