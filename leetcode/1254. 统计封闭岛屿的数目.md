## 破局眼 🎯

> **DFS 淹没所有连通的 0，同时判断是否触碰到边界。如果没碰到边界，就是封闭岛屿。**

你的思路完全正确——关键就一条：**被 1 包围 = 不触碰网格边界**。

### 解法一：DFS 同时判断边界（你的思路）

```python
def closedIsland(self, grid: List[List[int]]) -> int:
    m, n = len(grid), len(grid[0])

    def dfs(i: int, j: int) -> bool:
        """返回 True 表示这块岛屿是封闭的（没触碰边界）"""
        if i < 0 or i >= m or j < 0 or j >= n:
            return False          # 碰到边界 → 不是封闭的
        if grid[i][j] == 1:
            return True           # 碰到水 → 没问题
        grid[i][j] = 1            # 淹没（标记已访问）
        # 四个方向：必须全部封闭，这块地才算封闭
        up = dfs(i - 1, j)
        down = dfs(i + 1, j)
        left = dfs(i, j - 1)
        right = dfs(i, j + 1)
        return up and down and left and right

    count = 0
    for i in range(m):
        for j in range(n):
            if grid[i][j] == 0:
                if dfs(i, j):
                    count += 1
    return count
```

### 解法二：先清除边界再数岛（另一种经典思路）

```python
def closedIsland(self, grid: List[List[int]]) -> int:
    m, n = len(grid), len(grid[0])

    def dfs(i: int, j: int):
        if i < 0 or i >= m or j < 0 or j >= n or grid[i][j] == 1:
            return
        grid[i][j] = 1
        for di, dj in ((1,0), (-1,0), (0,1), (0,-1)):
            dfs(i + di, j + dj)

    # 第一步：淹没所有触碰边界的陆地（它们不是封闭的）
    for i in range(m):
        dfs(i, 0)
        dfs(i, n - 1)
    for j in range(n):
        dfs(0, j)
        dfs(m - 1, j)

    # 第二步：剩下的 0 都是封闭岛屿，正常数
    count = 0
    for i in range(m):
        for j in range(n):
            if grid[i][j] == 0:
                dfs(i, j)
                count += 1
    return count
```

## 什么性质的题可以用这个解法？

本题本质是 **"网格连通分量 + 边界条件判定"** 的 Flood Fill 模式。

### 必要条件

| 性质 | 本题体现 | 反例 |
|------|---------|------|
| **网格上的连通分量** | 4 方向连通的 0 | 非网格图 → 普通图遍历 |
| **边界条件参与判定** | 碰边界 = 不封闭 | 所有分量都计数 → 普通岛屿数量 LC 200 |
| **可原地修改** | 淹没（0→1）不影响结果 | 不能修改原数组 → 用 visited 数组 |
| **小范围**（≤ 100×100） | DFS 栈不会溢出 | 超大网格 → 用 BFS 避免递归栈溢出 |

### 判断流程

```
网格上的岛屿/连通分量问题？
  ├── 是否有额外条件（如是否封闭/是否有特殊形状）？
  │     ├── 无 → 普通 DFS 数岛屿（LC 200）
  │     ├── 是否封闭 → ✅ Flood Fill + 边界判断
  │     ├── 最大面积 → DFS 同时统计面积
  │     └── 周长 → DFS 时碰水界就 +1
  └── 能否原地修改？
        ├── 能 → 直接淹没，不需额外 visited
        └── 不能 → 用 visited 数组或集合
```

### Flood Fill 同类题

| 题目 | 目标 | 特殊条件 |
|------|------|---------|
| LC 200 岛屿数量 | 数所有连通分量 | 无 |
| **LC 1254 封闭岛屿** | **数不碰边界的** | **边界判断** |
| LC 695 岛屿最大面积 | 求最大面积 | 统计面积 |
| LC 463 岛屿的周长 | 求周长 | 水陆交界 +1 |
| LC 130 被围绕的区域 | 找被包围的区域 | 反向：从边界 DFS 标记 |

> **核心：Land 就是 0，水是 1，Flood Fill 是万能的。额外条件（封闭/面积/周长）在 DFS 过程中顺手统计就行。**
