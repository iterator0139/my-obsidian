给你两个整数，`n` 和 `start` 。

数组 `nums` 定义为：`nums[i] = start + 2*i`（下标从 0 开始）且 `n == nums.length` 。

请返回 `nums` 中所有元素按位异或（**XOR**）后得到的结果。

**示例 1：**

**输入：**n = 5, start = 0
**输出：**8
**解释：**数组 nums 为 [0, 2, 4, 6, 8]，其中 (0 ^ 2 ^ 4 ^ 6 ^ 8) = 8 。
     "^" 为按位异或 XOR 运算符。

**示例 2：**

**输入：**n = 4, start = 3
**输出：**8
**解释：**数组 nums 为 [3, 5, 7, 9]，其中 (3 ^ 5 ^ 7 ^ 9) = 8.

**示例 3：**

**输入：**n = 1, start = 7
**输出：**7

**示例 4：**

**输入：**n = 10, start = 5
**输出：**2

**提示：**

- `1 <= n <= 1000`
- `0 <= start <= 1000`
- `n == nums.length`

---

## 破局眼 🎯

> **`n ≤ 1000`，O(n) 直接循环异或就是最优解，代码极简无坑。**

## 解法一：O(n) 暴力（推荐）

```python
def xorOperation(self, n: int, start: int) -> int:
    res = 0
    for i in range(n):
        res ^= start + 2 * i
    return res
```

## 解法二：O(1) 数学（面试亮点）

**思路：** 提取因子 2，将等差数列异或转为连续整数异或。

连续整数 `0 ^ 1 ^ ... ^ x` 的周期规律 `%4`：

| x % 4 | XOR(0..x) |
|-------|-----------|
| 0     | x         |
| 1     | 1         |
| 2     | x+1       |
| 3     | 0         |

```python
def xorOperation(self, n: int, start: int) -> int:
    def xorTo(x):
        if x < 0: return 0
        if x % 4 == 0: return x
        if x % 4 == 1: return 1
        if x % 4 == 2: return x + 1
        return 0

    s = start >> 1
    high = (xorTo(s + n - 1) ^ xorTo(s - 1)) << 1
    low = (start & 1) & (n & 1)   # 奇数个奇数 → 最低位为 1
    return high | low
```

## 什么性质的题可以用这个解法？

本题本质是 **"序列元素按位运算"** 模式。解法一（循环）和 解法二（数学）各自对应的性质不同：

### 解法一（O(n) 循环）适用性质

| 性质 | 本题体现 | 反例 |
|------|---------|------|
| **操作可累积**（结合律） | XOR 满足结合律和交换律 | 非交换运算（如减法） |
| **操作有单位元** | XOR 的单位元是 0 | 无单位元的运算 |
| **数据量小**（n ≤ 1000） | 1000 次循环完全够用 | n > 10⁶ → 必须找数学规律 |

### 解法二（O(1) 数学）适用性质

| 性质 | 本题体现 |
|------|---------|
| **序列有规律**（等差数列） | `start + 2i` 是等差数列 |
| **操作有周期模式** | 连续整数 XOR 有 `%4` 周期 |
| **可提取公因子** | 除以 2 后变成连续整数异或 |

**判断流程：**
```
序列元素按位/算术运算（XOR/AND/OR/SUM）？
  ├── n 很小（≤ 1000）→ ✅ 直接循环，简单可靠
  └── n 很大或追求 O(1)？
        ├── 序列有规律（等差/等比/已知公式）？
        │     ├── 是 → ✅ 找数学规律（周期、通项）
        │     └── 否 → 考虑其他数据结构优化
        └── 运算有逆运算？
              ├── 是 → 前缀和/前缀异或
              └── 否 → 难以优化
```
