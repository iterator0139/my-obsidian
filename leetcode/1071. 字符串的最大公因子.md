对于字符串 `s` 和 `t`，只有在 `s = t + t + t + ... + t + t`（`t` 自身连接 1 次或多次）时，我们才认定 “`t` 能除尽 `s`”。

给定两个字符串 `str1` 和 `str2` 。返回 _最长字符串 `x`，要求满足 `x` 能除尽 `str1` 且 `x` 能除尽 `str2`_ 。

**示例 1：**

**输入：**str1 = "ABCABC", str2 = "ABC"

**输出：**"ABC"

**示例 2：**

**输入：**str1 = "ABABAB", str2 = "ABAB"

**输出：**"AB"

**示例 3：**

**输入：**str1 = "LEET", str2 = "CODE"

**输出：**""

**示例 4：**

**输入：**str1 = "AAAAAB", str2 = "AAA"

**输出：**""

**提示：**

- `1 <= str1.length, str2.length <= 1000`
- `str1` 和 `str2` 由大写英文字母组成

这道题我的思路是，公因子一定是更短的那个的因子组成的，从最长往下递减去判断是否是公因子。暴力判断 

你的暴力法思路完全走在正确的道路上！因为 1≤length≤1000，你的这种“从最长因子往下试”的暴力枚举在时间复杂度上是完全可以支撑通过的。

不过，字符串的“除法”有一个非常神奇的**数学对称性质**。如果我们利用这个性质，就能直接从 O(N2) 的暴力判断，降维打击到 O(N) 的纯数学秒杀。

### 破局眼 🎯

如果两个字符串 `str1` 和 `str2` 存在公共的“因子串” x，那么它们无论怎么拼，结果都应该是一样的。也就是说，**`str1 + str2` 必然等于 `str2 + str1`**。 如果它们连这个拼图测试都过不去，说明根本没有公共因子，直接返回 `""`。 如果通过了测试，那么最大公因子串的长度，就是 `len(str1)` 和 `len(str2)` 的**最大公约数 (GCD)**！

### 解法：数学性质 + 辗转相除法

Python

```
import math

def gcdOfStrings(str1: str, str2: str) -> str:
    # 1. 核心大前提：如果两字符串有公共周期，则满足交换律
    if str1 + str2 != str2 + str1:
        return ""
        
    # 2. 算长度的最大公约数
    gcd_len = math.gcd(len(str1), len(str2))
    
    # 3. 直接截取该长度的子串即为最优解
    return str1[:gcd_len]
```

### 过程图解（str1 = "ABABAB", str2 = "ABAB"）

1. **拼接校验：**
    
    - `str1 + str2` = `"ABABAB" + "ABAB" = "ABABABABAB"`
        
    - `str2 + str1` = `"ABAB" + "ABABAB" = "ABABABABAB"`
        
    - 两者相等！说明必有解。
        
2. **计算长度 GCD：**
    
    - `len(str1) = 6`
        
    - `len(str2) = 4`
        
    - 6 和 4 的最大公约数 gcd(6,4)=2。
        
3. **切片输出：**
    
    - `str1[:2]` → `"AB"`。
        

### 什么性质的题可以用这个解法？

本题本质是 **“字符串周期性与算术同构（Arithmetic Isomorphism）”** 模式。

#### 必要条件

|性质|本题体现|反例（不能用数学 GCD）|
|---|---|---|
|**操作可结合与交换**|`str1 + str2 == str2 + str1` 成立是基础。|字符串拼接顺序会改变核心语境（如非周期性字符串）。|
|**周期刚性绑定**|字符串纯粹由同一个基础单元不断重复拼接而成。|字符串里有“杂质”或允许中间有不同的字符。|
|**长度与内容同构**|内容的周期长度，严格对应数字上的公约数。|问的是“最长公共子序列（LCS）” → 必须用动态规划。|
