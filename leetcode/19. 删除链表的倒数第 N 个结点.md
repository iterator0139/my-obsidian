给你一个链表，删除链表的倒数第 `n` 个结点，并且返回链表的头结点。

**示例 1：**

```
输入：head = [1,2,3,4,5], n = 2
输出：[1,2,3,5]
```

**示例 2：**

```
输入：head = [1], n = 1
输出：[]
```

**示例 3：**

```
输入：head = [1,2], n = 1
输出：[1]
```

**示例 4：**

```
输入：head = [1,2], n = 2
输出：[]
```

**提示：**

- 链表中结点的数目为 `sz`
- `1 <= n <= sz`
- `0 <= Node.val <= 100`
- **进阶**：你能尝试使用一趟扫描实现吗？

---

## 五分钟读题法分析

### 第一步：分析性质

#### 识别信号

> **链表找「倒数第 n 个」= 快指针先走 n 步，再快慢同走，快到头时慢在待删结点的前驱。**

#### 题目性质

- **数据规模**：一趟扫描即可，无特殊 n 上限
- **数据结构**：单向链表
- **目标类型**：删除指定位置结点，返回新头
- **范围约束**：倒数第 n 个，可能删掉头结点
- **操作特征**：单向链表无法从尾往前走，需要 **间距为 n 的双指针**

#### 性质 → 方法

| 性质 | 本题体现 | 若不满足则… |
|------|---------|------------|
| 单向链表 | 只能正向遍历 | 双向链表可两头走 |
| 倒数定位 | 快慢间距 n | 正数第 k 个 → 走 k-1 步即可 |
| 可能删头 | 需要 dummy 哨兵 | 不删头可不用 dummy |
| 要求一趟 | 快慢同扫 O(n) | 两趟：先数长度再删 |

**判断流程**：

```
链表 + 倒数第 n 个？
  ├── 一趟扫描？
  │     └── ✅ 快慢指针：快先走 n 步，再同步走
  └── 两趟可接受？
        └── 先数长度 len，删正数第 (len-n+1) 个
```

#### 方法约束

- **约束**：快慢指针有效，需要「固定间距走完后，一个指针位置能代表目标」
- **本题**：满足。快指针到 `None` 时，慢指针恰在 **待删结点的前一个**
- **易混淆**：
  - LC 876 找中间结点：快走 2 步、慢走 1 步
  - 本题：快先走 **n** 步，再走 1 步间隔（快在待删结点后一位）

---

### 第二步：读题与盲猜

**题目核心**：删除倒数第 n 个结点，返回头结点。

**第一直觉**：第一遍数长度 `len`，第二遍走到 `len-n` 的位置删 `next`。O(n) 时间但两趟。

**盲猜优化方向**：

- **数据结构**：dummy + 快慢指针
- **时间复杂度**：O(n) 一趟
- **关键洞察**：两指针保持 n 的间距，快指针到尾时，慢指针在待删结点 **前驱**

---

### 第三步：最优解法

#### 核心转换

```
倒数第 n 个
  ⇔ 正数第 (len - n + 1) 个
  ⇔ 让 fast 领先 slow 共 n+1 步（含 dummy），fast 到 None 时 slow 在待删前驱
```

#### 状态定义

- `dummy`：虚拟头，`dummy.next = head`，统一处理删头
- `slow`、`fast`：均从 `dummy` 出发
- `fast` 先走 `n+1` 步（或先走 n 步再同步，见变体）

#### 核心状态转移（破局眼）

```python
# fast 先走 n+1 步
for _ in range(n + 1):
    fast = fast.next
# 同步走直到 fast 为 None
while fast:
    slow = slow.next
    fast = fast.next
# slow.next 即待删结点
slow.next = slow.next.next
```

#### 关键实现细节

- **一定要 dummy**：`n == len` 时删的是头结点，`slow` 停在 dummy 上
- **为什么走 n+1 步而不是 n 步？** 走 n 步时 slow 指向待删结点本身，单向链表删结点需要前驱；走 n+1 步 slow 停在前驱，直接 `slow.next = slow.next.next`
- **循环条件**：`while fast`（fast 到 `None` 停止），不是 `while fast.next`
- **返回值**：`dummy.next`，不是 `head`（头可能被删）

### 核心代码（Python）

```python
# Definition for singly-linked list.
# class ListNode:
#     def __init__(self, val=0, next=None):
#         self.val = val
#         self.next = next

def removeNthFromEnd(head: ListNode, n: int) -> ListNode:
    dummy = ListNode(0, head)
    slow = fast = dummy

    for _ in range(n + 1):
        fast = fast.next

    while fast:
        slow = slow.next
        fast = fast.next

    slow.next = slow.next.next
    return dummy.next
```

#### 变体写法（先走 n 步）

```python
# fast 先走 n 步到「倒数第 n 个」本身，同步后 slow 指向待删结点
# 删的时候需要 prev：可在循环后再 slow = slow.next 跳过，或配合 dummy 用前驱写法
```

推荐统一记 **n+1 步 + 前驱删除**，边界最少。

### 第四步：拆解记忆点

#### 一句话破局眼

> **LeetCode 19 删除倒数第 N 个结点：dummy + 快先走 n+1 步，同步走到尾，slow.next 删掉。**

#### 复杂度对比

| 方法 | 时间 | 空间 | 趟数 |
|------|------|------|------|
| 数长度 + 再遍历 | O(n) | O(1) | 2 趟 |
| 快慢指针 | O(n) | O(1) | ✅ 1 趟 |
| 栈存全部结点 | O(n) | O(n) | 1 趟 |

#### 关键理解点

1. **为什么是 n+1 步？** 删链表结点要前驱；n 步对准待删结点，n+1 步对准前驱。
2. **为什么需要 dummy？** 删头 = 删倒数第 len 个，`slow` 必须能停在 dummy 上。
3. **和找中点 (LC 876) 的区别**：876 快 2 慢 1；本题快先走固定 n+1，再 1:1 同步。
4. **返回值为什么是 dummy.next？** 原 head 可能已被删除。
