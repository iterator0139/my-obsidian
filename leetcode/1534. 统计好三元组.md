给你一个整数数组 `arr` ，以及 `a`、`b` 、`c` 三个整数。请你统计其中好三元组的数量。

如果三元组 `(arr[i], arr[j], arr[k])` 满足下列全部条件，则认为它是一个 **好三元组** 。

- `0 <= i < j < k < arr.length`
- `|arr[i] - arr[j]| <= a`
- `|arr[j] - arr[k]| <= b`
- `|arr[i] - arr[k]| <= c`

其中 `|x|` 表示 `x` 的绝对值。

返回 **好三元组的数量** 。

**示例 1：**

**输入：**arr = [3,0,1,1,9,7], a = 7, b = 2, c = 3
**输出：**4
**解释：**一共有 4 个好三元组：[(3,0,1), (3,0,1), (3,1,1), (0,1,1)] 。

**示例 2：**

**输入：**arr = [1,1,2,2,3], a = 0, b = 0, c = 1
**输出：**0
**解释：**不存在满足所有条件的三元组。

---

## 破局眼 🎯

> **`n ≤ 100`，三层暴力 O(n³) 就是最优解。约束复杂但数据极小，暴力枚举比任何"优化"都干净。**

不能用双指针，因为三个下标有 `i < j < k` 位置约束，且条件涉及绝对值差，没有单调性可依赖。

## 代码

```python
def countGoodTriplets(self, arr: List[int], a: int, b: int, c: int) -> int:
    n, ans = len(arr), 0
    for i in range(n):
        for j in range(i + 1, n):
            if abs(arr[i] - arr[j]) > a: continue      # 剪枝
            for k in range(j + 1, n):
                if abs(arr[j] - arr[k]) > b: continue  # 剪枝
                if abs(arr[i] - arr[k]) <= c:
                    ans += 1
    return ans
```

## 什么性质的题可以用这个解法？

本题解法本质是 **"小数据范围 + 枚举所有组合"** 的暴力模式。符合以下性质可以使用：

| 性质                 | 本题体现               | 反例（不能用）             |
| ------------------ | ------------------ | ------------------- |
| **数据规模小**（n ≤ 100） | `arr.length ≤ 100` | n > 1000 → O(n³) 超时 |
| **下标有严格顺序约束**      | `i < j < k`        | 无顺序约束 → 组合数公式直接算    |
| **条件可 O(1) 验证**    | 三次绝对值比较            | 条件需要复杂计算 → 需预处理     |
| **无特殊结构可利用**       | 绝对值差无单调性           | 有序数组 → 可用双指针/二分     |

**判断流程：**
```
数据量 n ≤ 100？
  ├── 条件涉及多个下标组合？
  │     ├── 是 → ✅ 三层暴力枚举 + 剪枝
  │     └── 否 → 考虑其他解法
  └── n > 100？
        ├── 能否用排序/哈希优化条件？
        │     ├── 是 → 用数据结构优化
        │     └── 否 → 可能不是这道题的正解
        └── 考虑滑动窗口/双指针/DP
```
