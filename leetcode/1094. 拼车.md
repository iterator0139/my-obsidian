车上最初有 `capacity` 个空座位。车 **只能** 向一个方向行驶（也就是说，**不允许掉头或改变方向**）

给定整数 `capacity` 和一个数组 `trips` ,  `trips[i] = [numPassengersi, fromi, toi]` 表示第 `i` 次旅行有 `numPassengersi` 乘客，接他们和放他们的位置分别是 `fromi` 和 `toi` 。这些位置是从汽车的初始位置向东的公里数。

当且仅当你可以在所有给定的行程中接送所有乘客时，返回 `true`，否则请返回 `false`。

**示例 1：**

**输入：**trips = $[[2,1,5],[3,3,7]]$, capacity = 4
**输出：**false

**示例 2：**

**输入：**trips = $[[2,1,5],[3,3,7]]$, capacity = 5
**输出：**true

**提示：**

- `1 <= trips.length <= 1000`
- `trips[i].length == 3`
- `1 <= numPassengersi <= 100`
- `0 <= fromi < toi <= 1000`
- `1 <= capacity <= 105`


## 题解

### 方法：差分数组（区间上下车法）

#### 思路分析
这道题的核心问题是：在所有行程中，车上是否有任何一个时刻的乘客数量超过了车的容量？

我们可以使用**差分数组**的方法来解决，这种方法非常直观且高效：
1. 将每个行程看作是一个区间，`from_i` 是上车点，`to_i` 是下车点
2. 在上车点增加乘客数量，在下车点减少乘客数量
3. 遍历整个行程，记录每个时刻的乘客数量，检查是否超出容量

#### 算法步骤
1. 创建一个差分数组 `diff`，用于记录乘客数量的变化
2. 遍历每个行程：
   - 在 `from_i` 位置增加 `numPassengers` 人
   - 在 `to_i` 位置减少 `numPassengers` 人
3. 通过差分数组计算每个时刻的实际乘客数量
4. 检查是否有任何时刻的乘客数量超过容量

#### 代码实现
```python
def carPooling(trips: List[List[int]], capacity: int) -> bool:
    # 创建差分数组，由于位置最大为1000，所以数组长度设为1001
    diff = [0] * 1001
    
    # 遍历每个行程，进行区间增减
    for num, start, end in trips:
        diff[start] += num
        diff[end] -= num
    
    # 计算前缀和，得到每个时刻的乘客数量
    current_passengers = 0
    for i in range(1001):
        current_passengers += diff[i]
        # 如果在任何时刻乘客数量超过容量，返回False
        if current_passengers > capacity:
            return False
    
    return True
```

#### 优化版本
我们可以进一步优化，只遍历实际存在的位置范围：
```python
def carPooling(trips: List[List[int]], capacity: int) -> bool:
    if not trips:
        return True
    
    # 找出最大位置
    max_location = 0
    for _, _, end in trips:
        max_location = max(max_location, end)
    
    # 创建差分数组
    diff = [0] * (max_location + 1)
    
    # 遍历每个行程
    for num, start, end in trips:
        diff[start] += num
        diff[end] -= num
    
    # 计算前缀和
    current_passengers = 0
    for i in range(max_location + 1):
        current_passengers += diff[i]
        if current_passengers > capacity:
            return False
    
    return True
```

#### 复杂度分析
- **时间复杂度**：O(n + L)，其中 n 是行程数量，L 是行程中的最大位置数
- **空间复杂度**：O(L)，用于存储差分数组

#### 示例解析

**示例1**：trips = [[2,1,5],[3,3,7]], capacity = 4

差分数组变化过程：
- 在位置1：+2 → diff[1] = 2
- 在位置5：-2 → diff[5] = -2
- 在位置3：+3 → diff[3] = 3
- 在位置7：-3 → diff[7] = -3

前缀和计算：
- 位置0：0人
- 位置1：0 + 2 = 2人
- 位置2：2人（不变）
- 位置3：2 + 3 = 5人 ← **超过容量4**

因此返回 False。

**示例2**：trips = [[2,1,5],[3,3,7]], capacity = 5

同样的行程，但容量变为5：
- 位置3：5人 ≤ 5容量

因此返回 True。

#### 其他解法

##### 方法二：排序+前缀和
```python
def carPooling(trips: List[List[int]], capacity: int) -> bool:
    # 将所有上下车事件合并并排序
    events = []
    for num, start, end in trips:
        events.append((start, num))
        events.append((end, -num))
    
    # 按位置排序，位置相同则先下车后上车
    events.sort(key=lambda x: (x[0], x[1]))
    
    current = 0
    for pos, change in events:
        current += change
        if current > capacity:
            return False
    
    return True
```

差分数组（区间标记法）是解决这类区间叠加问题的经典方法，特别适合需要频繁进行区间加减操作的场景。对于这道题，它的时间复杂度和空间复杂度都比较优秀，且实现简单直观。
