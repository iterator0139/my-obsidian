给你一个整数数组 `nums` 和一个正整数 `k`。

判断是否有可能把这个数组分成 `k` 个 **非空** 子集，其总和都相等。

**示例 1：**

**输入：** nums = [4,3,2,3,5,2,1], k = 4
**输出：** true
**解释：** 可以划分成 4 个子集，每个子集和为 5：[5]、[1,4]、[2,3]、[2,3]

**示例 2：**

**输入：** nums = [1,2,3,4], k = 3
**输出：** false

**提示：**

- `1 <= k <= nums.length <= 16`
- `1 <= nums[i] <= 10^4`

---

## 五分钟读题法分析

### 第一步：分析性质

#### 识别信号

> **把数组分成 k 组、每组和相等 → 先算 target = sum/k；每组容量都是 target，每个数用一次 → k 个背包 / 重复子集和，n≤16 用回溯或状压 DP。**

#### 题目性质

- **数据规模**：n ≤ **16**——2¹⁶ ≈ 65536，状压 DP / 回溯都可行
- **数据结构**：整数数组
- **目标类型**：可行性（能否划分）
- **约束特征**：每个元素**恰好用一次**；k 组**非空**、组和相等
- **背包信号**：每组和固定为 `target`，等价于往 k 个容量为 `target` 的背包里装物品

#### 性质 → 方法

| 性质 | 本题体现 | 若不满足则… |
|------|---------|------------|
| 组和相等 | 每组和 = sum/k | sum % k ≠ 0 → 直接 false |
| 每元素用一次 | 划分，不重复 | 可重复用 → 完全背包 |
| n 很小（≤16） | 状压 DP / 回溯 | n 大 → 只能近似或更强剪枝 |
| 可行性 | 只需 true/false | 要数方案数 → DP 计数 |

**判断流程**：

```
能否分成 k 个和相等的非空子集？
  ├── sum % k ≠ 0 → false
  ├── max(nums) > target → false
  └── n ≤ 16
        ├── 回溯 + 剪枝 → ✅ 经典写法
        └── 状压 DP（背包）→ ✅ 你的直觉，等价正确
```

#### 方法约束

- **约束**：必须先有 `target = sum / k`；回溯需降序排序 +「空桶失败则剪枝」；状压需记录当前桶已装多少
- **本题**：满足
- **易混淆**：LC 416「分割等和子集」是 k=2 的特例；本题不是贪心（如按顺序凑和会漏解）

### 第二步：读题与盲猜

**题目核心**：能否把数组分成 k 份，每份非空且和都是 `sum/k`。

**第一直觉**：贪心——从大数开始往 k 个桶里放？会漏解，如 `[2,2,2,2], k=2` 需配对而非简单贪心。

**盲猜优化方向**：

- **数据结构**：回溯（used 数组）或 状压 `dp[mask]`
- **时间复杂度**：O(k · 2^n · n) 回溯；O(2^n · n) 状压 DP
- **关键洞察**：k 组和相等 ⟺ 用所有数填满 k 个容量为 `target` 的背包；本质是**子集和 / 背包**的扩展

---

### 第三步：最优解法

#### 核心转换

```
1. target = sum(nums) / k   （sum % k ≠ 0 则 false）
2. 问题等价于：能否把 nums 分成 k 个子集，每个子集和 = target
3. 再等价于：k 个容量为 target 的背包，每个数用一次，能否全部装完
```

这就是 **k-划分背包** / **重复子集和**——你的「背包」直觉完全正确。

#### 写法 A：回溯 + 剪枝（最常用）

**状态**：当前填第几个桶 `k`、当前桶已装 `bucket`、从 `start` 开始尝试

**破局眼**：

```
填满一桶（bucket == target）→ 开始填下一桶
否则从 start 起选未用过的数加入当前桶
剪枝：bucket == 0 且本层失败 → break（同样数字不要重复尝试开新桶）
```

#### 写法 B：状压 DP（背包视角）

**状态定义**

- `mask`：哪些数已选用（二进制位）
- `sums[mask]`：当前正在装的这一桶，已装多少
- `dp[mask]`：该 mask 状态是否可达

**破局眼**：

```
从可达的 mask 出发，选一个未用的 nums[i]：
  new_sum = sums[mask] + nums[i]
  if new_sum > target: skip
  if new_sum == target: 一桶装满 → sums[new_mask] = 0
  else:                  sums[new_mask] = new_sum
  dp[new_mask] = True

答案：dp[全 1 mask] 且 sums[全 1 mask] == 0（最后一桶也刚好装满）
```

### 核心代码（Python）

**写法 A：回溯**

```python
def canPartitionKSubsets(nums: list[int], k: int) -> bool:
    total = sum(nums)
    if total % k != 0:
        return False
    target = total // k
    nums.sort(reverse=True)
    if nums[0] > target:
        return False

    used = [False] * len(nums)

    def dfs(k: int, bucket: int, start: int) -> bool:
        if k == 0:
            return True
        if bucket == target:
            return dfs(k - 1, 0, 0)
        for i in range(start, len(nums)):
            if used[i] or bucket + nums[i] > target:
                continue
            used[i] = True
            if dfs(k, bucket + nums[i], i + 1):
                return True
            used[i] = False
            if bucket == 0:
                break
        return False

    return dfs(k, 0, 0)
```

**写法 B：状压 DP（背包）**

```python
def canPartitionKSubsets_dp(nums: list[int], k: int) -> bool:
    total = sum(nums)
    if total % k != 0:
        return False
    target = total // k
    n = len(nums)
    full = (1 << n) - 1

    dp = [False] * (1 << n)
    sums = [0] * (1 << n)
    dp[0] = True

    for mask in range(1 << n):
        if not dp[mask]:
            continue
        for i in range(n):
            if mask & (1 << i):
                continue
            nxt = mask | (1 << i)
            s = sums[mask] + nums[i]
            if s > target:
                continue
            dp[nxt] = True
            sums[nxt] = 0 if s == target else s
            if nxt == full and sums[nxt] == 0:
                return True
    return dp[full] and sums[full] == 0
```

### 第四步：拆解记忆点

#### 一句话破局眼

> **LeetCode 698 划分为 k 个相等的子集：target = sum/k，k 个容量 target 的背包每个数用一次；n≤16 回溯或状压 DP。**

#### 复杂度对比

| 方法 | 时间复杂度 | 空间复杂度 | 适用性 |
|------|-----------|-----------|--------|
| 贪心 | — | — | 会漏解，不可用 |
| **回溯 + 剪枝** | **O(k · 2^n · n)** | **O(n)** | **面试最常写** |
| **状压 DP** | **O(2^n · n)** | **O(2^n)** | **背包视角，n≤16** |

#### 关键理解点

1. **为什么是背包？** 每组和 = target = 背包容量；每个数用一次 = 0/1 背包；要装 k 个满桶
2. **先判什么？** `sum % k != 0` 或 `max(nums) > target` 直接 false
3. **回溯剪枝**：降序排序；`bucket == 0` 本层失败就 break，避免重复排列（如两个 2 开新桶）
4. **和 416 的关系**：416 是 k=2 特例；698 是 k 个相等子集
