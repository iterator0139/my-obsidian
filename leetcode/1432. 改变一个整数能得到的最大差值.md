给你一个整数 `num` 。你可以对它进行以下步骤共计 **两次**：

- 选择一个数字 `x (0 <= x <= 9)`.
- 选择另一个数字 `y (0 <= y <= 9)` 。数字 `y` 可以等于 `x` 。
- 将 `num` 中所有出现 `x` 的数位都用 `y` 替换。

令两次对 `num` 的操作得到的结果分别为 `a` 和 `b` 。

请你返回 `a` 和 `b` 的 **最大差值** 。

注意，`a` 和 `b` **必须不能** 含有前导 0，并且 **不为** 0。

**示例 1：**

**输入：**num = 555
**输出：**888
**解释：**第一次选择 x = 5 且 y = 9 ，并把得到的新数字保存在 a 中。
第二次选择 x = 5 且 y = 1 ，并把得到的新数字保存在 b 中。
现在，我们有 a = 999 和 b = 111 ，最大差值为 888

**示例 2：**

**输入：**num = 9
**输出：**8
**解释：**第一次选择 x = 9 且 y = 9 ，并把得到的新数字保存在 a 中。
第二次选择 x = 9 且 y = 1 ，并把得到的新数字保存在 b 中。
现在，我们有 a = 9 和 b = 1 ，最大差值为 8

**示例 3：**

**输入：**num = 123456
**输出：**820000

**示例 4：**

**输入：**num = 10000
**输出：**80000

**示例 5：**

**输入：**num = 9288
**输出：**8700

**提示：**

- `1 <= num <= 10^8`

## 破局眼 🎯

> **求 max：从左找第一个 ≠9 的数字，替换成 9。求 min：首位≠1 则替换首位为 1；首位=1 则从左找第一个 ≠0 且 ≠1 的数字，替换成 0。**

两次操作独立，分别求 a（最大可能值）和 b（最小可能值），差值 = a - b。

### 求最大值 a（高位优先变大）

从左到右找**第一个不是 9 的数字**，把所有这个数字替换成 9。

```text
555  → 第一个非9 = 5 → 5→9 → 999
9288 → 第一个非9 = 2 → 2→9 → 9988
9    → 全是9 → 不变 → 9
```

### 求最小值 b（高位优先变小）

分两种情况：

| 情况 | 操作 | 例子 |
|------|------|------|
| **首位 ≠ 1** | 把首位（及所有相同数字）替换成 1 | `555→111`, `9288→1288`, `9→1` |
| **首位 = 1** | 从左找第一个**≠0 且 ≠1** 的数字，替换成 0 | `123456→103456` |
| **首位 = 1 且后面全是 0/1** | 无法变小，b = 原数 | `10000→10000`, `110→110` |

## 代码

```python
def maxDiff(self, num: int) -> int:
    s = str(num)

    # 求最大值：找第一个不是9的数字，换成9
    def get_max(s: str) -> int:
        for ch in s:
            if ch != '9':
                return int(s.replace(ch, '9'))
        return int(s)

    # 求最小值
    def get_min(s: str) -> int:
        # 情况1：首位不是1 → 把首位换成1
        if s[0] != '1':
            return int(s.replace(s[0], '1'))
        # 情况2：首位是1 → 找第一个不是0也不是1的数字，换成0
        for ch in s[1:]:
            if ch not in ('0', '1'):
                return int(s.replace(ch, '0'))
        return int(s)   # 找不到能换的

    return get_max(s) - get_min(s)
```

> ⚠️ `s.replace(ch, '9')` 会把字符串中**所有** `ch` 替换成 `9`，正好满足题目"所有出现的 x 都用 y 替换"。

## 什么性质的题可以用这个解法？

本题本质是 **"数字位替换 + 贪心（高位优先）"** 模式。

### 必要条件

| 性质 | 本题体现 | 反例（不能用） |
|------|---------|-------------|
| **替换全局性**（改一处全改） | 所有相同数字全替换 | 可逐位独立修改 → 每一位单独决策 |
| **前导零约束** | 首位不能变成 0 | 无此约束 → 直接把首位变 0 得最小值 |
| **高位权重大** | 最左位变化影响最大 | 每一位权重相同（如集合）→ 换哪个都行 |
| **两次操作独立** | max 和 min 分别对原数操作 | 操作串联（第二次基于第一次结果）→ 需整体决策 |

### 贪心策略的数学基础

**位置权重**决定了为什么从左找第一个可替换数字：

```text
数字 abcd = a·10³ + b·10² + c·10¹ + d·10⁰
           ↑ 权重最高，修改这里影响最大
```

- **求最大**：把高位能变大最多的数字变大 → 从左找第一个 ≠9
- **求最小**：把高位能变小最多的数字变小 → 首位≠1 则首位→1，首位=1 则下一个 →0

### 判断流程

```
数字/字符串替换问题？
  ├── 替换是否全局（同字符全换）？
  │     ├── 是 → 关注"替换什么数字"（而非"替换哪个位置"）
  │     └── 否 → 关注"替换哪个位置"
  ├── 是否有前导零约束？
  │     ├── 是 → 首位需要特殊处理
  │     └── 否 → 无限制，更大操作空间
  ├── 目标是最值（最大/最小）？
  │     ├── 是 → ✅ 贪心：高位优先
  │     └── 否 → 可能是计数/可行性问题
  └── 替换后的值要参与计算？
        ├── 是 → 按需调整
        └── 否 → 只需输出替换后的字符串
```

| LC 1432 最大差值 | 全局替换，最值 | 贪心高位优先 |
